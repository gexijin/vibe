# 使用 Claude Code 在 Excel 中 Vibe 编程打造预算追踪表

Vibe 编程就像与计算机对话——你描述想要的结果，Claude Code 负责构建，你来测试和完善。这不是魔法，而是一种新的工作方式：你把握方向，AI 负责处理电子表格的具体细节，包括公式、格式和图表。本教程将带你仅用自然语言请求，打造一个真正的多工作表预算追踪表。

## 核心概念

- **[Claude Code](https://code.claude.com/)** - AI 编程助手，根据你的自然语言请求编写、编辑和修复文件
- **多工作表工作簿** - 一个包含多个标签页（收入、支出、汇总）的 `.xlsx` 文件，各标签页之间通过公式相互引用
- **迭代完善** - Vibe 编程的核心模式：描述 → 测试 → 完善 → 提交可用版本

## 你需要准备的内容

- 完成 [在 VS Code 中使用 Claude Code 处理 Excel](./Excel_Coding_VS_Code_Guide)
- 完成 [将 GitHub Desktop 与 Claude Code 结合使用](./GitHub_Desktop_Claude_Code_Workflow)
- 25-30 分钟

## 步骤 1：创建新的 GitHub 仓库

- 打开 GitHub Desktop
- 点击 **File > New Repository**
- 填写详细信息：
  - **Name:** `budget-dashboard`
  - **Description:** `用 Vibe 编程打造的个人预算追踪表`
  - **Local Path:** 选择一个位置（例如 Documents 或工作文件夹）
  - 勾选 **Initialize this repository with a README**
- 点击 **Create Repository**
- 点击顶部的 **Publish repository**
- 如果希望公开，取消勾选 **Keep this code private**（可选）
- 点击 **Publish Repository**

现在你已拥有一个本地 Git 仓库，以及在 GitHub 上的备份。

## 步骤 2：在 VS Code 中打开项目

- 打开 VS Code
- 点击 **File > Open Folder**
- 选择你的 `budget-dashboard` 文件夹
- 点击 **Select Folder**（Windows）或 **Open**（Mac）
- 如果还没有安装，请安装 MESCIUS 发布的 **Spreadsheet Viewer** 扩展（原名为 GrapeCity 发布的 **Excel Viewer**），这样无需离开 VS Code 就能预览电子表格。在 Extensions 面板中搜索它的 ID `GrapeCity.gc-excelviewer`，即可找到正确的扩展

## 步骤 3：启动 Claude Code

- 点击 **Terminal > New Terminal**
- 输入以下命令启动 Claude Code：

```bash
claude
```

- 如有提示请登录，然后等待 Claude 的欢迎信息出现

Claude Code 现在已经运行，随时可以接收你的请求。

## 步骤 4：第一次 Vibe - 创建收入和支出工作表

不用一个单元格一个单元格地搭建电子表格，只需描述你想要什么。

- 在 Claude Code 终端中输入：

```
创建一个名为 budget.xlsx 的电子表格，包含两个工作表：“收入”和“支出”。“收入”工作表包含“来源”、“月份”和“金额”三列，填入 3 个示例收入来源，覆盖 2 个月。“支出”工作表包含“类别”、“月份”和“金额”三列，填入 6 个示例类别（如房租、日用杂货、交通、水电费、娱乐、储蓄），覆盖同样的 2 个月。在每个工作表底部添加一个“合计”行，使用 SUM 公式求和。
```

- 按 Enter
- 看着 Claude 编写并运行一个 Python 脚本来生成工作簿，然后重新计算，让合计显示真实的数字
- 在 Spreadsheet Viewer 标签页中打开 `budget.xlsx`，逐个点击查看两个工作表

**保存进度**：让 Claude 用 Git 提交，或者自己在 GitHub Desktop 中操作：
```
提交这些更改。
```

## 步骤 5：第二次 Vibe - 添加汇总工作表

在制作图表之前，先把两个工作表关联起来。

- 在 Claude Code 终端中输入：

```
在 budget.xlsx 中添加第三个工作表，命名为“汇总”。它应显示“总收入”、“总支出”和“净储蓄”（收入减去支出），每一项都要用引用“收入”和“支出”工作表的公式计算，而不是写死的数字。
```

- 按 Enter
- Claude 会更新工作簿并重新计算
- 打开 **汇总** 标签页，点击“净储蓄”单元格，确认它是一个引用了其他工作表的公式

**保存进度**：让 Claude 提交，或者使用 GitHub Desktop。

## 步骤 6：第三次 Vibe - 添加图表

数字固然有用，但图表能让你一眼看懂全貌。

- 在 Claude Code 终端中输入：

```
在“支出”工作表中添加一个饼图，显示每个类别在总支出中所占的比例。在“汇总”工作表中添加一个柱状图，按月比较总收入和总支出。
```

- 按 Enter
- Claude 会添加这两个图表并重新计算文件
- 在 Spreadsheet Viewer 中重新打开 `budget.xlsx`（或刷新标签页），检查两个工作表中的新图表

## 步骤 7：第四次 Vibe - 突出显示超支类别

让问题一目了然，而不必在一堆数字中苦苦寻找。

- 在 Claude Code 终端中输入：

```
在“支出”工作表中添加条件格式：单月超过 $500 的支出用红色突出显示，低于 $100 的用绿色突出显示。
```

- 按 Enter
- 重新打开文件，检查“支出”工作表——单元格现在应该会根据数值显示不同颜色

如果有地方看起来不对，把你看到的内容复制下来，描述给 Claude，让它修复。

## 步骤 8：第五次 Vibe - 添加类别下拉列表

让表格更容易扩展，同时避免输入错误。

- 在 Claude Code 终端中输入：

```
为“支出”工作表中的“类别”列添加数据验证，使其只接受下拉列表中的值，列表包含现有的所有类别，再加上“其他”。在底部添加两行空白行，方便填写新条目。
```

- 按 Enter
- 打开文件，点击其中一个空白的“类别”单元格，确认出现了下拉箭头，并且列表中有你的各个类别

## 步骤 9：审查并提交

提交之前，先检查一下 Claude 构建的内容。

- 在 Spreadsheet Viewer 中，逐个点击查看全部三个工作表——收入、支出、汇总
- 你不需要看懂每一个公式，但要大致了解整体结构
- 打开 GitHub Desktop
- 你会看到 `budget.xlsx` 显示为已更改的文件
- 在左下角的 **Summary** 字段中输入：

```
为预算追踪表添加图表、条件格式和类别下拉列表
```

- 点击 **Commit to main**
- 点击 **Push origin** 备份到 GitHub

你已经保存了一个完整可用的预算追踪表版本！

## 步骤 10：迭代并改进

Vibe 编程的优势在于迭代。试着通过描述来添加新功能：

**可以向 Claude 提出的请求示例：**

- “在‘汇总’工作表中添加一个‘储蓄目标’行，显示距离每月 $500 储蓄目标的进度”
- “添加第四个工作表，等我补充更多月份的数据后，用它显示同比对比”
- “把饼图的颜色改成蓝灰色主题”
- “为每个公式添加注释说明，让我能学习它们的作用”
- “再创建一个名为 household_budget.xlsx 的工作簿，为四口之家设计，包含更多类别”

每成功完成一个功能后：
- 打开文件，在 Spreadsheet Viewer 中检查
- 如果没问题，用 GitHub Desktop 提交
- 如果有地方不对，描述给 Claude 并请它修复
- 修复后，提交可用的版本

**核心原则：**

- **描述结果，而不是实现方式** - 说“突出显示超过 $500 的支出”，而不是“使用 CellIsRule 设置条件格式”
- **快速迭代** - 测试 → 完善 → 测试 → 完善
- **提交可用版本** - 在尝试新功能之前，先保存每一次成功的成果
- **坦然面对失败** - 如果公式或图表没有达到预期，只需描述问题，请 Claude 修复
- **掌握主导权** - 由你决定追踪表应该显示什么，以及什么时候算是足够好

每次都遵循这个模式：描述 → 检查文件 → 迭代 → 提交。

## 下一步

- **分享你的追踪表** - 把完成的文件推送到 GitHub，这样你（或家人）就能随时获取最新版本
- **了解更多 Vibe 编程知识** - 访问 [IBM 的指南](https://www.ibm.com/think/topics/vibe-coding)，深入了解这种编程方式

## 故障排除

- **公式单元格显示为空白或 `None`** - 文件在编辑后需要重新计算。可以对 Claude 说：“重新计算 budget.xlsx，并确认没有公式错误。”
- **修改数据后图表没有更新** - 在 VS Code 中重新打开标签页（关闭后再次点击文件），强制 Spreadsheet Viewer 刷新。
- **Claude 出错了** - 这很正常！描述哪里看起来不对，请 Claude 修复。Vibe 编程本身就包含迭代和调试。
- **无法推送到 GitHub** - 确认你已登录 GitHub Desktop，并且已经发布了仓库（步骤 1）。检查网络连接。
- **下拉列表没有出现** - 数据验证只会在真正的电子表格应用（Excel、LibreOffice、Google Sheets）中显示，轻量级预览工具不一定支持。请用 Excel 或 LibreOffice Calc 打开文件进行测试。

## 工作流程概述

本教程将几种工具组合成了一个工作流程：

- **GitHub Desktop** - 具有可视化界面的版本控制（创建仓库、提交、推送）
- **VS Code** - 带有 Spreadsheet Viewer 扩展、可快速预览的编辑器
- **Claude Code** - 根据你的描述构建和编辑真正 `.xlsx` 文件的 AI 助手
- **openpyxl（在幕后工作）** - Claude 用来向文件写入公式、格式和图表的引擎

魔法不在于任何单一工具——而在于 Vibe 编程让你能够描述想要的内容并快速迭代。你从一个空文件夹开始，最终得到了一个可用的、图表丰富的预算追踪表，全程没有亲手写过一个公式。

## 日常工作流程

完成这次初始设置后，你日常的 Vibe 编程流程将变成：

1. **打开 VS Code** - 打开你的项目文件夹
2. **启动 Claude Code** - 在终端中输入 `claude`
3. **描述你的目标** - “添加一个功能……”或“修复……那一行”
4. **检查文件** - 在 Spreadsheet Viewer 或 Excel/LibreOffice 中打开它
5. **迭代或提交** - 如果有问题，描述需要怎么修复；如果没问题，用 GitHub Desktop 提交
6. **定期推送** - 点击 **Push origin** 备份到 GitHub

练习得越多，你就越擅长描述自己想要的东西。Vibe 编程是一项技能——你会逐渐了解哪种描述方式最有效，以及如何把大的电子表格构想拆分成可以逐一测试的小部分。
