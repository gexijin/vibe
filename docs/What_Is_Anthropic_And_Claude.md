# What Is Anthropic and Claude?

Before you install anything, it helps to know what you're actually installing. **Claude** is an AI assistant made by a company called **Anthropic** — think of it like a very capable helper you chat with in plain English, and it can read, write, answer questions, and even write computer code for you. This guide gets you talking to Claude for the first time, with no downloads or setup required.

## Key Concepts

- **Anthropic** - The company that builds Claude. It's based in San Francisco and focuses on making AI that's helpful and safe to use
- **Claude** - Anthropic's AI assistant. You chat with it by typing messages, similar to texting a very knowledgeable friend
- **Prompt** - The message you type to Claude. The clearer your prompt, the better Claude's answer
- **Model** - A specific version of Claude (for example, one built for quick answers and one built for harder problems). You don't need to pick one yet

## What You'll Need

- A computer or phone with a web browser
- An email address
- 10 - 15 minutes

## Step 1: Create a Free Claude Account

- Go to [claude.ai](https://claude.ai)
- Click **Sign up**
- Type your email address and click **Continue**
- Check your email for a verification code and type it in
- Follow the on-screen prompts to finish creating your account

## Step 2: Send Your First Message

- Once you're logged in, you'll see a text box that says something like "How can I help you today?"
- Click inside the box and type:
   ```
   Explain what a computer program is, like I'm 10 years old.
   ```
- Click the **send arrow** (or press **Enter**)
- Read Claude's response — it should appear within a few seconds

## Step 3: Ask a Follow-Up Question

Claude remembers what you've already talked about in the same conversation.

- In the same chat, type a follow-up such as:
   ```
   Can you give me a real-world example of that?
   ```
- Notice that Claude's answer builds on your first question, without you repeating any context

## Step 4: Find the Model Picker

- Look near the top of the chat window for a button showing a model name (for example, "Claude")
- Click it to see a short list of available models
- You don't need to change anything here — just know this menu exists, since some later tutorials will ask you to pick a specific model

- **Keep chatting**: Ask Claude to help plan something you're already working on — an email, a recipe, or a study guide
- **Try a harder prompt**: Ask Claude to compare two options for a decision you're facing, and see how it explains its reasoning

## Troubleshooting

- **Didn't receive a verification email** - Check your spam or junk folder; wait a minute and click **Resend code** if needed
- **Page won't load or looks broken** - Refresh the page, or try a different browser like Chrome or Firefox
- **Not sure what to type** - Start simple: ask Claude to explain a topic you're curious about, or ask for help with something you're already doing today
