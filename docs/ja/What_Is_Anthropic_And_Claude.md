# AnthropicとClaudeとは？

何かをインストールする前に、自分が何をインストールしようとしているのかを知っておくと役立ちます。**Claude**は、**Anthropic**という会社が作ったAIアシスタントです。普段の言葉で話しかけられるとても有能なお手伝い役のようなもので、文章を読んだり書いたり、質問に答えたり、さらにはコンピュータのコードを書いたりもしてくれます。このガイドでは、ダウンロードや設定なしで、初めてClaudeと会話するところまでを案内します。

## 主要な概念

- **Anthropic** - Claudeを開発している会社です。サンフランシスコを拠点とし、役に立ち、安全に使えるAIづくりに力を入れています
- **Claude** - AnthropicのAIアシスタントです。メッセージを入力してチャットします。物知りな友人にメッセージを送るような感覚です
- **プロンプト（Prompt）** - Claudeに入力するメッセージのことです。プロンプトがわかりやすいほど、Claudeの回答も良くなります
- **モデル（Model）** - Claudeの特定のバージョンです（たとえば、すばやく答えるためのものや、難しい問題に取り組むためのものがあります）。今はまだ選ぶ必要はありません

## 用意するもの

- Webブラウザが使えるコンピュータまたはスマートフォン
- メールアドレス
- 10〜15分

## ステップ1：無料のClaudeアカウントを作成する

- [claude.ai](https://claude.ai)にアクセス
- **Sign up**をクリック
- メールアドレスを入力し、**Continue**をクリック
- メールに届いた確認コードを確認し、入力
- 画面の指示に従ってアカウントの作成を完了

## ステップ2：最初のメッセージを送る

- ログインすると、「How can I help you today?」のような文が表示された入力欄が表示されます
- 入力欄の中をクリックして、次のように入力します：
   ```
   コンピュータプログラムとは何か、10歳の子どもにもわかるように説明してください。
   ```
- **送信矢印**をクリック（または**Enter**キーを押す）
- Claudeの返答を読みます。数秒以内に表示されるはずです

## ステップ3：続けて質問する

Claudeは、同じ会話の中ですでに話した内容を覚えています。

- 同じチャットで、次のような追加の質問を入力します：
   ```
   それについて、身近な例を挙げてもらえますか？
   ```
- 前の内容を繰り返さなくても、Claudeの回答が最初の質問を踏まえたものになっていることに注目してください

## ステップ4：モデル選択メニューを見つける

- チャット画面の上部付近にある、モデル名（たとえば「Claude」）が表示されたボタンを探します
- クリックすると、利用できるモデルの短い一覧が表示されます
- ここで何かを変更する必要はありません。後のチュートリアルで特定のモデルを選ぶよう求められることがあるので、このメニューがあることだけ覚えておきましょう

## 次のステップ

- **Claude Codeをインストールする**：[WindowsにClaude Codeをインストール](Install_CLAUDE_Code_Win)または[MacにClaude Codeをインストール](Install_Claude_Code_MacOS)で、同じAIアシスタントをコーディングプロジェクトに取り入れましょう
- **チャットを続ける**：メール、レシピ、学習ガイドなど、今取り組んでいることの計画をClaudeに手伝ってもらいましょう
- **もっと難しいプロンプトを試す**：迷っている選択肢を2つ比べてもらい、Claudeがどのように理由を説明するか見てみましょう

## トラブルシューティング

- **確認メールが届かない** - 迷惑メールフォルダを確認してください。1分ほど待ってから、必要に応じて**Resend code**をクリックします
- **ページが読み込まれない、または表示が崩れる** - ページを再読み込みするか、ChromeやFirefoxなど別のブラウザを試してください
- **何を入力すればよいかわからない** - まずは簡単なことから始めましょう。気になる話題について説明してもらったり、今日やっていることを手伝ってもらったりしてみてください
