# Die Claude Desktop-App installieren

Claude Desktop ist eine eigenständige Chat-App für Windows und Mac. Sie öffnen die App, tippen eine Nachricht ein, und Claude antwortet – ganz ohne Terminal und ohne Befehle. Damit können Sie bequem mit Claude chatten, etwa für Alltagsfragen, Recherchen oder zum Schreiben.

Das ist etwas anderes als **Claude Code**, das Werkzeug, das in den übrigen Tutorials verwendet wird. Claude Code läuft in einem Terminal und hilft Ihnen, Code in einem Projektordner zu schreiben und zu bearbeiten. Claude Desktop ist ein allgemeines Chatfenster. Sie können beides installieren und mit einem kostenpflichtigen Abo Claude Code sogar direkt aus Claude Desktop heraus öffnen.

## Wichtige Konzepte

- **Claude Desktop**: Eine Desktop-App für Windows und Mac, in der Sie direkt mit Claude chatten – ähnlich wie in einer Messenger-App.
- **Claude.ai-Konto**: Das Konto, mit dem Sie sich anmelden – dasselbe, das Sie auch auf [claude.ai](https://claude.ai) verwenden würden. Sowohl kostenlose als auch kostenpflichtige Abos funktionieren.
- **Claude Code**: Der terminalbasierte Programmierassistent, um den es in den anderen Tutorials dieser Website geht. Er wird separat installiert – siehe [Claude Code unter Windows installieren](./Install_CLAUDE_Code_Win.md) oder [Claude Code auf dem Mac installieren](./Install_Claude_Code_MacOS.md).

## Was Sie benötigen

- Einen Computer mit Windows 10 (oder neuer) oder einen Mac (macOS 11 Big Sur oder neuer)
- Eine Internetverbindung
- Ein kostenloses oder kostenpflichtiges Claude.ai-Konto (falls Sie noch keines haben, können Sie es während der Einrichtung erstellen)
- 5 Minuten

## Schritt 1: Das Installationsprogramm herunterladen

- Rufen Sie [claude.ai/download](https://claude.ai/download) auf
- **Windows:** Klicken Sie auf **Download for Windows**. (Falls Sie einen Windows-PC mit ARM-Prozessor haben – das ist eher selten –, verwenden Sie stattdessen den separaten arm64-Download-Link auf der Seite.)
- **Mac:** Klicken Sie auf **Download for macOS**. Dieser eine Download funktioniert sowohl auf Macs mit Intel- als auch mit Apple-Silicon-Chip, Sie müssen also nicht wissen, welchen Chip Ihr Mac hat.

## Schritt 2: Die App installieren

### Windows

- Öffnen Sie die heruntergeladene Datei (schauen Sie in Ihrem **Downloads**-Ordner nach, falls sie sich nicht automatisch öffnet)
- Folgen Sie den Anweisungen des Installationsprogramms auf dem Bildschirm
- Wenn die Installation abgeschlossen ist, finden Sie **Claude** in Ihrem Startmenü

### Mac

- Öffnen Sie die heruntergeladene Datei
- Ziehen Sie das **Claude**-Symbol in den Ordner **Programme** (englisch: **Applications**), wenn Sie dazu aufgefordert werden
- Öffnen Sie **Claude** aus Ihrem **Programme**-Ordner oder über das Launchpad

## Schritt 3: Anmelden

- Starten Sie die Claude-App
- Melden Sie sich mit Ihrem Claude.ai-Konto an und folgen Sie dabei den Anweisungen auf dem Bildschirm
- Sie haben noch kein Konto? Erstellen Sie zuerst auf [claude.ai](https://claude.ai) ein kostenloses Konto, kommen Sie dann zurück und melden Sie sich an

## Schritt 4: Ihre erste Nachricht senden

- Klicken Sie in das Nachrichtenfeld
- Tippen Sie zum Beispiel: `Wobei kannst du mir helfen?`
- Drücken Sie **Enter**, um die Nachricht zu senden
- Claude antwortet direkt im App-Fenster

## Schritt 5: (Optional) Entdecken, was Claude Desktop noch kann

Claude Desktop ist nicht nur zum Chatten da. Je nach Abo stehen Ihnen folgende Funktionen zur Verfügung:

- **Chat** – in jedem Abo verfügbar, auch im kostenlosen (Free)
- **Claude Code** – mit den Abos Pro, Max, Team und Enterprise können Sie Claude Code direkt aus Claude Desktop heraus starten, ohne ein separates Terminal zu öffnen
- **Claude Cowork** – in kostenpflichtigen Abos kann Claude damit mehrstufige Aufgaben erledigen und dabei auf lokale Dateien zugreifen
- **Desktop Extensions** – eine fortgeschrittene Funktion, die Claude über ein Verzeichnis installierbarer Erweiterungen mit lokalen Apps und Dateien verbindet; für den Einstieg nicht nötig

Für das alltägliche Chatten mit Claude Desktop brauchen Sie nichts davon – es lohnt sich aber, diese Funktionen auszuprobieren, sobald Sie mit den Grundlagen vertraut sind.

## Fehlerbehebung

- **Windows blockiert das Installationsprogramm mit der Meldung „Der Computer wurde durch Windows geschützt“ („Windows protected your PC“)** – Das ist die übliche SmartScreen-Warnung von Windows bei neuen Downloads und betrifft nicht nur Claude. Klicken Sie auf **Weitere Informationen** (**More info**) und dann auf **Trotzdem ausführen** (**Run anyway**), wenn Sie der Quelle vertrauen (der offiziellen Seite claude.ai/download).
- **Der Mac meldet, dass die App „nicht geöffnet werden kann, da sie von einem nicht verifizierten Entwickler stammt“** – Das ist Gatekeeper, eine übliche Sicherheitsprüfung von macOS. Klicken Sie mit der rechten Maustaste (oder bei gedrückter control-Taste) auf die Claude-App, wählen Sie **Öffnen** (**Open**) und bestätigen Sie.
- **Die Anmeldung funktioniert nicht** – Prüfen Sie Ihre Internetverbindung und testen Sie zuerst, ob Sie sich im Browser auf [claude.ai](https://claude.ai) anmelden können.
- **Die App startet nach der Installation nicht** – Starten Sie Ihren Computer neu und versuchen Sie dann erneut, Claude zu öffnen. Falls das nicht hilft, laden Sie das Installationsprogramm erneut von [claude.ai/download](https://claude.ai/download) herunter.
