# Was ist Anthropic und was ist Claude?

Bevor Sie etwas installieren, ist es hilfreich zu wissen, was Sie da eigentlich installieren. **Claude** ist ein KI-Assistent (KI = künstliche Intelligenz) der Firma **Anthropic** – stellen Sie sich einen sehr fähigen Helfer vor, mit dem Sie in ganz normaler Sprache chatten. Claude kann lesen, schreiben, Fragen beantworten und sogar Computercode für Sie schreiben. Mit dieser Anleitung sprechen Sie zum ersten Mal mit Claude – ganz ohne Downloads oder Einrichtung.

## Wichtige Konzepte

- **Anthropic** - Die Firma, die Claude entwickelt. Sie sitzt in San Francisco und hat sich zum Ziel gesetzt, KI hilfreich und sicher nutzbar zu machen
- **Claude** - Der KI-Assistent von Anthropic. Sie chatten mit ihm, indem Sie Nachrichten eintippen – ähnlich wie beim Schreiben von Textnachrichten mit einem sehr gut informierten Freund
- **Prompt** - Die Nachricht, die Sie an Claude schreiben. Je klarer Ihr Prompt, desto besser die Antwort von Claude
- **Modell** - Eine bestimmte Version von Claude (zum Beispiel eine für schnelle Antworten und eine für schwierigere Aufgaben). Sie müssen jetzt noch keine auswählen

## Was Sie benötigen

- Einen Computer oder ein Smartphone mit Webbrowser
- Eine E-Mail-Adresse
- 10 - 15 Minuten

## Schritt 1: Ein kostenloses Claude-Konto erstellen

- Gehen Sie zu [claude.ai](https://claude.ai)
- Klicken Sie auf **Sign up**
- Geben Sie Ihre E-Mail-Adresse ein und klicken Sie auf **Continue**
- Sehen Sie in Ihrem E-Mail-Postfach nach einem Bestätigungscode und geben Sie ihn ein
- Folgen Sie den Anweisungen auf dem Bildschirm, um Ihr Konto fertig zu erstellen

## Schritt 2: Ihre erste Nachricht senden

- Nach der Anmeldung sehen Sie ein Textfeld mit einem Hinweis wie „How can I help you today?“
- Klicken Sie in das Feld und tippen Sie:
   ```
   Erkläre mir, was ein Computerprogramm ist, so als wäre ich 10 Jahre alt.
   ```
- Klicken Sie auf den **Senden-Pfeil** (oder drücken Sie **Enter**)
- Lesen Sie die Antwort von Claude – sie sollte innerhalb weniger Sekunden erscheinen

## Schritt 3: Eine Anschlussfrage stellen

Claude merkt sich, worüber Sie in derselben Unterhaltung bereits gesprochen haben.

- Tippen Sie im selben Chat eine Anschlussfrage ein, zum Beispiel:
   ```
   Kannst du mir dafür ein Beispiel aus dem echten Leben geben?
   ```
- Beachten Sie, dass die Antwort von Claude auf Ihrer ersten Frage aufbaut, ohne dass Sie den Zusammenhang wiederholen müssen

## Schritt 4: Die Modellauswahl finden

- Suchen Sie oben im Chatfenster nach einer Schaltfläche, auf der ein Modellname steht (zum Beispiel „Claude“)
- Klicken Sie darauf, um eine kurze Liste der verfügbaren Modelle zu sehen
- Sie müssen hier nichts ändern – merken Sie sich nur, dass es dieses Menü gibt, denn in einigen späteren Tutorials werden Sie gebeten, ein bestimmtes Modell auszuwählen

## Nächste Schritte

- **Claude Code installieren**: Holen Sie sich denselben KI-Assistenten in Ihre Programmierprojekte – mit [Claude Code unter Windows installieren](Install_CLAUDE_Code_Win) oder [Claude Code auf dem Mac installieren](Install_Claude_Code_MacOS)
- **Weiter chatten**: Bitten Sie Claude, Ihnen bei der Planung von etwas zu helfen, an dem Sie gerade arbeiten – einer E-Mail, einem Rezept oder einer Lernübersicht
- **Einen schwierigeren Prompt ausprobieren**: Bitten Sie Claude, zwei Möglichkeiten für eine anstehende Entscheidung zu vergleichen, und sehen Sie, wie Claude seine Überlegungen erklärt

## Fehlerbehebung

- **Keine Bestätigungs-E-Mail erhalten** - Sehen Sie in Ihrem Spam- oder Junk-Ordner nach; warten Sie eine Minute und klicken Sie bei Bedarf auf **Resend code**
- **Seite lädt nicht oder sieht fehlerhaft aus** - Laden Sie die Seite neu oder probieren Sie einen anderen Browser wie Chrome oder Firefox
- **Sie wissen nicht, was Sie eintippen sollen** - Fangen Sie einfach an: Bitten Sie Claude, ein Thema zu erklären, das Sie interessiert, oder lassen Sie sich bei etwas helfen, das Sie heute ohnehin erledigen
