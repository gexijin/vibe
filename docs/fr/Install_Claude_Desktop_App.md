# Installer l'application Claude Desktop

Claude Desktop est une application de discussion autonome pour Windows et Mac. Vous l'ouvrez, vous tapez un message, et Claude vous répond — pas de terminal, pas de commandes à taper. C'est un excellent moyen de discuter avec Claude pour vos questions du quotidien, vos recherches ou vos écrits.

C'est différent de **Claude Code**, l'outil utilisé dans le reste de ces tutoriels. Claude Code vit dans un terminal et vous aide à écrire et modifier du code dans un dossier de projet. Claude Desktop est une fenêtre de discussion à usage général. Vous pouvez installer les deux, et même ouvrir Claude Code depuis Claude Desktop avec les abonnements payants.

## Concepts clés

- **Claude Desktop** : une application native pour Windows et Mac dans laquelle vous discutez directement avec Claude, comme dans une messagerie.
- **Compte Claude.ai** : le compte avec lequel vous vous connectez — le même que celui que vous utiliseriez sur [claude.ai](https://claude.ai). Les abonnements gratuits et payants fonctionnent tous les deux.
- **Claude Code** : l'assistant de programmation dans le terminal présenté dans les autres tutoriels de ce site. Il s'installe séparément — consultez [Installer Claude Code sur Windows](./Install_CLAUDE_Code_Win.md) ou [Installer Claude Code sur Mac](./Install_Claude_Code_MacOS.md).

## Ce dont vous aurez besoin

- Un ordinateur Windows 10 (ou plus récent) ou un Mac (macOS 11 Big Sur ou plus récent)
- Une connexion Internet
- Un compte Claude.ai gratuit ou payant (vous pouvez en créer un pendant l'installation si vous n'en avez pas)
- 5 minutes

## Étape 1 : Télécharger le programme d'installation

- Allez sur [claude.ai/download](https://claude.ai/download)
- **Windows :** cliquez sur **Download for Windows**. (Si vous avez un PC Windows à processeur ARM — c'est rare — utilisez plutôt le lien de téléchargement arm64 séparé sur la page.)
- **Mac :** cliquez sur **Download for macOS**. Ce téléchargement unique fonctionne à la fois sur les Mac Intel et Apple Silicon, vous n'avez donc pas besoin de savoir quelle puce équipe votre Mac.

## Étape 2 : Installer l'application

### Windows

- Ouvrez le fichier téléchargé (regardez dans votre dossier **Téléchargements** s'il ne s'ouvre pas automatiquement)
- Suivez les instructions affichées à l'écran par le programme d'installation
- Une fois l'installation terminée, trouvez **Claude** dans votre menu Démarrer

### Mac

- Ouvrez le fichier téléchargé
- Faites glisser l'icône **Claude** dans le dossier **Applications** lorsque cela vous est demandé
- Ouvrez **Claude** depuis votre dossier **Applications** ou depuis le Launchpad

## Étape 3 : Se connecter

- Lancez l'application Claude
- Connectez-vous avec votre compte Claude.ai en suivant les instructions à l'écran
- Vous n'avez pas de compte ? Allez d'abord sur [claude.ai](https://claude.ai) pour en créer un gratuitement, puis revenez vous connecter

## Étape 4 : Envoyer votre premier message

- Cliquez dans la zone de message
- Tapez par exemple : `Comment peux-tu m'aider ?`
- Appuyez sur **Entrée** pour envoyer
- Claude répondra directement dans la fenêtre de l'application

## Étape 5 : (Facultatif) Découvrir les autres possibilités de Claude Desktop

Claude Desktop ne sert pas qu'à discuter. Selon votre abonnement :

- **Chat** — disponible avec tous les abonnements, y compris Free (gratuit)
- **Claude Code** — les abonnements Pro, Max, Team et Enterprise peuvent lancer Claude Code depuis Claude Desktop, sans ouvrir de terminal séparé
- **Claude Cowork** — avec les abonnements payants, permet à Claude de travailler sur des tâches en plusieurs étapes avec accès à vos fichiers locaux
- **Desktop Extensions** — une fonctionnalité avancée qui connecte Claude à vos applications et fichiers locaux grâce à un répertoire d'extensions installables ; inutile pour démarrer

Vous n'avez besoin d'aucune de ces fonctionnalités pour utiliser Claude Desktop au quotidien — elles valent la peine d'être explorées une fois que vous serez à l'aise avec les bases.

## Dépannage

- **Windows bloque le programme d'installation avec le message « Windows a protégé votre ordinateur » (« Windows protected your PC »)** — C'est l'avertissement SmartScreen standard de Windows pour les nouveaux téléchargements ; il n'est pas propre à Claude. Cliquez sur **Informations complémentaires** (**More info**), puis sur **Exécuter quand même** (**Run anyway**), si vous faites confiance à la source (la page officielle claude.ai/download).
- **Le Mac indique que l'application « ne peut pas être ouverte car elle provient d'un développeur non identifié »** — C'est Gatekeeper, une vérification de sécurité standard de macOS. Faites un clic droit (ou Contrôle-clic) sur l'application Claude, choisissez **Ouvrir** (**Open**), puis confirmez.
- **La connexion ne fonctionne pas** — Vérifiez votre connexion Internet, et assurez-vous d'abord de pouvoir vous connecter sur [claude.ai](https://claude.ai) dans un navigateur.
- **L'application ne se lance pas après l'installation** — Redémarrez votre ordinateur, puis essayez à nouveau d'ouvrir Claude. Si cela ne suffit pas, téléchargez de nouveau le programme d'installation depuis [claude.ai/download](https://claude.ai/download).
