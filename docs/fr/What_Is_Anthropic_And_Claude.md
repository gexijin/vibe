# Qu'est-ce qu'Anthropic et Claude ?

Avant d'installer quoi que ce soit, il est utile de savoir ce que vous installez vraiment. **Claude** est un assistant d'intelligence artificielle (IA) créé par une entreprise appelée **Anthropic** — imaginez un assistant très compétent avec qui vous discutez en langage courant, et qui peut lire, écrire, répondre à des questions et même écrire du code informatique pour vous. Ce guide vous permet de parler à Claude pour la première fois, sans téléchargement ni installation.

## Concepts Clés

- **Anthropic** - L'entreprise qui crée Claude. Elle est basée à San Francisco et s'attache à rendre l'IA utile et sûre à utiliser
- **Claude** - L'assistant IA d'Anthropic. Vous discutez avec lui en tapant des messages, un peu comme si vous écriviez des textos à un ami très savant
- **Prompt** - Le message que vous tapez pour Claude. Plus votre prompt est clair, meilleure est la réponse de Claude
- **Modèle** - Une version précise de Claude (par exemple, une conçue pour les réponses rapides et une autre pour les problèmes plus difficiles). Vous n'avez pas encore besoin d'en choisir un

## Ce Dont Vous Aurez Besoin

- Un ordinateur ou un téléphone avec un navigateur web
- Une adresse e-mail
- 10 à 15 minutes

## Étape 1 : Créer un Compte Claude Gratuit

- Allez sur [claude.ai](https://claude.ai)
- Cliquez sur **Sign up**
- Tapez votre adresse e-mail et cliquez sur **Continue**
- Consultez vos e-mails pour trouver un code de vérification et saisissez-le
- Suivez les instructions à l'écran pour terminer la création de votre compte

## Étape 2 : Envoyer Votre Premier Message

- Une fois connecté, vous verrez une zone de texte qui affiche quelque chose comme « How can I help you today? »
- Cliquez dans la zone et tapez :
   ```
   Explique-moi ce qu'est un programme informatique, comme si j'avais 10 ans.
   ```
- Cliquez sur la **flèche d'envoi** (ou appuyez sur **Entrée**)
- Lisez la réponse de Claude — elle devrait apparaître en quelques secondes

## Étape 3 : Poser une Question de Suivi

Claude se souvient de ce dont vous avez déjà parlé dans la même conversation.

- Dans la même conversation, tapez une question de suivi, par exemple :
   ```
   Peux-tu me donner un exemple concret de la vie réelle ?
   ```
- Remarquez que la réponse de Claude s'appuie sur votre première question, sans que vous ayez à répéter le contexte

## Étape 4 : Trouver le Sélecteur de Modèle

- Regardez en haut de la fenêtre de conversation : vous y trouverez un bouton affichant le nom d'un modèle (par exemple, « Claude »)
- Cliquez dessus pour voir une courte liste des modèles disponibles
- Vous n'avez rien à changer ici — sachez simplement que ce menu existe, car certains tutoriels suivants vous demanderont de choisir un modèle précis

## Prochaines Étapes

- **Installer Claude Code** : Utilisez ce même assistant IA dans vos projets de code avec [Installer Claude Code sur Windows](Install_CLAUDE_Code_Win) ou [Installer Claude Code sur Mac](Install_Claude_Code_MacOS)
- **Continuer à discuter** : Demandez à Claude de vous aider à planifier quelque chose sur lequel vous travaillez déjà — un e-mail, une recette ou une fiche de révision
- **Essayer un prompt plus difficile** : Demandez à Claude de comparer deux options pour une décision que vous devez prendre, et voyez comment il explique son raisonnement

## Dépannage

- **Vous n'avez pas reçu l'e-mail de vérification** - Vérifiez votre dossier de spam ou de courrier indésirable ; attendez une minute et cliquez sur **Resend code** si nécessaire
- **La page ne se charge pas ou s'affiche mal** - Actualisez la page, ou essayez un autre navigateur comme Chrome ou Firefox
- **Vous ne savez pas quoi taper** - Commencez simplement : demandez à Claude d'expliquer un sujet qui vous intéresse, ou demandez de l'aide pour quelque chose que vous faites déjà aujourd'hui
