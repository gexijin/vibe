# Claude Code के साथ शोध पत्र लिखें

Claude Code को शोध, विचार-मंथन, योजना, प्रारूप तैयार करने और संपादन के लिए एक सहायक के रूप में उपयोग करते हुए शोध पत्र लिखें। फिर एक टेम्पलेट स्लैश कमांड (slash command) बनाकर इस प्रक्रिया को स्वचालित करें। इस वर्कफ़्लो का उपयोग करके बनाया गया एक [उदाहरण पत्र](./example_paper.md) देखें।

## मुख्य अवधारणाएँ

- **वर्कफ़्लो** - शोध → विचार-मंथन → केंद्रित शोध → रूपरेखा → प्रारूप → स्वयं संशोधन → AI से निखारना → सार जोड़ना → शीर्षक सुधारना → संदर्भ जाँचना → AI से प्रूफरीड
- **AI सहायक** - मनुष्य महत्वपूर्ण निर्णय लेता है जबकि AI थकाऊ काम करता है
- **Claude Code** - एक एजेंटिक AI सिस्टम जो वेब खोजता है, शोध व्यवस्थित करता है, और सरल अनुरोधों के ज़रिए सामग्री का प्रारूप तैयार करता है
- **स्लैश कमांड (slash command)** - एक अनुकूलित, विस्तृत प्रॉम्प्ट जिसे Claude Code में दोबारा उपयोग किया जा सकता है

## आपको क्या चाहिए

- पूरा किया हुआ [Windows पर VS Code में Claude Code](./Claude_Code_in_VS_Code_Win) या [Mac पर VS Code में Claude Code](./Claude_Code_in_VS_Code_Mac) ट्यूटोरियल
- 30-40 मिनट

## चरण 1: एक प्रोजेक्ट फ़ोल्डर बनाएँ

अपने शोध पत्र के लिए एक फ़ोल्डर बनाएँ:

- **File Explorer** (Windows) या **Finder** (Mac) खोलें
- **Documents** पर जाएँ
- `test_claude` नाम का एक नया फ़ोल्डर बनाएँ

इस प्रोजेक्ट से जुड़ा सब कुछ इसी फ़ोल्डर में होगा।

## चरण 2: VS Code शुरू करें
Windows के लिए:
- **Windows Start बटन** (स्क्रीन के निचले-बाएँ कोने में) पर क्लिक करें
- सर्च बॉक्स में `Visual Studio Code` या `VS Code` टाइप करें
- खोज परिणामों में दिखाई देने पर **Visual Studio Code** पर क्लिक करें
- VS Code एक Welcome टैब के साथ खुलेगा - आप इस टैब को बंद कर सकते हैं
- VS Code के निचले-बाएँ कोने को देखें - आपको एक नीला या हरा आइकन दिखाई देगा
- रिमोट कनेक्शन मेनू खोलने के लिए इस आइकन पर क्लिक करें
- मेनू से **Connect to WSL** चुनें
- VS Code रीलोड होकर आपकी Ubuntu इंस्टॉलेशन से जुड़ जाएगा
- अब निचले-बाएँ कोने में **WSL: Ubuntu** दिखना चाहिए

Mac के लिए:
- **Finder** खोलें और **Applications** पर जाएँ
- **Visual Studio Code** ढूँढें और उस पर डबल-क्लिक करें
- अगर आपको "Visual Studio Code is an app downloaded from the internet" चेतावनी दिखे, तो **Open** पर क्लिक करें
- VS Code एक Welcome टैब के साथ खुलेगा - आप इस टैब को बंद कर सकते हैं

## चरण 3: फ़ोल्डर को VS Code में खोलें
Windows के लिए (WSL के ज़रिए):
- VS Code में (जो अभी भी WSL से जुड़ा है), मेनू बार में **File**, फिर **Open Folder** पर क्लिक करें
- ऊपर बीच में एक **Open Folder** ड्रॉपडाउन दिखाई देगा।
- यह टाइप करके अपना फ़ोल्डर ढूँढें:
  ```
  /mnt/c/Users/YOUR_USERNAME/Documents/test_claude
  ```
  `YOUR_USERNAME` को अपने Windows यूज़रनेम से बदलें (जैसे, `John.Smith`)
- **OK** पर क्लिक करें। VS Code आपके `test_claude` फ़ोल्डर के साथ रीलोड होगा


Mac के लिए:
- VS Code में, मेनू बार में **File**, फिर **Open Folder** पर क्लिक करें
- `test_claude` फ़ोल्डर तक जाएँ और उसे चुनें
- **Open** (Mac) या **OK** (Windows) पर क्लिक करें
- अगर "Do you trust the authors?" पूछा जाए, तो **Yes, I trust the authors** पर क्लिक करें

## चरण 4: Claude Code शुरू करें

- एक टर्मिनल खोलें: VS Code के मुख्य मेनू में **Terminal**, फिर **New Terminal** पर क्लिक करें
- टर्मिनल पैनल में टाइप करें:
  ```
  claude
  ```

इंस्टॉलेशन ट्यूटोरियल ([Windows](Install_CLAUDE_Code_Win.md) | [Mac](Install_Claude_Code_MacOS.md)) के अनुसार अपनी Claude सब्सक्रिप्शन से लॉग इन करें। लॉग इन करने के बाद, आपको एक स्वागत संदेश और Claude Code प्रॉम्प्ट दिखाई देगा।

## चरण 5: शुरुआती शोध

Claude से अपने विषय पर शोध करने के लिए कहें। इस प्रॉम्प्ट को कॉपी करके Claude Code में पेस्ट करें, और विषय को अपने विषय से बदल दें:

```
मैं कार्यस्थल में AI अपनाए जाने पर लगभग 1,000 शब्दों का एक शोध पत्र लिख रहा/रही हूँ।
इन पर हाल के डेटा (2023-2025) खोजें:
- AI टूल्स से उत्पादकता में वृद्धि
- नौकरी छूटने की चिंताएँ और आँकड़े
- कंपनियों के वास्तविक जीवन के केस स्टडी

आवश्यकताएँ:
- पीयर-रिव्यूड शोध और विश्वसनीय उद्योग रिपोर्टों को प्राथमिकता दें
- किस्से-कहानियों और राय-आधारित लेखों से बचें
- हर स्रोत को 1-3 वाक्यों के सारांश के साथ सूचीबद्ध करें
- स्रोतों को विषय के अनुसार समूहित करें

general_research.md के रूप में सेव करें
```

Claude वेब खोजता है और निष्कर्षों को `general_research.md` नाम की फ़ाइल में व्यवस्थित करता है। इसमें एक या दो मिनट लग सकते हैं। पूरा होने पर, सारांश माँगें:

```
मुझे एक संक्षिप्त सारांश दें।
```

शोध के परिदृश्य की त्वरित समझ पाने के लिए Claude का सारांश समीक्षा करें।

## चरण 6: स्रोत पढ़ें
शोध दस्तावेज़ को पढ़ें और जानकारी की पुष्टि करने के लिए मूल स्रोतों पर क्लिक करके जाएँ:

1. बाईं ओर Explorer पैनल में `general_research.md` पर क्लिक करें
2. फ़ॉर्मेट किए गए दस्तावेज़ का पूर्वावलोकन करें: `general_research.md` टैब पर राइट-क्लिक करें और **Open Preview** चुनें
3. मूल लेख और अध्ययन पढ़ने के लिए स्रोत लिंक पर क्लिक करें

## चरण 7: अपना नज़रिया तय करने के लिए विचार-मंथन करें

Claude से विचार-मंथन में मदद माँगें:

```
इस शोध के आधार पर, मुझे इस पत्र के लिए 3-4 संभावित नज़रिए सुझाएँ।
```

नज़रियों की समीक्षा करें और जो आपको सबसे दिलचस्प लगे उसे चुनें।

## चरण 8: केंद्रित शोध

अब जब आपके पास अपना नज़रिया है, Claude से लक्षित शोध के लिए कहें:

```
मैं [आपका चुना हुआ नज़रिया] पर ध्यान केंद्रित करना चाहता/चाहती हूँ। इस दृष्टिकोण का समर्थन
करने वाले अधिक विशिष्ट डेटा और उदाहरण खोजें। focused_research.md के रूप में सेव करें
```

Claude लक्षित जानकारी ढूँढता है।

## चरण 9: अपनी योजना बनाएँ

Claude से आपके चुने हुए नज़रिए के आधार पर एक रूपरेखा बनाने के लिए कहें:

```
केंद्रित शोध और मेरे चुने हुए नज़रिए के आधार पर मेरे पत्र के लिए एक संक्षिप्त
रूपरेखा के 3 विकल्प दें। कथा-प्रवाह के लिए बुलेट पॉइंट का उपयोग करें।
outlines.md के रूप में सेव करें
```

रूपरेखा की समीक्षा करें और ज़रूरत पड़ने पर Claude से बदलाव करने को कहें (जैसे, "सेक्शन 2 को केस स्टडी पर अधिक केंद्रित करें" या "सीमाओं पर एक सेक्शन जोड़ें")।

## चरण 10: पत्र का प्रारूप तैयार करें

अपनी रूपरेखा चुनें और Claude से पूरा प्रारूप लिखने के लिए कहें:

```
मुझे रूपरेखा #2 [आपका चुना हुआ विकल्प] पसंद है।

रूपरेखा और शोध के आधार पर लगभग 1,000 शब्दों का शोध पत्र लिखें।

संरचना:
- परिचय: आकर्षक शुरुआत, संदर्भ, थीसिस स्टेटमेंट
- मुख्य भाग: तर्कों, आँकड़ों और उदाहरणों के साथ 2-3 सेक्शन
- निष्कर्ष: सारांश और निहितार्थ

शैली:
- स्पष्ट, संक्षिप्त वाक्य (औसतन 15-20 शब्द)
- सक्रिय स्वर, विश्लेषणात्मक लहजा
- आँकड़ों को गद्य में पिरोया जाए (बुलेट सूची नहीं)
- पैराग्राफ के बीच सहज बदलाव

उद्धरण:
- दावों के बाद क्रमांकित संदर्भ [1], [2], आदि का उपयोग करें
- 5-15 संदर्भ शामिल करें
- अंत में एक संदर्भ सेक्शन जोड़ें

paper.md के रूप में सेव करें
```

Claude प्रारूप लिखता है।

## चरण 11: स्वयं संशोधन करें

अपने टेक्स्ट एडिटर में `paper.md` खोलें। ध्यान से पढ़ें और अपने खुद के संशोधन करें:
- अपनी व्यक्तिगत आवाज़ और अंतर्दृष्टि जोड़ें
- तर्कों को अपनी सोच के अनुसार समायोजित करें
- किसी भी अटपटे वाक्यांश को ठीक करें
- सुनिश्चित करें कि उद्धरण सटीक हैं

एडिटर में अपने बदलाव सेव करें।

## चरण 12: AI से निखारें

Claude से विशिष्ट सेक्शन सुधारने के लिए कहें:

```
परिचय को एक आकर्षक शुरुआत के साथ और दिलचस्प बनाएँ।
```

## चरण 13: एक सार (Abstract) जोड़ें

Claude से शुरुआत में एक छोटा कार्यकारी सारांश जोड़ने के लिए कहें:

```
पत्र की शुरुआत में एक सार जोड़ें। पत्र का सारांश देने वाले 2-3 छोटे
वाक्य लिखें।
```

Claude सार जोड़ देगा। इसकी समीक्षा और संपादन करें ताकि यह सुनिश्चित हो सके कि यह आपके पत्र के सार को सही ढंग से दर्शाता है।

## चरण 14: शीर्षक सुधारें

Claude से शीर्षक के लिए कुछ विकल्प देने को कहें:

```
मुझे शीर्षक के लिए कुछ विकल्प दें। इसे और आकर्षक बनाएँ।
```

एक शीर्षक चुनें। अपना खुद का स्पर्श जोड़ें:

```
मुझे विकल्प #2 [आपकी पसंद] पसंद है। फ़ाइल को संपादित करें।
```

## चरण 15: संदर्भ जाँचें (वैकल्पिक)
Claude से आपके उद्धरणों की स्थिरता और पूर्णता सत्यापित करने के लिए कहें:
```
मेरे पत्र में सभी संदर्भ जाँचें:
- सत्यापित करें कि हर उद्धरण संख्या [1], [2], आदि का एक मिलता-जुलता संदर्भ है
- सत्यापित करें कि सूची में हर संदर्भ वास्तव में पत्र में उद्धृत है
- जाँचें कि लेखक के नाम और शीर्षक सुसंगत हैं
- सत्यापित करें कि उद्धृत डेटा और उदाहरण स्रोत में मौजूद हैं
```

नोट: Claude केवल सार्वजनिक रूप से सुलभ स्रोतों को सत्यापित कर सकता है। पेवॉल वाले लेखों के लिए, स्वयं जाँच लें कि आपके उद्धरण उससे मेल खाते हैं जो आपने पढ़ा।

## चरण 16: AI से प्रूफरीड करें

Claude से अंतिम प्रूफरीड करने के लिए कहें:

```
पत्र का अंतिम प्रूफरीड करें:
- वर्तनी और व्याकरण की किसी भी त्रुटि को ठीक करें
- पूरे दस्तावेज़ में एक जैसी फ़ॉर्मेटिंग सुनिश्चित करें
- प्रवाह और बदलावों की जाँच करें
```

Claude के बदलावों की समीक्षा करें।

**Word में एक्सपोर्ट करें:** VS Code में, `paper.md` टैब पर राइट-क्लिक करें और **Open Preview** चुनें। पूर्वावलोकन पैनल के अंदर क्लिक करें, फिर **Edit > Select All** और **Edit > Copy** पर क्लिक करें। Microsoft Word में पेस्ट करें - फ़ॉर्मेटिंग बरकरार रहेगी।

## चरण 17: भविष्य के पत्रों के लिए एक स्लैश कमांड बनाएँ

अपने अगले शोध पत्र के लिए इस वर्कफ़्लो को एक पुनः उपयोग योग्य स्लैश कमांड के रूप में सेव करें:

```
/research-paper नाम का एक स्लैश कमांड बनाएँ जो मुझे इस पूरे वर्कफ़्लो
से गुज़ारे। इसे इस तरह सेव करें कि मैं इसे भविष्य में विभिन्न विषयों पर शोध पत्रों के लिए इस्तेमाल कर सकूँ।
```

Claude आपके `.claude/commands/` फ़ोल्डर में एक कस्टम स्लैश कमांड बनाएगा। यह एक प्रॉम्प्ट वाली Markdown फ़ाइल है। आप बस `/research-paper [आपका विषय]` टाइप करके अपना अगला शोध पत्र शुरू कर सकते हैं!

## चरण 18: फीडबैक लें

LLM की कोई याददाश्त नहीं होती। हर जवाब के लिए, हमें चैट सेशन की सभी पिछली बातचीत को संदर्भ के रूप में भेजना पड़ता है। जैसे-जैसे बातचीत लंबी होती जाती है, हमें संदर्भ की लंबाई का ध्यान रखना ज़रूरी हो जाता है। अगर यह असंबंधित है, या हम एक साफ़ संदर्भ दे सकते हैं, तो हमें एक नई शुरुआत से फ़ायदा होगा।

अपने पत्र पर फीडबैक पाने के लिए Claude की याददाश्त मिटाएँ। टाइप करें:

```
/clear
```

इससे पूरा बातचीत इतिहास हट जाता है, इसलिए Claude आपके पत्र को नई नज़र से पढ़ेगा। अब फीडबैक माँगें:

```
paper.md पढ़ें और मुझे ईमानदार फीडबैक दें।
```

Claude आपके पत्र की समीक्षा करेगा, बिना इस बात से प्रभावित हुए कि उसने इसे लिखा था। फीडबैक के आधार पर अंतिम संशोधन करें।


## पूरा वर्कफ़्लो

1. **फ़ोल्डर बनाएँ** - Documents में अपना प्रोजेक्ट फ़ोल्डर सेट अप करें
2. **VS Code में खोलें** - फ़ोल्डर को VS Code में खोलें
3. **Claude Code शुरू करें** - टर्मिनल से Claude Code लॉन्च करें
4. **शोध** - Claude आपके विषय पर सामान्य जानकारी खोजता है
5. **स्रोत पढ़ें** - अपने टेक्स्ट एडिटर में शोध की समीक्षा करें
6. **विचार-मंथन** - अपना नज़रिया/दृष्टिकोण चुनें
7. **केंद्रित शोध** - Claude आपके चुने हुए नज़रिए के लिए लक्षित डेटा ढूँढता है
8. **योजना** - Claude आपके दृष्टिकोण के आधार पर रूपरेखा के विकल्प बनाता है
9. **प्रारूप** - Claude संदर्भों सहित पूरा पत्र लिखता है
10. **स्वयं संशोधन** - आप अपनी आवाज़ जोड़ते हैं और बदलाव करते हैं
11. **AI से निखारना** - Claude विशिष्ट सेक्शन सुधारता है
12. **सार जोड़ना** - Claude कार्यकारी सारांश बनाता है
13. **शीर्षक सुधारना** - Claude शीर्षक के विकल्प सुझाता है, आप उसे अनुकूलित करते हैं
14. **संदर्भ जाँचना** - (वैकल्पिक) Claude सभी उद्धरण सत्यापित करता है
15. **AI से प्रूफरीड** - Claude त्रुटियाँ ठीक करता है और प्रवाह सुधारता है
16. **स्लैश कमांड बनाना** - भविष्य के पत्रों के लिए वर्कफ़्लो सेव करना
17. **ताज़ा फीडबैक लेना** - निष्पक्ष समीक्षा के लिए याददाश्त मिटाना

## अगले कदम

अब जब आपके पास `/research-paper` स्लैश कमांड है, और पत्र लिखकर देखें:

- **तकनीक:** `/research-paper "किशोरों के मानसिक स्वास्थ्य पर सोशल मीडिया का प्रभाव"`
- **व्यवसाय:** `/research-paper "रिमोट वर्क उत्पादकता"`
- **विज्ञान:** `/research-paper "CRISPR जीन एडिटिंग की नैतिकता"`
- **फ़ॉर्मेट:** Claude से कहें `मुझे पत्र LaTeX फ़ॉर्मेट में दें`

स्लैश कमांड आपको पूरे वर्कफ़्लो से अपने आप गुज़ार देगा! विषय बदलते समय याददाश्त मिटाना न भूलें।

## समस्या निवारण

- **Claude के खोज परिणाम पुराने लग रहे हैं:** यह बताएँ "[विषय] पर 2024-2025 के डेटा के लिए खोजें"
- **प्रारूप बहुत लंबा/छोटा है:** Claude से कहें: "इसे लगभग 1,000 शब्दों का बनाएँ"
- **फ़ाइलें नहीं मिल रहीं:** टर्मिनल में, वर्तमान फ़ोल्डर की सभी फ़ाइलें सूचीबद्ध करने के लिए `ls` टाइप करें

## आप Claude से क्या पूछ सकते हैं

- `[विषय] पर हाल के आँकड़े खोजें` - नया डेटा ढूँढें
- `इस पत्र के मुख्य तर्कों का सारांश दें` - एक सिंहावलोकन पाएँ
- `निष्कर्ष को और अधिक प्रेरक बनाएँ` - विशिष्ट सेक्शन सुधारें
- `सभी स्रोतों को APA फ़ॉर्मेट में उद्धृत करें` - संदर्भ फ़ॉर्मेट करें
