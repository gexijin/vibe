# Mac पर VS Code में R के लिए Claude Code का उपयोग करें

आपने VS Code में R सेट कर लिया है और मैन्युअल रूप से कोड लिख सकते हैं। अब आप चाहते हैं कि AI आपके R कोड को लिखने, सुधारने और डीबग करने में मदद करे, जबकि आप विश्लेषण पर ध्यान केंद्रित करें। Claude Code को एक कोडिंग पार्टनर समझें जो VS Code के अंदर रहता है - आप बताते हैं कि आपको क्या चाहिए, और यह उसी विंडो में रहते हुए कोड लिखता या सुधारता है।

## मुख्य अवधारणाएँ

- **[Claude Code Extension](https://marketplace.visualstudio.com/items?itemName=anthropic.claude-code)** - VS Code एक्सटेंशन जो Claude AI असिस्टेंट को इनलाइन कोड एडिट के साथ सीधे आपके एडिटर में लाता है
- **चैट पैनल (Chat Panel)** - VS Code में साइड पैनल जहाँ आप अपने कोड के बारे में Claude से बातचीत करते हैं
- **इनलाइन एडिट (Inline Edits)** - Claude के सुझाए गए कोड बदलाव सीधे आपकी फ़ाइलों में डिफ़ के साथ दिखते हैं, जिन्हें आप स्वीकार या अस्वीकार कर सकते हैं

## आपको क्या चाहिए

- [VS Code में R](./R_Coding_VS_Code_Guide) ट्यूटोरियल पूरा किया हो - R को VS Code में काम करना चाहिए
- [Mac पर Claude Code इंस्टॉल करना](./Install_Claude_Code_MacOS) ट्यूटोरियल पूरा किया हो - Claude Code CLI इंस्टॉल होना चाहिए
- Claude Pro/Max सब्सक्रिप्शन या Anthropic API key
- 20-30 मिनट

## चरण 1: VS Code खोलें और R प्रोजेक्ट बनाएँ

- **Visual Studio Code** खोलें
- मेनू बार में **File** पर क्लिक करें, फिर **Open Folder**
- अपने **Documents** फ़ोल्डर पर जाएँ
- डायलॉग के नीचे **New Folder** पर क्लिक करें
- फ़ोल्डर का नाम `claude_r_test` रखें
- नया फ़ोल्डर खोलने के लिए **Open** पर क्लिक करें
- अगर "Do you trust the authors?" पूछा जाए, तो **Yes, I trust the authors** पर क्लिक करें

## चरण 2: Claude Code एक्सटेंशन इंस्टॉल करें और साइन इन करें

- बाईं साइडबार में **Extensions** आइकन पर क्लिक करें (चार चौकोर आकृतियों वाला आइकन)
- सर्च बॉक्स में `Claude Code` टाइप करें
- Anthropic द्वारा बनाया गया **Claude Code** खोजें और **Install** पर क्लिक करें
- इंस्टॉलेशन के बाद, बाईं साइडबार में एक Claude आइकन (स्पार्कल) दिखाई देगा
- चैट पैनल खोलने के लिए Claude आइकन पर क्लिक करें
- चैट पैनल में **Sign in to Claude Code** पर क्लिक करें
- अपनी ऑथेंटिकेशन विधि चुनें:
  - **Claude Pro/Max उपयोगकर्ता**: **Sign in with Claude.ai** पर क्लिक करें, ब्राउज़र में अनुमति दें, और कोड को वापस VS Code में कॉपी करें
  - **API key उपयोगकर्ता**: **Use API Key** पर क्लिक करें और अपनी Anthropic API key पेस्ट करें
- विस्तृत ऑथेंटिकेशन चरणों के लिए, [Mac पर Claude Code इंस्टॉल करना](./Install_Claude_Code_MacOS) गाइड (चरण 5) देखें
- साइन इन करने के बाद, चैट पैनल में "Ready to help" दिखेगा

## चरण 3: प्रारंभिक R स्क्रिप्ट मैन्युअल रूप से बनाएँ

- मेनू बार में **File > New File** पर क्लिक करें
- **Select a language** पर क्लिक करें और `R` टाइप करें, फिर **R** चुनें
- **File > Save** पर क्लिक करके फ़ाइल सेव करें, इसका नाम `iris_analysis.R` रखें
- यह कोड टाइप करें:

```r
data(iris)
str(iris)
summary(iris)
```

- **File > Save** पर क्लिक करके फ़ाइल सेव करें
- R टर्मिनल खोलें: मेनू बार में **View** पर क्लिक करें, फिर **Command Palette**, `R: Create R Terminal` टाइप करें, Enter दबाएँ
- कोड चुनें और उसे चलाने के लिए `Ctrl+Enter` (Windows/Linux) या `Cmd+Enter` (Mac) दबाएँ
- आपको टर्मिनल में डेटासेट की संरचना और सारांश आँकड़े दिखेंगे

## चरण 4: Claude से स्कैटर प्लॉट जोड़ने के लिए कहें

- चैट पैनल खोलने के लिए बाईं साइडबार में **Claude** आइकन पर क्लिक करें
- नीचे चैट बॉक्स में टाइप करें:

```
iris_analysis.R में sepal length बनाम width का एक स्कैटर प्लॉट बनाने के लिए कोड जोड़ें, जिसे species के अनुसार रंगा गया हो। ggplot2 का उपयोग करें।
```

- भेजने के लिए Enter दबाएँ
- Claude आपकी फ़ाइल पढ़ता है और बदलावों का सुझाव देता है - आपको जोड़े जाने वाले नए कोड को दिखाने वाला एक डिफ़ दिखेगा
- बदलाव लागू करने के लिए **Accept** पर क्लिक करें
- ggplot2 कोड आपकी फ़ाइल में दिखाई देगा
- अगर आपके पास ggplot2 इंस्टॉल नहीं है, तो R टर्मिनल में `install.packages("ggplot2")` चलाएँ

## चरण 5: अपडेट किया गया कोड चलाएँ

- `iris_analysis.R` में सारा कोड चुनें
- `Ctrl+Enter` (Windows/Linux) या `Cmd+Enter` (Mac) दबाएँ
- एक अलग ग्राफ़िक्स विंडो में स्कैटर प्लॉट दिखाई देता है
- आपको species (setosa, versicolor, virginica) के अनुसार रंगे गए बिंदु दिखने चाहिए

## चरण 6: Claude से प्लॉट सुधारने के लिए कहें

- Claude चैट पैनल में टाइप करें:

```
टाइटल हटाएँ। species के अनुसार मार्कर टाइप बदलें। classic थीम में बदलें।
```

- Enter दबाएँ
- Claude अपडेट किए गए कोड बदलाव दिखाता है
- **Accept** पर क्लिक करें
- अपडेट किया गया कोड फिर से चलाएँ: सारा कोड चुनें और `Ctrl+Enter` / `Cmd+Enter` दबाएँ
- अब प्लॉट में हर species के लिए अलग मार्कर आकार, बिना टाइटल के, और classic थीम दिखता है

## चरण 7: Claude से PCA विश्लेषण के लिए कहें

- Claude चैट पैनल में टाइप करें:

```
संख्यात्मक वेरिएबल्स पर PCA करने और पहले दो प्रिंसिपल कंपोनेंट्स का उपयोग करके सैंपल्स को प्लॉट करने के लिए कोड जोड़ें।
```

- Enter दबाएँ
- Claude आपकी स्क्रिप्ट में PCA कोड जोड़ता है
- **Accept** पर क्लिक करें
- सारा कोड चलाएँ: सब कुछ चुनें और `Ctrl+Enter` / `Cmd+Enter` दबाएँ
- एक PCA प्लॉट दिखाई देता है जो PC1 और PC2 पर प्रोजेक्ट किए गए सैंपल्स को species के अनुसार रंगकर दिखाता है

## चरण 8: Claude से समीक्षा और टिप्पणी के लिए कहें

- Claude चैट पैनल में टाइप करें:

```
सटीकता के लिए पूरी स्क्रिप्ट की समीक्षा करें। जहाँ ज़रूरी हो वहाँ टिप्पणियाँ (comments) जोड़ें।
```

- Enter दबाएँ
- Claude कोड की समीक्षा करता है और हर सेक्शन को समझाने वाली टिप्पणियों का सुझाव देता है
- **Accept** पर क्लिक करें
- अब आपकी स्क्रिप्ट में डेटा लोडिंग, विज़ुअलाइज़ेशन और PCA विश्लेषण को समझाने वाली स्पष्ट टिप्पणियाँ हैं

## अगले कदम

- Claude से R Markdown रिपोर्ट बनाने के लिए कहें: "इस विश्लेषण के लिए एक R Markdown फ़ाइल बनाएँ"
- एरर डीबग करने के लिए Claude का उपयोग करें: "यह कोड Error X दे रहा है, क्या आप इसे ठीक कर सकते हैं?"
- सांख्यिकीय परीक्षणों का अनुरोध करें: "setosa और versicolor के बीच sepal length की तुलना करने वाला एक t-test जोड़ें"
- Claude से कोड ऑप्टिमाइज़ करने के लिए कहें: "वेक्टराइज़ेशन का उपयोग करके इस लूप को तेज़ बनाएँ"
- अपरिचित फ़ंक्शन के साथ मदद लें: "समझाएँ कि dplyr::mutate क्या करता है"

## समस्या निवारण

- **Claude एक्सटेंशन नहीं दिख रहा** - इंस्टॉलेशन के बाद VS Code को रीस्टार्ट करें। यह सत्यापित करने के लिए **View > Extensions** पर क्लिक करें कि यह इंस्टॉल है।
- **"Cannot read R file" एरर** - सुनिश्चित करें कि आपने फ़ाइल को `.R` एक्सटेंशन के साथ सेव किया है। Claude को फ़ाइलें पढ़ने के लिए उनका सेव होना ज़रूरी है।
- **ऑथेंटिकेशन विफल** - जाँचें कि आपका Claude Pro/Max सब्सक्रिप्शन सक्रिय है या आपकी API key मान्य है। ऑथेंटिकेशन समस्या निवारण के लिए [Mac पर Claude Code इंस्टॉल करना](./Install_Claude_Code_MacOS) देखें।
- **ggplot2 नहीं मिला** - इसे R टर्मिनल में इंस्टॉल करें: `install.packages("ggplot2")`। कोड चलाने से पहले इंस्टॉलेशन पूरा होने की प्रतीक्षा करें।
- **कोड बदलाव लागू नहीं हो रहे** - सुनिश्चित करें कि आपने डिफ़ पर **Accept** पर क्लिक किया है। अगर यह काम नहीं कर रहा, तो Claude के सुझाए गए कोड को मैन्युअल रूप से कॉपी करने की कोशिश करें।

## वर्कफ़्लो सारांश

- **Claude Code Extension** चैट पैनल और इनलाइन डिफ़ के साथ सीधे VS Code में एक AI असिस्टेंट प्रदान करता है
- **पुनरावृत्त सुधार** - बुनियादी कोड से शुरू करें, Claude से सुधार के लिए कहें, तुरंत परीक्षण करें, फिर और सुधारें
- **संदर्भ जागरूकता** - Claude आपकी R फ़ाइलें पढ़ता है और आपके प्रोजेक्ट की संरचना को समझता है
- **इनलाइन एडिटिंग** - सुझाए गए बदलाव आपकी असली फ़ाइलों में डिफ़ के रूप में दिखते हैं, अलग चैट जवाबों में नहीं
- **फ़्लो में बने रहें** - ब्राउज़र और एडिटर के बीच स्विच करने की ज़रूरत नहीं - सब कुछ VS Code में होता है
