# Claude Code के साथ Excel में बजट ट्रैकर की Vibe Coding

Vibe coding अपने कंप्यूटर के साथ बातचीत करने जैसा है - आप नतीजा बताते हैं, Claude Code उसे बनाता है, आप टेस्ट करके सुधारते हैं। यह कोई जादू नहीं है; यह काम करने का एक नया तरीका है जहाँ आप दिशा तय करते हैं और AI स्प्रेडशीट का तकनीकी काम संभालता है: फ़ॉर्मूला, फ़ॉर्मेटिंग और चार्ट। यह ट्यूटोरियल आपको दिखाता है कि सिर्फ़ सादी भाषा में अनुरोध करके कई शीट वाला एक असली बजट ट्रैकर कैसे बनाएँ।

## मुख्य अवधारणाएँ

- **[Claude Code](https://code.claude.com/)** - AI कोडिंग असिस्टेंट जो आपके सादी भाषा के अनुरोधों के आधार पर फ़ाइलें लिखता, बदलता और ठीक करता है
- **कई शीट वाली वर्कबुक** - एक ही `.xlsx` फ़ाइल जिसमें कई टैब (Income, Expenses, Summary) होते हैं, जो फ़ॉर्मूला के ज़रिए एक-दूसरे से जुड़े रहते हैं
- **इटरेटिव सुधार** - vibe coding का मुख्य पैटर्न: बताएँ → टेस्ट करें → सुधारें → काम करने वाले वर्शन को कमिट करें

## आपको क्या चाहिए

- पूरा किया हुआ [VS Code में Excel के साथ Claude Code का उपयोग करें](./Excel_Coding_VS_Code_Guide)
- पूरा किया हुआ [Claude Code के साथ GitHub Desktop का उपयोग करें](./GitHub_Desktop_Claude_Code_Workflow)
- चार्ट, रंग और ड्रॉपडाउन देखने के लिए Microsoft Excel, [LibreOffice Calc](https://www.libreoffice.org/download/download-libreoffice/) (मुफ़्त), या Google Sheets (आपके वेब ब्राउज़र में मुफ़्त)
- 25-30 मिनट

## चरण 1: नई GitHub रिपॉज़िटरी बनाएँ

- GitHub Desktop खोलें
- **File > New Repository** पर क्लिक करें
- विवरण भरें:
  - **Name:** `budget-dashboard`
  - **Description:** `Personal budget tracker built with vibe coding`
  - **Local Path:** एक स्थान चुनें (जैसे, Documents या work फ़ोल्डर)
  - **Initialize this repository with a README** को चेक करें
- **Create Repository** पर क्लिक करें
- ऊपर **Publish repository** पर क्लिक करें
- अगर आप इसे पब्लिक बनाना चाहते हैं तो **Keep this code private** को अनचेक करें (वैकल्पिक)
- **Publish Repository** पर क्लिक करें

अब आपके पास एक लोकल Git रिपॉज़िटरी और GitHub पर एक बैकअप है।

## चरण 2: प्रोजेक्ट को VS Code में खोलें

- VS Code खोलें
- **File > Open Folder** पर क्लिक करें
- अपना `budget-dashboard` फ़ोल्डर चुनें
- **Select Folder** (Windows) या **Open** (Mac) पर क्लिक करें
- अगर आपने अभी तक नहीं किया है, तो MESCIUS का **Spreadsheet Viewer** एक्सटेंशन (पहले का नाम GrapeCity का **Excel Viewer**) इंस्टॉल करें, ताकि आप VS Code छोड़े बिना स्प्रेडशीट देख सकें। सही एक्सटेंशन पाने के लिए Extensions पैनल में उसका ID, `GrapeCity.gc-excelviewer`, खोजें
- Spreadsheet Viewer नंबर और फ़ॉर्मूला जाँचने के लिए बढ़िया है, लेकिन यह चार्ट, रंगीन हाइलाइटिंग या ड्रॉपडाउन सूचियाँ नहीं दिखा सकता - उनके लिए आप Excel, LibreOffice Calc या Google Sheets का उपयोग करेंगे

## चरण 3: Claude Code शुरू करें

- **Terminal > New Terminal** पर क्लिक करें
- Claude Code शुरू करने के लिए यह कमांड टाइप करें:

```bash
claude
```

- पूछे जाने पर लॉग इन करें, फिर Claude के स्वागत संदेश की प्रतीक्षा करें

Claude Code अब चल रहा है और आपके अनुरोधों के लिए तैयार है।

## चरण 4: पहला Vibe - Income और Expenses शीट बनाएँ

स्प्रेडशीट को एक-एक सेल करके बनाने के बजाय, बस बताएँ कि आपको क्या चाहिए।

- Claude Code टर्मिनल में, टाइप करें:

```
budget.xlsx नाम की एक स्प्रेडशीट बनाएँ जिसमें दो शीट हों: "Income" और "Expenses"। Income शीट में Source, Month और Amount कॉलम हों, और 2 महीनों के लिए आमदनी के 3 उदाहरण स्रोत हों। Expenses शीट में Category, Month और Amount कॉलम हों, और उन्हीं 2 महीनों के लिए 6 उदाहरण कैटेगरी हों (जैसे Rent, Groceries, Transportation, Utilities, Entertainment, Phone)। हर शीट के सबसे नीचे SUM फ़ॉर्मूला से एक Total पंक्ति जोड़ें। सभी रकम US डॉलर ($) में रखें।
```

- Enter दबाएँ
- देखें कि Claude एक Python स्क्रिप्ट लिखकर चलाता है जो वर्कबुक बनाती है
- अगर Claude कमांड चलाने या मददगार टूल इंस्टॉल करने की अनुमति माँगे, तो **Yes** चुनें
- Spreadsheet Viewer टैब में `budget.xlsx` खोलें और दोनों शीट पर क्लिक करके देखें

**अपना काम सेव करें:** Claude से Git का उपयोग करके कमिट करने को कहें, या इसे खुद GitHub Desktop से करें:
```
इन बदलावों को कमिट करें।
```

## चरण 5: दूसरा Vibe - एक Summary शीट जोड़ें

चार्ट बनाने से पहले, दोनों शीट को आपस में जोड़ें।

- Claude Code टर्मिनल में, टाइप करें:

```
budget.xlsx में "Summary" नाम की एक तीसरी शीट जोड़ें। इसमें Total Income, Total Expenses और Net Savings (Income में से Expenses घटाकर) दिखें, और हर एक की गणना ऐसे फ़ॉर्मूला से हो जो Income और Expenses शीट से जुड़े हों - सीधे टाइप किए गए नंबर नहीं। उसके नीचे एक छोटी टेबल जोड़ें जो हर महीने की Income और Expenses दिखाए, वह भी फ़ॉर्मूला से।
```

- Enter दबाएँ
- Claude वर्कबुक अपडेट करता है
- **Summary** टैब खोलें और Net Savings सेल पर क्लिक करके पक्का करें कि यह एक फ़ॉर्मूला है जो दूसरी शीट से जुड़ा है

**अपना काम सेव करें:** Claude से कमिट करने को कहें, या GitHub Desktop का उपयोग करें।

## चरण 6: तीसरा Vibe - चार्ट जोड़ें

नंबर काम के होते हैं, लेकिन चार्ट एक नज़र में पूरी बात बता देते हैं।

- Claude Code टर्मिनल में, टाइप करें:

```
Expenses शीट में एक पाई चार्ट जोड़ें जो कुल खर्च में हर कैटेगरी का हिस्सा दिखाए। Summary शीट में एक बार चार्ट जोड़ें जो हर महीने के लिए Total Income और Total Expenses की तुलना करे।
```

- Enter दबाएँ
- Claude दोनों चार्ट जोड़ता है
- उन्हें देखने के लिए, `budget.xlsx` को Excel या LibreOffice Calc में खोलें (File Explorer या Finder में उस पर डबल-क्लिक करें), या उसे Google Sheets में अपलोड करें, और दोनों शीट जाँचें
- VS Code का Spreadsheet Viewer चार्ट नहीं दिखाएगा - यह सामान्य है, चार्ट फ़ाइल में मौजूद हैं
- Claude से और बदलाव माँगने से पहले Excel या LibreOffice में फ़ाइल बंद कर दें

## चरण 7: चौथा Vibe - बजट से ज़्यादा खर्च वाली कैटेगरी को हाइलाइट करें

नंबरों में खोजने के बजाय, समस्याओं को एक नज़र में दिखने लायक बनाएँ।

- Claude Code टर्मिनल में, टाइप करें:

```
Expenses शीट में conditional formatting जोड़ें, ताकि किसी एक महीने में $500 से ज़्यादा का कोई भी खर्च लाल रंग में हाइलाइट हो, और $100 से कम का कोई भी खर्च हरे रंग में हाइलाइट हो। Total पंक्ति में रंग न लगाएँ।
```

- Enter दबाएँ
- फ़ाइल को Excel, LibreOffice Calc या Google Sheets में खोलें और Expenses शीट जाँचें - अब सेल अपनी वैल्यू के हिसाब से रंगीन दिखने चाहिए (Spreadsheet Viewer ये रंग नहीं दिखाता)

अगर कुछ ठीक न दिखे, तो जो आप देख रहे हैं उसे कॉपी करें और Claude को बताकर ठीक करने को कहें।

## चरण 8: पाँचवाँ Vibe - कैटेगरी ड्रॉपडाउन जोड़ें

शीट को ऐसा बनाएँ कि उसमें बिना टाइपिंग की गलती के नई चीज़ें जोड़ी जा सकें।

- Claude Code टर्मिनल में, टाइप करें:

```
Expenses शीट के Category कॉलम में data validation जोड़ें, ताकि वह सिर्फ़ एक ड्रॉपडाउन सूची की वैल्यू ही ले, जिसमें मौजूदा कैटेगरी और "Other" हों। नई एंट्री के लिए सबसे नीचे दो खाली पंक्तियाँ जोड़ें।
```

- Enter दबाएँ
- फ़ाइल को Excel, LibreOffice Calc या Google Sheets में खोलें, किसी खाली Category सेल में क्लिक करें, और पक्का करें कि आपकी कैटेगरी सूची के साथ एक ड्रॉपडाउन तीर दिखता है (Spreadsheet Viewer ड्रॉपडाउन नहीं दिखाता)
- काम हो जाने पर फ़ाइल बंद कर दें

## चरण 9: समीक्षा करें और कमिट करें

कमिट करने से पहले, देखें कि Claude ने क्या बनाया।

- Spreadsheet Viewer में तीनों शीट - Income, Expenses, Summary - पर क्लिक करके देखें
- आपको हर फ़ॉर्मूला समझने की ज़रूरत नहीं, बस संरचना का अंदाज़ा लगाएँ
- GitHub Desktop खोलें
- आपको `budget.xlsx` बदली हुई फ़ाइल के रूप में दिखेगी
- नीचे बाईं ओर **Summary** फ़ील्ड में, टाइप करें:

```
बजट ट्रैकर में चार्ट, conditional formatting और कैटेगरी ड्रॉपडाउन जोड़े
```

- **Commit to main** पर क्लिक करें
- GitHub पर बैकअप लेने के लिए **Push origin** पर क्लिक करें

आपने अपने बजट ट्रैकर का पूरा, काम करने वाला वर्शन सेव कर लिया है!

## चरण 10: सुधारें और बेहतर बनाएँ

Vibe coding तब चमकता है जब आप सुधार करते जाते हैं। नई सुविधाओं का वर्णन करके उन्हें जोड़ने की कोशिश करें:

**Claude से किए जाने वाले उदाहरण अनुरोध:**

- "Summary शीट में एक Savings Goal पंक्ति जोड़ें, जो $500/महीने के बचत लक्ष्य की ओर प्रगति दिखाए"
- "एक चौथी शीट जोड़ें जो ज़्यादा महीनों का डेटा जोड़ने पर साल-दर-साल तुलना दिखाए"
- "पाई चार्ट के रंग नीले और स्लेटी थीम में बदलें"
- "हर फ़ॉर्मूला को समझाने वाला एक नोट जोड़ें ताकि मैं सीख सकूँ कि वे क्या करते हैं"
- "चार लोगों के परिवार के लिए ज़्यादा कैटेगरी वाली household_budget.xlsx नाम की एक दूसरी वर्कबुक बनाएँ"

हर सफल सुविधा के बाद:
- फ़ाइल खोलकर जाँचें - नंबरों के लिए Spreadsheet Viewer, या चार्ट और रंगों के लिए Excel/LibreOffice का उपयोग करें
- अगर यह काम करता है, तो GitHub Desktop से कमिट करें
- अगर कुछ गलत दिखे, तो Claude को बताएँ और ठीक करने को कहें
- ठीक होने के बाद, काम करने वाले वर्शन को कमिट करें

**मुख्य सिद्धांत:**

- **नतीजे बताएँ, तरीका नहीं** - "$500 से ज़्यादा के खर्च हाइलाइट करें" कहें, "CellIsRule के साथ conditional formatting का उपयोग करें" नहीं
- **तेज़ी से सुधार करें** - टेस्ट → सुधारें → टेस्ट → सुधारें
- **काम करने वाले वर्शन कमिट करें** - नई सुविधाएँ आज़माने से पहले हर सफलता को सेव करें
- **असफलताओं को स्वीकार करें** - अगर कोई फ़ॉर्मूला या चार्ट सही न बने, तो बस समस्या बताएँ और Claude से उसे ठीक करने को कहें
- **नियंत्रण अपने पास रखें** - ट्रैकर में क्या दिखना चाहिए और वह कब काफ़ी अच्छा है, यह आप तय करते हैं

हर बार, इस पैटर्न का पालन करें: बताएँ → फ़ाइल जाँचें → सुधारें → कमिट करें।

## अगले कदम

- **अपने खुद के पैसों के हिसाब पर लागू करें** - Claude से अपनी असली आमदनी और खर्च की कैटेगरी के हिसाब से ट्रैकर दोबारा बनाने को कहें
- **असली डेटा जोड़ें** - बैंक स्टेटमेंट की CSV फ़ाइल अपने प्रोजेक्ट फ़ोल्डर में डालें और Claude से उसे ट्रैकर में जोड़ने को कहें
- **पूछकर सीखें** - जब Claude कोई फ़ॉर्मूला लिखे, तो Excel सीखने के लिए पूछें "समझाएँ कि यह फ़ॉर्मूला क्या करता है"
- **अपना ट्रैकर शेयर करें** - तैयार फ़ाइल को GitHub पर push करें ताकि आप (या परिवार के लोग) सबसे नया वर्शन ले सकें
- **vibe coding के बारे में पढ़ें** - इस कोडिंग शैली के बारे में और जानने के लिए [IBM की गाइड](https://www.ibm.com/think/topics/vibe-coding) देखें

## समस्या निवारण

- **फ़ॉर्मूला वाले सेल में खाली या `None` दिखता है** - बदलाव के बाद फ़ाइल का दोबारा हिसाब लगाना ज़रूरी है। Claude से कहें: "budget.xlsx का दोबारा हिसाब लगाएँ और पक्का करें कि किसी फ़ॉर्मूला में त्रुटि नहीं है।"
- **चार्ट नहीं दिख रहा** - Spreadsheet Viewer चार्ट नहीं दिखा सकता। फ़ाइल को Excel, LibreOffice Calc या Google Sheets में खोलें। अगर वहाँ भी चार्ट न हो, तो Claude को समस्या बताएँ और चार्ट फिर से जोड़ने को कहें।
- **Claude गलती करता है** - सामान्य बात है! जो गलत दिखे उसे बताएँ और Claude से ठीक करने को कहें। Vibe coding में सुधार और डिबगिंग शामिल है।
- **GitHub पर push नहीं हो पा रहा** - पक्का करें कि आप GitHub Desktop में लॉग इन हैं और रिपॉज़िटरी पब्लिश की है (चरण 1)। अपना इंटरनेट कनेक्शन जाँचें।
- **ड्रॉपडाउन सूची नहीं दिख रही** - Data validation सिर्फ़ असली स्प्रेडशीट ऐप (Excel, LibreOffice, Google Sheets) में दिखता है, हल्के प्रीव्यू टूल में हमेशा नहीं। इसे टेस्ट करने के लिए फ़ाइल को Excel या LibreOffice Calc में खोलें।

## वर्कफ़्लो का अवलोकन

इस ट्यूटोरियल ने कई टूल को एक वर्कफ़्लो में जोड़ा:

- **GitHub Desktop** - दिखने वाले इंटरफ़ेस के साथ वर्शन कंट्रोल (रिपॉज़िटरी बनाना, कमिट, push)
- **VS Code** - जल्दी प्रीव्यू के लिए Spreadsheet Viewer एक्सटेंशन वाला एडिटर
- **Claude Code** - AI असिस्टेंट जो आपके बताए अनुसार असली `.xlsx` फ़ाइलें बनाता और बदलता है
- **openpyxl (पर्दे के पीछे)** - वह इंजन जिससे Claude फ़ाइल में फ़ॉर्मूला, फ़ॉर्मेटिंग और चार्ट लिखता है

असली जादू किसी एक टूल में नहीं है - यह इसमें है कि vibe coding से आप जो चाहते हैं वह बता सकते हैं और तेज़ी से सुधार कर सकते हैं। आप एक खाली फ़ोल्डर से चार्ट वाले एक काम करने वाले बजट ट्रैकर तक पहुँच गए, बिना हाथ से एक भी फ़ॉर्मूला लिखे।

## रोज़ का वर्कफ़्लो

इस शुरुआती सेटअप के बाद, आपका रोज़ का vibe coding रूटीन यह बन जाता है:

1. **VS Code खोलें** - अपना प्रोजेक्ट फ़ोल्डर खोलें
2. **Claude Code शुरू करें** - टर्मिनल में `claude` टाइप करें
3. **अपना लक्ष्य बताएँ** - "एक सुविधा जोड़ें जो..." या "उस पंक्ति को ठीक करें जहाँ..."
4. **फ़ाइल जाँचें** - उसे Spreadsheet Viewer में या Excel/LibreOffice में खोलें
5. **सुधारें या कमिट करें** - अगर कुछ गड़बड़ है, तो सुधार बताएँ; अगर काम करता है, तो GitHub Desktop से कमिट करें
6. **नियमित रूप से push करें** - GitHub पर बैकअप लेने के लिए **Push origin** पर क्लिक करें

जितना ज़्यादा आप अभ्यास करेंगे, उतना बेहतर आप बता पाएँगे कि आपको क्या चाहिए। Vibe coding एक हुनर है - आप सीखते हैं कि किस तरह का वर्णन सबसे अच्छा काम करता है और स्प्रेडशीट के बड़े विचारों को टेस्ट किए जा सकने वाले छोटे हिस्सों में कैसे बाँटें।
