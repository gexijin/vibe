# Claude Code: बुनियादी संचालन

AI की मदद से कोडिंग सीखना शुरुआत में भारी लग सकता है। Claude Code को अपने बगल में बैठे एक जानकार सहकर्मी की तरह सोचें—आप सामान्य भाषा में बताते हैं कि आपको क्या चाहिए, और यह आपको वहाँ तक पहुँचने में मदद करता है। यह ट्यूटोरियल आपको वे ज़रूरी संचालन सिखाता है जिनका आप रोज़ाना उपयोग करेंगे, बातचीत शुरू करने से लेकर अपने वर्कस्पेस को प्रबंधित करने तक।

## मुख्य अवधारणाएँ

- **वर्कस्पेस (Workspace)** - वह फ़ोल्डर जहाँ से आप Claude Code शुरू करते हैं; Claude उस सत्र के लिए उसके अंदर की फ़ाइलें पढ़ता और संपादित करता है
- **REPL (Read-Eval-Print Loop)** - एक इंटरैक्टिव सत्र जहाँ आप कमांड टाइप करते हैं, Claude जवाब देता है, और बातचीत तब तक जारी रहती है जब तक आप बाहर नहीं निकलते
- **कॉन्टेक्स्ट (Context)** - कोड और बातचीत के इतिहास की वह मात्रा जिसे Claude याद रखता है; जैसे एक कार्यशील मेमोरी जो समय के साथ भरती जाती है
- **स्लैश कमांड (Slash Commands)** - `/` से शुरू होने वाले बिल्ट-इन शॉर्टकट जो इतिहास साफ़ करने या मदद दिखाने जैसे विशिष्ट काम करते हैं

## आपको क्या चाहिए

- [Windows](Install_CLAUDE_Code_Win.md) या [Mac](Install_Claude_Code_MacOS.md) ट्यूटोरियल से इंस्टॉल किया गया Claude Code
- यदि आप Windows का उपयोग कर रहे हैं तो WSL इंस्टॉल किया हुआ
- टर्मिनल या कमांड प्रॉम्प्ट के उपयोग की बुनियादी जानकारी
- 15-20 मिनट

## चरण 1: अपना टर्मिनल खोलें

- **Windows**: Windows की दबाएँ, `Ubuntu` टाइप करें, और WSL टर्मिनल खोलने के लिए Enter दबाएँ
- **Mac**: `Cmd+Space` दबाएँ, `Terminal` टाइप करें, और Enter दबाएँ

एक टेक्स्ट विंडो खुलेगी जहाँ आप कमांड टाइप कर सकते हैं।

## चरण 2: डेमो प्रोजेक्ट फ़ाइलें प्राप्त करें

हम Claude Code की सुविधाओं को जानने के लिए एक असली डेटा साइंस प्रोजेक्ट का उपयोग करेंगे। आप इसे Git से क्लोन कर सकते हैं या सीधे डाउनलोड कर सकते हैं।

**विकल्प A: Git से क्लोन करें (यदि आपके पास Git इंस्टॉल है):**

```
git clone https://github.com/gexijin/data_projects
cd data_projects
```

**विकल्प B: बिना Git के डाउनलोड करें:**

- अपने वेब ब्राउज़र में [https://github.com/gexijin/data_projects](https://github.com/gexijin/data_projects) पर जाएँ
- ऊपर दाईं ओर हरे रंग के **Code** बटन पर क्लिक करें
- **Download ZIP** पर क्लिक करें
- ZIP फ़ाइल को Downloads फ़ोल्डर के अंदर **data_projects** नामक फ़ोल्डर में एक्सट्रैक्ट करें।
- अपने टर्मिनल में, एक्सट्रैक्ट किए गए फ़ोल्डर पर जाएँ:
  - **Windows**: `cd /mnt/c/Users/YourName/Downloads/data_projects`
  - **Mac/Linux**: `cd ~/Downloads/data_projects`

`YourName` को अपने असली यूज़रनेम से बदलें और यदि आपने इसे कहीं और एक्सट्रैक्ट किया है तो पथ को उसी अनुसार समायोजित करें। Windows उपयोगकर्ताओं के लिए, आपकी Windows फ़ाइलें Linux सिस्टम में /mnt/c से एक्सेस की जाती हैं।

## चरण 3: फ़ोल्डर से Claude Code शुरू करें

अपने टर्मिनल में (सुनिश्चित करें कि आप data_projects फ़ोल्डर के अंदर हैं), टाइप करें:

```bash
claude
```

इंस्टॉलेशन ट्यूटोरियल ([Windows](Install_CLAUDE_Code_Win.md) | [Mac](Install_Claude_Code_MacOS.md)) के अनुसार अपने Claude सब्सक्रिप्शन से लॉग इन करें। लॉग इन करने के बाद, आपको एक स्वागत संदेश और Claude Code प्रॉम्प्ट दिखाई देगा।

## चरण 4: अपने प्रोजेक्ट के बारे में सवाल पूछें

Claude Code ज़रूरत पड़ने पर आपकी फ़ाइलें अपने आप पढ़ लेता है। अपने प्रोजेक्ट को समझने के लिए ये सवाल आज़माएँ:

**फ़ोल्डर संरचना के बारे में पूछें:**

```
इस प्रोजेक्ट की फ़ोल्डर संरचना क्या है?
```

**तकनीकों के बारे में पूछें:**

```
यह प्रोजेक्ट कौन-सी तकनीकों और लाइब्रेरी का उपयोग करता है?
```

**हाल के बदलावों के बारे में पूछें:**

```
इस प्रोजेक्ट में सबसे आखिरी बदलाव क्या किया गया था?
```

Claude Git इतिहास (यदि उपलब्ध हो) की जाँच करेगा और आपको हाल के कमिट के बारे में बताएगा।

आप Claude से अपने कोड के बारे में सामान्य भाषा में कुछ भी पूछ सकते हैं। यह आपके सवालों के जवाब देने के लिए ज़रूरत के मुताबिक फ़ाइलें पढ़ता है।

## चरण 5: ज़रूरी स्लैश कमांड

सभी उपलब्ध कमांड देखने के लिए `/` टाइप करें और Enter दबाएँ। यहाँ सबसे महत्वपूर्ण कमांड दिए गए हैं:

**सभी कमांड देखें:**

```
/
```

यह सभी स्लैश कमांड का एक मेनू दिखाता है। ब्राउज़ करने के लिए ऐरो कीज़ का उपयोग करें, चुनने के लिए Enter दबाएँ, या रद्द करने के लिए Esc दबाएँ।

**मदद पाएँ:**

```
/help
```
Claude Code के उपयोग से जुड़ा दस्तावेज़ीकरण दिखाता है।



**कॉन्टेक्स्ट का उपयोग जाँचें:**
कॉन्टेक्स्ट, यानी Claude की "कार्यशील मेमोरी", को प्रबंधित करना ज़रूरी है।

```
/context
```

**बातचीत का इतिहास साफ़ करें:**

जब कॉन्टेक्स्ट भर जाए, तो `/clear` से नई बातचीत शुरू करें।
```
/clear
```
मौजूदा बातचीत को मिटाकर नए सिरे से शुरू करता है। इसका उपयोग तब करें जब आप विषय बदलना चाहते हों या जब आपकी बातचीत बहुत लंबी हो जाए। कॉन्टेक्स्ट प्रबंधित करना ज़रूरी है।


**Claude Code से बाहर निकलें:**

```
/exit
```

आपके सत्र को समाप्त करता है और आपको सामान्य टर्मिनल प्रॉम्प्ट पर वापस ले जाता है। आप **Ctrl + C** को दो बार दबाकर भी बाहर निकल सकते हैं।

## चरण 6: बदलावों को स्वीकृति दें और शॉर्टकट का उपयोग करें

जब Claude किसी फ़ाइल में बदलाव करना या कोई कमांड चलाना चाहता है, तो यह **हाँ** (Yes) और **नहीं** (No) जैसे विकल्पों वाला एक छोटा मेनू दिखाता है। अपनी पसंद को हाइलाइट करने के लिए ऐरो कीज़ का उपयोग करें और **Enter** दबाएँ।

Claude Code के साथ काम को तेज़ बनाने के लिए कुछ कीबोर्ड शॉर्टकट भी हैं:

- **Shift+Tab** - मोड्स के बीच बदलें (Manual, Accept Edits, Plan) - Claude द्वारा कोई बदलाव करने से पहले किसी जटिल काम की समीक्षा करने के लिए Plan मोड उपयोगी है
- **Ctrl+C** - मौजूदा ऑपरेशन या Claude की प्रतिक्रिया रद्द करें
- **Esc** - Claude को बीच में रोकें, या कोई मेनू बंद करें
- **`\` फिर Enter** (या **Ctrl+J**) - अपने संदेश को भेजे बिना उसमें एक नई लाइन जोड़ें

## चरण 7: हमेशा एक CLAUDE.md फ़ाइल बनाएँ

CLAUDE.md फ़ाइल आपके प्रोजेक्ट की Claude के लिए निर्देश-पुस्तिका है। यह सत्रों के बीच बनी रहती है, इसलिए Claude आपके प्रोजेक्ट के बारे में महत्वपूर्ण जानकारी याद रखता है।

**फ़ाइल बनाएँ:**

```
/init
```

Claude आपके प्रोजेक्ट के सारांश के साथ यह फ़ाइल बनाएगा। यह फ़ाइल आपके प्रोजेक्ट रूट में रहती है और Claude हर बार नया सत्र शुरू करने पर इसे अपने आप पढ़ता है।

आप कभी भी प्रोजेक्ट फ़ोल्डर में CLAUDE.md को संपादित करके प्रोजेक्ट-विशिष्ट निर्देश, कोडिंग परंपराएँ, या फ़ाइलों के उद्देश्य जैसी महत्वपूर्ण जानकारी जोड़ सकते हैं।

## चरण 8: फ़ाइलों या कोड की लाइनों का संदर्भ देना

आप किसी खास फ़ाइल का संदर्भ देने के लिए `@` का उपयोग कर सकते हैं:

```
@Visualization/Matplotlib/Nested_Pie_Chart.ipynb में मौजूद कोड को समझाएँ
```

Claude नोटबुक को पढ़ेगा और बताएगा कि यह क्या करता है, कैसे काम करता है, और कोड क्या हासिल करता है। इससे फ़ाइल असरदार तरीके से कॉन्टेक्स्ट में आ जाती है।

यदि आप VS Code से Claude Code के साथ काम कर रहे हैं और आपके पास Claude Code एक्सटेंशन इंस्टॉल है, तो आप बस फ़ाइल को खोलकर उसे कॉन्टेक्स्ट में जोड़ सकते हैं। आपको कमांड विंडो के नीचे दाईं ओर `In Nested_Pie_Chart.ipynb` लिखा दिखेगा। तब Claude को पता चल जाता है कि आप इसी फ़ाइल की बात कर रहे हैं।

इसके अलावा, आप कोड की कुछ लाइनें चुन सकते हैं और Claude **3 lines selected** दिखाएगा। आप Claude से इन लाइनों में जल्दी बदलाव करने या सवाल पूछने के लिए कह सकते हैं। इसलिए, मैं VS Code से Claude Code का उपयोग करने की ज़ोरदार सलाह देता हूँ।


## चरण 9: Linux कमांड से काम करें

Claude कई तरह से Linux कमांड चलाकर काम कर सकता है।

- सॉफ़्टवेयर इंस्टॉल करें
  ```
  pandas लाइब्रेरी इंस्टॉल करें
  ```

- वर्ज़न कंट्रोल शुरू करें
  ```
  Git का उपयोग करके बदलावों को ट्रैक करना शुरू करें। मेरा नाम James Bond है और मेरा ईमेल bond@earth.com है
  ```
- बदलाव कमिट करें
  ```
  इन बदलावों को कमिट करें।
  ```
- डेटा खोजें और डाउनलोड करें
  ```
  UCI से wine quality dataset डाउनलोड करें। इसे wine नाम के एक नए फ़ोल्डर में रखें।
  ```

- कोड चलाएँ
  ```
  नेस्टेड पाई चार्ट कोड को एक सामान्य Python स्क्रिप्ट के रूप में फिर से लिखें।
  इसे चलाएँ और नए कोड व प्लॉट्स को उसी फ़ोल्डर में सेव करें।
  ```

Claude सॉफ़्टवेयर इंस्टॉल करता है, त्रुटियों का निवारण करता है, और वातावरण (environments) को प्रबंधित करता है—यह सब अपने-आप।



आपके पास अनिवार्य रूप से Linux bash कमांड का एक विशेषज्ञ उपलब्ध है। जब तक आप अनुमतियाँ प्रबंधित करते हैं और कार्यों को स्वीकृति देते हैं, आप बहुत उत्पादक बन सकते हैं।

## अगले कदम

अब जब आप बुनियादी बातें जान गए हैं, तो इन्हें खुद आज़माएँ:

- Claude से प्रोजेक्ट के फ़ोल्डरों में से किसी एक में मौजूद मशीन लर्निंग एल्गोरिदम को समझाने के लिए कहें
- किसी मौजूदा नोटबुक में बदलाव का अनुरोध करें (जैसे चार्ट के रंग बदलना या नई सुविधाएँ जोड़ना)
- प्रोजेक्ट के डेटा का उपयोग करने वाली एक नई Python स्क्रिप्ट बनाएँ
- Claude से कोडबेस में दो अलग-अलग तरीकों की तुलना करने के लिए कहें

## समस्या निवारण

- **"Command not found" त्रुटि** - Claude Code इंस्टॉल नहीं है या आपके PATH में नहीं है। [Windows](Install_CLAUDE_Code_Win.md) या [Mac](Install_Claude_Code_MacOS.md) इंस्टॉलेशन ट्यूटोरियल को दोबारा फॉलो करें, या इंस्टॉलर को सीधे फिर से चलाएँ: `irm https://claude.ai/install.ps1 | iex` (Windows PowerShell) या `curl -fsSL https://claude.ai/install.sh | bash` (Mac/WSL)।
- **Claude पुरानी जानकारी देता है** - `/clear` से कॉन्टेक्स्ट साफ़ करें और फिर से पूछें। लंबी बातचीत Claude की मेमोरी को भर सकती है।
- **फ़ाइल में बदलाव काम नहीं कर रहे** - सुनिश्चित करें कि आपके पास प्रोजेक्ट फ़ोल्डर में राइट परमिशन है। Claude फ़ाइलों में बदलाव करने से पहले स्वीकृति माँगेगा—दिखने वाले मेनू में से **हाँ** (Yes) चुनें।
- **कॉन्टेक्स्ट तेज़ी से भर रहा है** - उपयोग जाँचने के लिए `/context` का इस्तेमाल करें। जब यह लगभग भर जाए, तो साफ़ शुरुआत के साथ नई बातचीत शुरू करने के लिए `/clear` का उपयोग करें।

## वर्कफ़्लो का अवलोकन

Claude Code के साथ काम करना इस पैटर्न का पालन करता है:

- अपने प्रोजेक्ट फ़ोल्डर में `claude` से Claude शुरू करें
