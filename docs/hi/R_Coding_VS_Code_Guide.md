# VS Code में R चलाएँ

आप R कोड लिखना चाहते हैं लेकिन RStudio आपको भारी लगता है या आप VS Code का लचीलापन पसंद करते हैं। VS Code को एक स्विस आर्मी नाइफ़ की तरह सोचें - यह R, Python और कई अन्य भाषाओं को एक ही हल्के एडिटर में संभाल सकता है। यह ट्यूटोरियल आपको दिखाता है कि VS Code में R को कैसे सेट करें, साथ ही कोड कम्प्लीशन, इंटरैक्टिव प्लॉट और यहाँ तक कि Shiny ऐप्स जैसी स्मार्ट सुविधाओं के साथ।

## मुख्य अवधारणाएँ

- **[languageserver](https://github.com/REditorSupport/languageserver)** - R पैकेज जो VS Code में कोड कम्प्लीशन, सिंटैक्स जाँच और हॉवर डॉक्यूमेंटेशन को सक्षम करता है
- **[R Extension](https://marketplace.visualstudio.com/items?itemName=REditorSupport.r)** - VS Code एक्सटेंशन जो आपके एडिटर को R से जोड़ता है और सिंटैक्स हाइलाइटिंग, कोड एक्ज़ीक्यूशन और डिबगिंग प्रदान करता है
- **[Shiny Extension](https://marketplace.visualstudio.com/items?itemName=Posit.shiny)** - ऑटो-रीलोड के साथ इंटरैक्टिव Shiny वेब ऐप्स बनाने और चलाने के लिए VS Code एक्सटेंशन

## आपको क्या चाहिए

- पूरा किया हुआ [VS Code Basics](./VS_Code_Getting_Started)
- R और पैकेज डाउनलोड करने के लिए इंटरनेट कनेक्शन
- 10-15 मिनट

## चरण 1: R इंस्टॉल या अपडेट करें

सबसे अच्छी संगतता के लिए आपको R वर्शन 4.0 या उससे ऊपर की ज़रूरत है।

- **Windows**:
  - [CRAN Windows](https://cran.r-project.org/bin/windows/base/) से नवीनतम R डाउनलोड करें और इंस्टॉलर चलाएँ
  - इंस्टॉलेशन के दौरान, **इंस्टॉलेशन पाथ नोट कर लें** (उदाहरण के लिए: `C:\Program Files\R\R-4.5.3`)
  - अगर आपके पास पुराना वर्शन है, तो पहले उसे Settings > Apps से अनइंस्टॉल करें

- **macOS**:
  - [CRAN macOS](https://cran.r-project.org/bin/macosx/) से डाउनलोड करें और .pkg इंस्टॉलर चलाएँ
  - नोट करें कि आप Intel (`/Library/Frameworks/R.framework/Resources/bin/R`) उपयोग कर रहे हैं या Homebrew के साथ Apple Silicon (`/opt/homebrew/bin/R`)
  - अगर अपडेट कर रहे हैं, तो नया वर्शन पुराने की जगह ले लेगा

- **Linux**:
  - अपने पैकेज मैनेजर का उपयोग करें (जैसे, Ubuntu पर `sudo apt install r-base`)
  - या [CRAN Linux](https://cran.r-project.org/bin/linux/) के निर्देशों का पालन करें

आप चरण 3 में VS Code को R ढूँढने के लिए कॉन्फ़िगर करेंगे, इसलिए चिंता न करें अगर अभी आपके टर्मिनल में `R --version` काम नहीं करता।

## चरण 2: VS Code में R एक्सटेंशन इंस्टॉल करें

- VS Code खोलें
- बाईं साइडबार में **Extensions** आइकन पर क्लिक करें
- `REditorSupport.r` खोजें और REditorSupport के R एक्सटेंशन पर **Install** क्लिक करें
- `Posit.shiny` खोजें और Posit के Shiny एक्सटेंशन पर **Install** क्लिक करें

## चरण 3: अपना R इंस्टॉलेशन पाथ ढूँढें

VS Code कॉन्फ़िगर करने से पहले, आपको यह जानना होगा कि आपके सिस्टम पर R कहाँ इंस्टॉल है।

### Windows उपयोगकर्ताओं के लिए

1. **File Explorer** खोलें
2. `C:\Program Files\R\` पर जाएँ
3. आपको `R-4.5.3` जैसा एक फ़ोल्डर दिखेगा (आपका वर्शन नंबर अलग हो सकता है)
4. उस फ़ोल्डर को खोलें → `bin` फ़ोल्डर खोलें
5. वहाँ आपको `R.exe` दिखेगा
6. पूरा पाथ है: `C:\Program Files\R\R-4.5.3\bin\R.exe`

**अपना वर्शन नंबर लिख लें या याद रखें** (जैसे, `R-4.5.3`) - आपको इसकी ज़रूरत चरण 4 में होगी।

### macOS उपयोगकर्ताओं के लिए

आपका R इंस्टॉलेशन आमतौर पर इनमें से किसी एक जगह होता है:

- **मानक इंस्टॉलेशन (Intel या Apple Silicon)**: `/Library/Frameworks/R.framework/Resources/bin/R`
- **Apple Silicon पर Homebrew**: `/opt/homebrew/bin/R`
- **Intel पर Homebrew**: `/usr/local/bin/R`

यह जाँचने के लिए कि आपका कौन-सा पाथ है, **Terminal** खोलें और टाइप करें:
```bash
which R
```

इससे आपको आपके R इंस्टॉलेशन का सटीक पाथ दिखेगा।

### Linux उपयोगकर्ताओं के लिए

R आमतौर पर यहाँ इंस्टॉल होता है: `/usr/bin/R`

एक टर्मिनल खोलकर और टाइप करके सत्यापित करें:
```bash
which R
```

## चरण 4: VS Code को R ढूँढने के लिए कॉन्फ़िगर करें

- VS Code में, नीचे बाईं ओर **गियर आइकन** पर क्लिक करें
- मेनू से **Settings** चुनें
- ऊपर सर्च बार में, `r.rpath.windows` (Windows), `r.rpath.mac` (macOS), या `r.rpath.linux` (Linux) टाइप करें
- आपको सेटिंग दिखनी चाहिए। सेटिंग के नीचे **Edit in settings.json** पर क्लिक करें
- settings.json फ़ाइल खुल जाएगी
- कर्ली ब्रेसेज़ `{}` के अंदर अपने प्लेटफ़ॉर्म के लिए उपयुक्त कॉन्फ़िगरेशन जोड़ें

**Windows के लिए**, यह लाइन जोड़ें (चरण 3 से अपने वर्शन के साथ `R-4.5.3` बदलें):

```json
"r.rpath.windows": "C:\\Program Files\\R\\R-4.5.3\\bin\\R.exe",
```

**दो बैकस्लैश (`\\`) क्यों?** JSON फ़ाइलों में, बैकस्लैश `\` एक विशेष कैरेक्टर होता है (जिसे एस्केप कैरेक्टर कहते हैं)। असली फ़ाइल पाथ में एक सिंगल बैकस्लैश दिखाने के लिए, आपको दो बैकस्लैश `\\` टाइप करने होंगे। इसलिए `C:\Program Files`, settings.json में `C:\\Program Files` बन जाता है।

**macOS के लिए**, इनमें से एक लाइन जोड़ें:

```json
"r.rpath.mac": "/Library/Frameworks/R.framework/Resources/bin/R",
```

या अगर आपने Apple Silicon पर Homebrew के ज़रिए R इंस्टॉल किया है:

```json
"r.rpath.mac": "/opt/homebrew/bin/R",
```

**Linux के लिए**, यह जोड़ें:

```json
"r.rpath.linux": "/usr/bin/R",
```

- **File > Save** पर क्लिक करके फ़ाइल सेव करें
- बदलावों को लागू करने के लिए **VS Code को पूरी तरह से रीस्टार्ट करें**

## चरण 5: ज़रूरी R पैकेज इंस्टॉल करें

- VS Code में, ऊपर के मेनू में **View** पर क्लिक करें, फिर **Command Palette** चुनें
- `R: Create R Terminal` टाइप करें और उसे चुनें
- नीचे टर्मिनल पैनल में एक R कंसोल दिखेगा
  - आपको R वर्शन जानकारी के साथ शुरू होते हुए दिखना चाहिए
  - अगर कोई त्रुटि आती है, तो चरण 4 में अपने settings.json कॉन्फ़िगरेशन की दोबारा जाँच करें और VS Code को रीस्टार्ट करें
- ये कमांड एक-एक करके टाइप करके पैकेज इंस्टॉल करें:

```r
install.packages("languageserver")
install.packages("shiny")
```

- इंस्टॉलेशन पूरा होने का इंतज़ार करें (कुछ मिनट लग सकते हैं)
- `q()` टाइप करें और Enter दबाएँ ताकि R से बाहर निकल सकें
- वर्कस्पेस सेव करने के बारे में पूछे जाने पर `n` टाइप करें

एक सामान्य टर्मिनल में सिर्फ़ `R` टाइप करना तब तक काम नहीं करेगा जब तक R आपके सिस्टम PATH में न हो। R एक्सटेंशन R ढूँढने के लिए आपकी `r.rpath` सेटिंग का उपयोग करता है।

## चरण 6: अपना R प्रोजेक्ट बनाएँ

- ऊपर के मेनू में **File > New File** पर क्लिक करें
- **File > Save** पर क्लिक करके फ़ाइल को `analysis.R` के रूप में सेव करें

## चरण 7: अपनी पहली R स्क्रिप्ट लिखें

- `analysis.R` में यह कोड टाइप करें:

```r
# Load the iris dataset
data(iris)

# View the first few rows
head(iris)

# Generate summary statistics
summary(iris)

hist(iris$Sepal.Length)
```

- **File > Save** पर क्लिक करके फ़ाइल सेव करें

## चरण 8: R कोड को इंटरैक्टिव रूप से चलाएँ

- `analysis.R` खुला होने पर, कोड की एक लाइन चुनें और उसे चलाने के लिए `Ctrl+Enter` (Windows/Linux) या `Cmd+Enter` (Mac) दबाएँ
- अगर आपका कोई टर्मिनल खुला नहीं है, तो पहला `Ctrl+Enter` / `Cmd+Enter` एक R टर्मिनल खोलता है। दूसरा कोड चलाता है।
- देखें कि टर्मिनल में आउटपुट दिखता है और प्लॉट अलग विंडो में खुलता है
- आप सभी लाइनें चुनकर उन्हें उसी तरह चला भी सकते हैं।

## चरण 9: एक सरल Shiny ऐप बनाएँ

- अपने प्रोजेक्ट फ़ोल्डर में एक नई फ़ाइल बनाएँ: **File > New File**
- इसे `app.R` के रूप में सेव करें
- यह कोड टाइप करें:

```r
library(shiny)

ui <- fluidPage(
  titlePanel("Interactive Histogram"),

  sidebarLayout(
    sidebarPanel(
      sliderInput("bins",
                  "Number of bins:",
                  min = 5,
                  max = 50,
                  value = 30)
    ),

    mainPanel(
      plotOutput("histogram")
    )
  )
)

server <- function(input, output) {
  output$histogram <- renderPlot({
    x <- faithful$waiting
    bins <- seq(min(x), max(x), length.out = input$bins + 1)

    hist(x, breaks = bins, col = "steelblue", border = "white",
         xlab = "Waiting time (minutes)",
         main = "Distribution of Waiting Times")
  })
}

shinyApp(ui = ui, server = server)
```

- फ़ाइल सेव करें
- एडिटर के ऊपरी दाईं ओर दिखने वाले **▶** बटन पर ध्यान दें
- **Run Shiny App** चुनने के लिए ड्रॉपडाउन पर क्लिक करें
- ऐप ब्राउज़र या VS Code पैनल में खुलता है
- स्लाइडर हिलाएँ और देखें कि हिस्टोग्राम तुरंत अपडेट होता है

## चरण 10: कोड कम्प्लीशन और हॉवर हेल्प का उपयोग करें

- `analysis.R` में, एक नई लाइन पर `mea` टाइप करना शुरू करें
- सुझावों के साथ एक ड्रॉपडाउन दिखेगा - Enter दबाकर `mean()` चुनें
- अपने मौजूदा कोड में `mean` शब्द पर माउस ले जाएँ
- एक पॉपअप फ़ंक्शन डॉक्यूमेंटेशन और उपयोग के उदाहरण दिखाता है
- उनके डॉक्यूमेंटेशन देखने के लिए `lm`, `summary`, या `plot` पर माउस ले जाकर देखें
- `data$` टाइप करें और देखें कि VS Code कॉलम नाम (`x` और `y`) सुझाता है

## चरण 11: और सुविधाएँ आज़माएँ

- **Markdown एकीकरण**: कोड, आउटपुट और टेक्स्ट को मिलाने के लिए एक R Markdown फ़ाइल (`.Rmd`) बनाएँ
- **कोड फ़ॉर्मेटिंग**: अपनी R स्क्रिप्ट में राइट-क्लिक करें और कोड को ऑटो-फ़ॉर्मेट करने के लिए **Format Document** चुनें
- **डिबगिंग**: लाइन नंबरों के बाईं ओर क्लिक करके ब्रेकपॉइंट सेट करें, फिर डिबग मोड में कोड चलाएँ
- **Git एकीकरण**: अपने R प्रोजेक्ट को वर्शन कंट्रोल करने के लिए VS Code की बिल्ट-इन Git सुविधाओं का उपयोग करें

- अलग `ui.R` और `server.R` फ़ाइलों के साथ एक मल्टी-फ़ाइल Shiny ऐप बनाएँ
- उन्नत डेटा विज़ुअलाइज़ेशन के लिए [ggplot2](https://ggplot2.tidyverse.org/) एक्सप्लोर करें
- डेटा मैनिपुलेशन के लिए [tidyverse](https://www.tidyverse.org/) पैकेज (`dplyr`, `tidyr`) आज़माएँ
- एम्बेडेड R कोड के साथ रिपोर्ट बनाने के लिए R Markdown या [Quarto](https://quarto.org/) सीखें
- उन्नत डिबगिंग के लिए [R Debugger extension](https://marketplace.visualstudio.com/items?itemName=RDebugger.r-debugger) इंस्टॉल करें

## समस्या निवारण

- **VS Code टर्मिनल में "R is not recognized"**: VS Code को R नहीं मिल रहा है। अपना settings.json जाँचें (चरण 4) - सत्यापित करें कि R पाथ सही है और `R.exe` (Windows) या R बाइनरी (Mac/Linux) की ओर इशारा करता है। उदाहरण पाथ:
  - Windows: `C:\\Program Files\\R\\R-4.5.3\\bin\\R.exe` (वर्शन नंबर एडजस्ट करें)
  - macOS Intel: `/Library/Frameworks/R.framework/Resources/bin/R`
  - macOS Homebrew: `/opt/homebrew/bin/R`
  - Linux: `/usr/bin/R`
  ठीक करने के बाद, VS Code को पूरी तरह से रीस्टार्ट करें।

- **सेटिंग्स में R वर्शन मेल न खाना**: अगर आपने R अपडेट किया लेकिन VS Code अभी भी पुराना वर्शन उपयोग कर रहा है, तो अपने settings.json के `r.rpath` कॉन्फ़िगरेशन में वर्शन नंबर को नए R इंस्टॉलेशन से मिलाने के लिए अपडेट करें (अपना मौजूदा इंस्टॉलेशन पाथ ढूँढने के लिए चरण 3 देखें)।

- **कोड कम्प्लीशन काम नहीं कर रहा**: सुनिश्चित करें कि languageserver सफलतापूर्वक इंस्टॉल हुआ है (चरण 5)। इंस्टॉलेशन के बाद VS Code को रीस्टार्ट करें। भाषा सर्वर के शुरू होने के लिए R फ़ाइल खोलने के बाद 10-20 सेकंड इंतज़ार करें। त्रुटियों के लिए Output पैनल जाँचें (View > Output > R Language Server)।

- **प्लॉट नहीं दिख रहे**: प्लॉट R के डिफ़ॉल्ट ग्राफ़िक्स डिवाइस का उपयोग करते हुए अलग विंडो में खुलेंगे। सुनिश्चित करें कि आपके पास एक विंडो मैनेजर उपलब्ध है। कुछ सिस्टम पर, आपको X11 (macOS) इंस्टॉल करने या ग्राफ़िक्स सपोर्ट सक्षम होना सुनिश्चित करने की ज़रूरत हो सकती है।

- **Shiny ऐप नहीं चल रहा**: सुनिश्चित करें कि Shiny एक्सटेंशन इंस्टॉल है (चरण 2), shiny पैकेज इंस्टॉल है (चरण 5), और आपकी फ़ाइल का नाम `app.R` है। त्रुटि संदेशों के लिए टर्मिनल जाँचें। Run बटन तभी दिखता है जब VS Code फ़ाइल को Shiny ऐप के रूप में पहचानता है।

## वर्कफ़्लो सारांश

VS Code इन मुख्य फ़ायदों के साथ RStudio का एक आधुनिक, हल्का विकल्प प्रदान करता है:

- **एकीकृत एनवायरनमेंट**: एक ही एडिटर में R, Python, JavaScript और अधिक कोड करें
- **कस्टमाइज़ेबल**: एक हल्के सेटअप के लिए केवल वे एक्सटेंशन इंस्टॉल करें जिनकी आपको ज़रूरत है
- **एकीकृत टर्मिनल**: R, Git और शेल कमांड साथ-साथ चलाएँ
- **Shiny डेवलपमेंट**: ऑटो-रीलोड के साथ वन-क्लिक ऐप लॉन्चिंग समय बचाती है
- **वर्शन कंट्रोल**: बाहरी टूल के बिना बिल्ट-इन Git एकीकरण
