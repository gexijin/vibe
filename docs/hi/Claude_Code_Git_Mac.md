# Mac के लिए Claude Code के साथ स्थानीय वर्ज़न कंट्रोल

आप AI की मदद से कोडिंग कर रहे हैं। यह आपकी फ़ाइलों में बदलाव करता है। कभी-कभी ये बदलाव बिल्कुल सही काम करते हैं। कभी-कभी नहीं। **वर्ज़न कंट्रोल आपके पूरे प्रोजेक्ट के लिए एक अनडू बटन जैसा है।** हर बार जब आप एक स्नैपशॉट सेव करते हैं (जिसे "कमिट" कहा जाता है), तो आप एक ऐसा रीस्टोर पॉइंट बनाते हैं जिस पर आप हमेशा वापस लौट सकते हैं। सबसे अच्छी बात यह है कि आप यह सब पूरी तरह अपने कंप्यूटर पर ही कर सकते हैं, और Claude Code यह आपके लिए करता है।

## मुख्य अवधारणाएँ

- **टर्मिनल (Terminal)** - Mac का बिल्ट-इन कमांड-लाइन इंटरफ़ेस, जिससे कमांड चलाए जाते हैं
- **Git** - आपके कंप्यूटर पर आपकी फ़ाइलों में हर बदलाव को ट्रैक करता है, और ऐसे रीस्टोर पॉइंट बनाता है जिन पर आप कभी भी लौट सकते हैं
- **कमिट (Commit)** - किसी खास समय पर आपके प्रोजेक्ट का एक स्नैपशॉट, साथ में यह बताता हुआ विवरण कि क्या बदला
- **Claude Code** - AI कोडिंग सहायक जो कोड लिखता है, बग ठीक करता है, और सरल अनुरोधों के ज़रिए Git से जुड़े काम संभालता है

## आपको क्या चाहिए

- पूरा किया हुआ [Mac पर Claude Code इंस्टॉल करना](./Install_Claude_Code_MacOS)
- 30 मिनट

## चरण 1: टर्मिनल खोलें

इनमें से कोई एक तरीका चुनें:

- **Spotlight:** `Command (⌘) + Space` दबाएँ, `Terminal` टाइप करें, Enter दबाएँ
- **Finder:** **Applications** > **Utilities** > **Terminal** खोलें
- **Launchpad:** Dock में **Launchpad** पर क्लिक करें, `Terminal` खोजें

आपको `$` या `%` पर खत्म होने वाला एक कमांड प्रॉम्प्ट दिखेगा।

## चरण 2: Git इंस्टॉल करें

Mac पर अक्सर Git पहले से इंस्टॉल होता है। चलिए जाँचते हैं:

- यह कमांड टाइप करें और Enter दबाएँ:
  ```
  git --version
  ```

**यदि आपको कोई वर्ज़न नंबर दिखे** (जैसे `git version 2.39.0`), तो Git पहले से इंस्टॉल है—चरण 3 पर जाएँ।

**यदि आपको "command not found" दिखे** या डेवलपर टूल्स इंस्टॉल करने के लिए कोई पॉपअप दिखे:
- पॉपअप में **Install** पर क्लिक करें, या यह चलाएँ:
  ```
  xcode-select --install
  ```
- इंस्टॉलेशन पूरा होने तक इंतज़ार करें (1-5 मिनट)
- जाँचें कि Git इंस्टॉल हो गया है:
  ```
  git --version
  ```

आपको `git version 2.39.0` जैसा कुछ दिखना चाहिए।

## चरण 3: अपनी पहचान के साथ Git कॉन्फ़िगर करें

कमिट संदेशों के लिए Git को यह जानना ज़रूरी है कि आप कौन हैं।

- अपना नाम और ईमेल सेट करें (काल्पनिक भी चल सकता है):
  ```
  git config --global user.name "Your Name"
  git config --global user.email "your.email@example.com"
  ```

अपने नाम और ईमेल का उपयोग करने से यह पहचानना आसान हो जाता है कि जब कई लोग इस पर काम करते हैं तो बदलाव किसने किए।

## चरण 4: अपने Documents फ़ोल्डर पर जाएँ

- अपने Documents फ़ोल्डर पर जाएँ:
  ```
  cd ~/Documents
  ```
- जाँचें कि आप सही जगह पर हैं:
  ```
  pwd
  ```

आपको `/Users/YOUR_USERNAME/Documents` दिखना चाहिए।

## चरण 5: प्रोजेक्ट फ़ोल्डर बनाएँ

- `test_claude` नाम का एक फ़ोल्डर बनाएँ:
  ```
  mkdir test_claude
  ```
- उसके अंदर जाएँ:
  ```
  cd test_claude
  ```

आपका प्रोजेक्ट यहीं रहेगा।

## चरण 6: Claude Code शुरू करें

- Claude Code शुरू करें:
  ```
  claude
  ```

[इंस्टॉलेशन ट्यूटोरियल](Install_Claude_Code_MacOS.md) के अनुसार अपने Claude सब्सक्रिप्शन से लॉग इन करें। लॉग इन करने के बाद, आपको एक स्वागत संदेश और Claude Code प्रॉम्प्ट दिखाई देगा।

## चरण 7: Claude से Git शुरू करने के लिए कहें

- यह अनुरोध टाइप करें:
  ```
  बदलावों को ट्रैक करना शुरू करें
  ```

Claude आपके फ़ोल्डर में एक Git रिपॉज़िटरी शुरू करता है (2-5 सेकंड लगते हैं)। अब आपके पास वर्ज़न कंट्रोल है!

## चरण 8: टाइमर ऐप बनाएँ

- Claude Code में टाइप करें:
  ```
  timer.html नाम की एक ही फ़ाइल में एक साधारण काउंटडाउन टाइमर ऐप बनाएँ।
  इसमें होना चाहिए:
  - मिनट सेट करने के लिए एक इनपुट फ़ील्ड
  - Start और Stop बटन
  - MM:SS फ़ॉर्मैट में बचे हुए समय को दिखाने वाला डिस्प्ले
  ```

Claude CSS और JavaScript कोड के साथ `timer.html` बनाता है (10-30 सेकंड लगते हैं)।

## चरण 9: टाइमर टेस्ट करें

- Finder खोलें
- **Documents** > **test_claude** पर जाएँ
- `timer.html` को ब्राउज़र में खोलने के लिए उस पर डबल-क्लिक करें
- टाइमर आज़माएँ:
  - इनपुट फ़ील्ड में `1` टाइप करें
  - **Start** पर क्लिक करें
  - काउंटडाउन देखें

**अगर कुछ खराब हो जाए:** Claude Code में, त्रुटि का वर्णन करें: `मुझे यह त्रुटि दिख रही है: [जो हुआ उसका वर्णन करें]. क्या आप इसे ठीक कर सकते हैं?`

## चरण 10: Claude से कमिट करने के लिए कहें

- Claude Code में टाइप करें:
  ```
  ये बदलाव सेव करें।
  ```

Claude यह करेगा:
- जाँचेगा कि कौन-सी फ़ाइलें बदली हैं
- एक वर्णनात्मक कमिट संदेश लिखेगा
- कमिट बनाएगा (5-10 सेकंड लगते हैं)

आपने अपना पहला सेव पॉइंट बना लिया है! आप हमेशा इस काम करने वाली वर्ज़न पर वापस लौट सकते हैं।

## चरण 11: प्रीसेट बटन जोड़ें

- Claude Code में टाइप करें:
  ```
  ऊपर दो बटन जोड़ें। अगर मैं उन पर क्लिक करूँ तो अपने-आप 1 और 5 मिनट के टाइमर शुरू हो जाएँ।
  ```
- अपने ब्राउज़र टैब को रिफ्रेश करें (या `Command (⌘) + R` दबाएँ)
- टेस्ट करें: **5 min** बटन पर क्लिक करें
- अगर यह काम करे, तो बदलाव कमिट करें:
  ```
  ये बदलाव सेव करें।
  ```

हमने दूसरा सेव पॉइंट बना लिया। इस वर्ज़न में दोनों बटन काम कर रहे हैं।

## चरण 12: एक और बटन जोड़ें

- Claude Code में टाइप करें:
  ```
  एक 15-मिनट का बटन जोड़ें।
  ```
- अपने ब्राउज़र टैब को रिफ्रेश करें (`Command (⌘) + R` दबाएँ)
- टेस्ट करें: **15 min** बटन पर क्लिक करें

**इस ट्यूटोरियल के लिए:** मान लीजिए कि 15-मिनट का बटन सही से काम नहीं करता। अभी कमिट न करें—हम खराब बदलावों को त्यागने का अभ्यास करेंगे।

## चरण 13: बदलाव त्यागें (Discard)

कभी-कभी AI का कोड काम नहीं करता और आपको अपने पिछले सेव पॉइंट से फिर से शुरू करना पड़ता है।

- Claude Code में टाइप करें:
  ```
  ये बदलाव त्याग दें।
  ```
- Claude पुष्टि माँगेगा
- `yes` टाइप करें और Enter दबाएँ
- अपना ब्राउज़र रिफ्रेश करें—15-मिनट का बटन गायब हो जाता है

Claude उन नए बदलावों को फेंक देता है जो हमें पसंद नहीं थे। टाइमर फिर से सिर्फ़ 1 और 5 मिनट के बटन के साथ काम करने लगता है!

## चरण 14: साउंड नोटिफिकेशन जोड़ें

- Claude Code में टाइप करें:
  ```
  समय खत्म होने पर एक साउंड नोटिफिकेशन जोड़ें।
  ```
- Claude के काम पूरा करने के बाद ब्राउज़र रिफ्रेश करें और टेस्ट करें (टाइमर को 0.1 मिनट पर सेट करें)
- अगर यह काम करे, तो बदलाव कमिट करें:
  ```
  ये बदलाव सेव करें।
  ```

## चरण 15: स्नूज़ बटन जोड़ें

- Claude Code में टाइप करें:
  ```
  साउंड तब तक बजता रहना चाहिए जब तक मैं उसे स्नूज़ करने के लिए किसी बटन पर क्लिक न करूँ।
  ```
- Claude के काम पूरा करने के बाद ब्राउज़र रिफ्रेश करें और टेस्ट करें (टाइमर को 0.1 मिनट पर सेट करें)
- अगर यह काम करे, तो बदलाव कमिट करें:
  ```
  ये बदलाव सेव करें।
  ```

## चरण 16: अपना कमिट इतिहास देखें

- Claude Code में टाइप करें:
  ```
  मेरा बदलाव इतिहास दिखाएँ
  ```

Claude आपके कमिट को पढ़ने योग्य फ़ॉर्मैट में दिखाता है। आपको दिखेगा:
- आपका शुरुआती टाइमर ऐप कमिट
- प्रीसेट बटन (1-मिनट और 5-मिनट) कमिट
- साउंड नोटिफिकेशन कमिट
- स्नूज़ बटन कमिट

ध्यान दें कि 15-मिनट के बटन की कोशिश वहाँ नहीं है—आपने उसे त्याग दिया था!

## चरण 17: कोड जाँचें

- जिस ब्राउज़र में ऐप दिख रहा है, उसमें राइट-क्लिक करें और **View Page Source** चुनें (या `Option (⌥) + Command (⌘) + U` दबाएँ)
- आप इसका सोर्स कोड देख सकते हैं
- Claude Code में पूछें
  ```
  इस कोड को समझाएँ। बस बड़ी तस्वीर।
  ```

## पूरा वर्कफ़्लो

- Claude से बदलाव करने के लिए कहें
- टेस्ट करें
- अगर यह काम करे → Claude से कमिट करने के लिए कहें
- अगर यह असफल हो → Claude से इसे ठीक करने के लिए कहें
- ठीक न हो पाए → बदलाव त्याग दें और फिर से कोशिश करें
- दोहराएँ

आप हमेशा किसी भी कमिट पर वापस लौट सकते हैं। बेझिझक त्यागें—सिर्फ़ काम करने वाला कोड ही कमिट करें!

## अगले कदम

अपने टाइमर में और सुविधाएँ जोड़ने की कोशिश करें:

- **15-मिनट बटन:** `एक काम करने वाला 15-मिनट प्रीसेट बटन जोड़ें` (जो हमने त्यागा था उसे फिर से करें!)
- **पॉज़ बटन:** `एक Pause/Resume बटन जोड़ें जो टाइमर की स्थिति को टॉगल करे`
- **बेहतर स्टाइलिंग:** `एक आधुनिक रंग योजना और बड़े फ़ॉन्ट के साथ विज़ुअल डिज़ाइन सुधारें`
- **प्रोग्रेस बार:** `बचे हुए समय को दिखाने वाला एक विज़ुअल प्रोग्रेस बार जोड़ें`

याद रखें: हर सुविधा के बाद टेस्ट करें, हर सफलता के बाद कमिट करें, असफलताओं को त्यागें।

## समस्या निवारण

- **"not a git repository" त्रुटि:** सुनिश्चित करें कि आप test_claude फ़ोल्डर में हैं (`cd ~/Documents/test_claude`)
- **Finder में timer.html नहीं मिल रही:** फ़ाइल यहाँ है `/Users/YOUR_USERNAME/Documents/test_claude/timer.html`
- **Git कमांड काम नहीं कर रहे:** सुनिश्चित करें कि आपने चरण 2 पूरा किया है और Git इंस्टॉल किया है
- **टाइमर काम नहीं कर रहा:** ब्राउज़र कंसोल खोलें (पेज पर राइट-क्लिक करें, **Inspect** चुनें, फिर **Console** टैब पर क्लिक करें), किसी भी लाल त्रुटि संदेश को कॉपी करें, उन्हें Claude को दें

## आप Claude से क्या पूछ सकते हैं

- `मैंने कौन-सी फ़ाइलें बदली हैं?` - बिना कमिट किए बदलाव देखें
- `मुझे diff दिखाओ` - ठीक-ठीक देखें कि कौन-सा कोड बदला
- `बताओ टाइमर का कोड क्या करता है` - इम्प्लीमेंटेशन को समझें
- `experiment नाम की एक ब्रांच बनाओ` - जोखिम भरे बदलावों को सुरक्षित रूप से आज़माएँ
- `पिछले कमिट पर वापस जाओ` - आखिरी कमिट के बाद के सभी बदलाव पूर्ववत करें

Claude सभी Git ऑपरेशन सामान्य भाषा के ज़रिए संभालता है—याद रखने के लिए कोई कमांड नहीं!

## वर्कफ़्लो का अवलोकन

- **सेटअप:** Git एक बार इंस्टॉल करें, पहचान एक बार कॉन्फ़िगर करें
- **डेवलपमेंट:** Claude कोड लिखता है, आप ब्राउज़र में टेस्ट करते हैं
- **वर्ज़न कंट्रोल:** Claude सरल अनुरोधों के ज़रिए सभी Git ऑपरेशन संभालता है
- **सुरक्षा:** कभी भी खराब बदलाव त्यागें, किसी भी पिछले कमिट पर वापस लौटें
- **स्थानीय (Local):** सब कुछ आपके कंप्यूटर पर ही रहता है, किसी अकाउंट या इंटरनेट की ज़रूरत नहीं
