# कस्टम स्लैश कमांड बनाएँ

बार-बार वही विस्तृत प्रॉम्प्ट टाइप करते-करते थक गए हैं? कस्टम स्लैश कमांड आपको जटिल निर्देशों को पुन: उपयोग करने योग्य शॉर्टकट के रूप में सेव करने देते हैं। अपने सबसे बार-बार होने वाले कामों के लिए कीबोर्ड शॉर्टकट बनाने की तरह, स्लैश कमांड लंबे प्रॉम्प्ट को `/stock-report Apple` जैसे सरल कमांड में बदल देते हैं जो तुरंत व्यापक रिपोर्ट तैयार करते हैं।

सबसे अच्छी बात? हम विस्तृत प्रॉम्प्ट लिखने और Skill बनाने के लिए Claude का ही उपयोग करते हैं। जी हाँ, Claude खुद को...प्रॉम्प्ट करने में बहुत अच्छा है।

## मुख्य अवधारणाएँ

- **स्लैश कमांड** - एक पुन: उपयोग करने योग्य प्रॉम्प्ट जो एक Markdown फ़ाइल के रूप में सेव होता है और जिसे Claude Code तब चलाता है जब आप `/command-name` टाइप करते हैं
- **आर्ग्यूमेंट्स** - वे वेरिएबल जो आप विशेष `$ARGUMENTS` कीवर्ड का उपयोग करके कमांड को पास करते हैं (जैसे स्टॉक टिकर)
- **`.claude/commands/` फ़ोल्डर** - जहाँ Claude Code आपके कस्टम कमांड को अपने आप खोजता और लोड करता है

## आपको क्या चाहिए

- पूरा किया हुआ [Claude Code in VS Code on Windows](./Claude_Code_in_VS_Code_Win.md) या [Claude Code in VS Code on Mac](./Claude_Code_in_VS_Code_Mac.md)
- रिसर्च करने के लिए एक विषय (हम उदाहरण के तौर पर स्टॉक रिपोर्ट का उपयोग करेंगे)
- VS Code जैसा एक टेक्स्ट एडिटर इंस्टॉल किया हुआ
- 15-20 मिनट

## चरण 1: एक प्रोजेक्ट फ़ोल्डर बनाएँ

**Windows (WSL):**
- स्टार्ट मेनू से **Ubuntu** खोलें
- ये कमांड टाइप करें:
  ```bash
  cd /mnt/c/Users/YOUR_USERNAME/Documents
  mkdir test_claude
  cd test_claude
   ```
  `YOUR_USERNAME` को अपने Windows यूज़रनेम से बदलें

**Mac:**
- **Terminal** खोलें (इसे Applications > Utilities में ढूँढें)
- ये कमांड टाइप करें:
  ```bash
  cd ~/Documents
  mkdir test_claude
  cd test_claude
  ```

## चरण 2: Claude Code शुरू करें

**Windows (WSL):**
- Ubuntu टर्मिनल में ही रहते हुए, टाइप करें:
  ```
  claude
  ```

**Mac:**
- Terminal में ही रहते हुए, टाइप करें:
  ```
  claude
  ```

इंस्टॉलेशन ट्यूटोरियल ([Windows](Install_CLAUDE_Code_Win.md) | [Mac](Install_Claude_Code_MacOS.md)) का पालन करते हुए अपनी Claude सब्सक्रिप्शन से लॉग इन करें। लॉग इन करने के बाद, आपको एक स्वागत संदेश और Claude Code प्रॉम्प्ट दिखेगा।

## चरण 3: Claude से एक स्लैश कमांड बनाने को कहें

फ़ाइलों को मैन्युअल रूप से बनाने के बजाय, Claude से यह काम करवाएँ। यह प्रॉम्प्ट टाइप करें:

```
एक स्लैश कमांड बनाओ जिसका नाम stock-report हो, जो नाम या टिकर सिंबल
से पहचानी गई किसी कंपनी की हाल की गतिविधियों पर रिपोर्ट तैयार करे।
इसमें शामिल करो:
- उत्पाद या सेवा से जुड़ी खबरें
- मैनेजमेंट टीम से जुड़ी खबरें
- हाल की वित्तीय रिपोर्ट
- विश्लेषकों की रिपोर्ट
```
जब पूछा जाए, तो फ़ाइल बनाने की अनुमति Claude को दें।
Claude एक विस्तृत प्रॉम्प्ट बनाएगा और उसे `.claude/commands/` फ़ोल्डर में `stock-report.md` के रूप में सेव करेगा।

**नोट:** हम प्रॉम्प्ट, रिपोर्ट और स्लैश कमांड में हर जगह Markdown फ़ॉर्मेट का उपयोग करते हैं। Markdown AI-फ़्रेंडली है और इसे प्लेन टेक्स्ट फ़ाइल के रूप में आसानी से एडिट किया जा सकता है।

## चरण 4: कमांड की समीक्षा करें

`.claude/commands/` फ़ोल्डर से `stock-report.md` फ़ाइल खोलने के लिए किसी भी टेक्स्ट एडिटर का उपयोग करें। यही स्लैश कमांड का प्रॉम्प्ट है।

अगर आपके पास VS Code इंस्टॉल है (सुझाया गया):
- VS Code शुरू करें
- **File** से, **Open folder** चुनें, और प्रोजेक्ट फ़ोल्डर `Documents/test_claude` चुनें
- फ़ाइल एक्सप्लोरर से, `.claude/commands` पर जाएँ और `stock-report.md` फ़ाइल पर क्लिक करके इसे खोलें

प्रॉम्प्ट की समीक्षा करें और अगर चाहें तो निर्देशों में बदलाव करें।

**नोट:** Claude प्रॉम्प्ट लिखने में बेहद अच्छा है। आप देख सकते हैं कि इसका प्रॉम्प्ट Markdown फ़ॉर्मेट का उपयोग करके अच्छी तरह संरचित और स्पष्ट रूप से लिखा गया है। इस तरह प्रॉम्प्ट लिखना सीखें। यह कभी-कभी यह निर्देश भी शामिल करता है कि अगर पहचानकर्ता अस्पष्ट है तो स्पष्टीकरण माँगा जाए।

## चरण 5: कमांड टेस्ट करें

पहले **Ctrl+C** को दो बार दबाकर मौजूदा Claude Code सेशन को **बंद** करें। फिर Claude को फिर से शुरू करें ताकि नया स्लैश कमांड लोड हो जाए:
  ```
  claude
  ```
अब अपने नए कमांड को एक असली स्टॉक टिकर के साथ टेस्ट करें:

```
/stock-report Apple
```

Claude वेब खोजता है और Apple Inc. के बारे में एक व्यापक रिपोर्ट तैयार करता है। इसमें 1-2 मिनट लग सकते हैं।

## चरण 6: तैयार की गई रिपोर्ट की समीक्षा करें

Claude कमांड लाइन में एक रिपोर्ट बनाता है। आउटपुट की समीक्षा करें:

- जाँचें कि हर सेक्शन में प्रासंगिक, मौजूदा जानकारी है
- सत्यापित करें कि स्रोत विश्वसनीय और हाल के हैं
- ध्यान दें कि Claude ने जानकारी को कैसे व्यवस्थित किया

## चरण 7: रिपोर्ट को फ़ाइल में सेव करें

आइए स्लैश कमांड को इस तरह बदलें कि रिपोर्ट अपने आप markdown फ़ाइल के रूप में सेव हो जाए। इसे स्लैश कमांड की markdown फ़ाइल के अंत में मैन्युअल रूप से जोड़ें।

- `.claude/commands/` फ़ोल्डर से `stock-report.md` फ़ाइल खोलें
- इसके अंत में यह जोड़ें।
  ```
  रिपोर्ट को एक markdown फ़ाइल के रूप में सेव करो। फ़ाइल के नाम में कंपनी का नाम और तारीख हो।
  ```
- फ़ाइल सेव करें।

## चरण 8: कमांड को फिर से चलाएँ

- पहले **Ctrl+C** को दो बार दबाकर मौजूदा Claude Code सेशन को **बंद** करें। फिर Claude को फिर से शुरू करें ताकि नया स्लैश कमांड लोड हो जाए:
  ```
  claude
  ```
- अब अपने नए कमांड को एक असली स्टॉक टिकर के साथ टेस्ट करें:

  ```
  /stock-report AAPL
  ```
- रिपोर्ट खोलें

Claude रिपोर्ट तैयार करता है और इसे `Apple_2025-12-13.md` जैसे नाम की एक markdown फ़ाइल के रूप में सेव करता है। इसे देखने के लिए VS Code में फ़ाइल पर क्लिक करें।

## चरण 9: Claude के ज़रिए कमांड में बदलाव करें

आप Claude से स्लैश कमांड को एडिट करने के लिए कह सकते हैं:

```
stock-report स्लैश कमांड को इस तरह बदलो कि रिपोर्ट html फ़ाइल के रूप में सेव हो।
```

Claude कमांड फ़ाइल को अपडेट करता है। आप इसे एडिटर से सत्यापित कर सकते हैं।

## चरण 10: अपडेट किए गए कमांड को टेस्ट करें

- पहले **Ctrl+C** को दो बार दबाकर मौजूदा Claude Code सेशन को **बंद** करें। फिर Claude को फिर से शुरू करें ताकि नया स्लैश कमांड लोड हो जाए:
  ```
  claude
  ```

- बेहतर बनाए गए कमांड को टेस्ट करें:

  ```
  /stock-report AAPL
  ```

Claude `Apple_2025-12-13.html` जैसे नाम की एक फ़ाइल बनाता है। इसे अपने डिफ़ॉल्ट ब्राउज़र में खोलने के लिए Windows या Mac पर File Explorer से इस फ़ाइल पर क्लिक करें।

## चरण 11: स्लैश कमांड का पुन: उपयोग करें (वैकल्पिक)

आपके स्लैश कमांड में `$ARGUMENTS` कीवर्ड एक प्लेसहोल्डर की तरह काम करता है। जब आप `/stock-report AAPL` टाइप करते हैं, तो Claude प्रॉम्प्ट चलाने से पहले `$ARGUMENTS` को `AAPL` से बदल देता है।

एक अलग टिकर आज़माएँ:

```
/stock-report TSLA
```

अब वही कमांड संरचना Tesla पर रिसर्च करती है।

## चरण 12: एक और स्लैश कमांड आज़माएँ (वैकल्पिक)

अगर आपने [Writing Research Paper](./Writing_Research_Paper_Claude_Code.md) ट्यूटोरियल पूरा किया है, तो आपके पास एक `/research-paper` कमांड होना चाहिए। इसे एक नए विषय पर टेस्ट करें।

पहले, नए सिरे से शुरू करने के लिए Claude की मेमोरी साफ़ करें:

```
/clear
```

फिर research paper कमांड चलाएँ:

```
/research-paper AI in schools
```

दो मुख्य अंतर:
- /research-paper को एक सेशन के अंत में मानवीय इंटरैक्शन को कैप्चर करके बनाया गया था, जबकि /stock-report को शुरुआत से बनाया गया है।
- /research-paper एक पेपर लिखने से पहले इंटरैक्टिव रूप से इनपुट माँगता है।

## अगले कदम

अब जब आप स्लैश कमांड समझ गए हैं, तो अपने वर्कफ़्लो के लिए और कस्टम कमांड बनाएँ:

- **कोड रिव्यू:** `/review-code` - बग और सुधार के लिए कोड का विश्लेषण करें
- **मीटिंग नोट्स:** `/meeting-summary` - संरचित मीटिंग सारांश तैयार करें
- **ईमेल ड्राफ़्ट:** `/email-reply` - प्रोफ़ेशनल ईमेल जवाब बनाएँ

## समस्या निवारण

- **कमांड नहीं मिला:** `.claude/commands/` से कमांड फिर से लोड करने के लिए Claude Code रीस्टार्ट करें
- **आर्ग्यूमेंट्स काम नहीं कर रहे:** जाँचें कि कमांड फ़ाइल में `$ARGUMENTS` सही ढंग से लिखा गया है (केस-सेंसिटिव)
- **रिपोर्ट अधूरी है:** Claude से "जारी रखो" या "[सेक्शन का नाम] सेक्शन में और विवरण जोड़ो" कहें

## वर्कफ़्लो का अवलोकन

- **कस्टम स्लैश कमांड** जटिल प्रॉम्प्ट को सरल शॉर्टकट में बदलकर समय बचाते हैं
- **आर्ग्यूमेंट्स** कमांड को अलग-अलग इनपुट (स्टॉक टिकर, विषय, फ़ाइलें) के लिए लचीला बनाते हैं
- **Claude कमांड बनाता है** - आपको मैन्युअल रूप से Markdown फ़ाइलें लिखने की ज़रूरत नहीं है; बस बताएँ कि आप क्या चाहते हैं
- **कमांड पुन: उपयोग करने योग्य हैं** - एक बार बन जाने पर, इन्हें अलग-अलग प्रोजेक्ट और सेशन में उपयोग करें
- **कमांड जोड़ें** - अलग-अलग कामों के लिए विशेष कमांड की एक लाइब्रेरी बनाएँ
