# VS Code शुरू करें

आप कोड लिखना चाहते हैं, लेकिन Notepad या TextEdit सीमित लगते हैं। आपको कुछ ऐसा चाहिए जो आपको तेज़ी से कोड करने में मदद करे - सिंटैक्स हाइलाइटिंग, ऑटोकम्प्लीट और बिल्ट-इन टूल के साथ। **VS Code कोड के लिए एक स्मार्ट नोटबुक की तरह है** - यह समझता है कि आप क्या लिख रहे हैं और रास्ते में आपकी मदद करता है। [Visual Studio Code](https://code.visualstudio.com) मुफ़्त है, किसी भी OS पर चलता है, और लाखों डेवलपर इसका उपयोग करते हैं।

## मुख्य अवधारणाएँ

- **एडिटर (Editor)** - मुख्य क्षेत्र जहाँ आप कोड लिखते हैं
- **एक्सप्लोरर (Explorer)** - साइडबार जो आपकी फ़ाइलें और फ़ोल्डर दिखाता है
- **एक्सटेंशन (Extensions)** - ऐड-ऑन जो VS Code को नई सुविधाएँ देते हैं
- **इंटीग्रेटेड टर्मिनल (Integrated Terminal)** - VS Code में बना हुआ एक कमांड लाइन

## आपको क्या चाहिए

- Windows, macOS, या Linux कंप्यूटर
- इंटरनेट कनेक्शन
- ~500 MB डिस्क स्पेस
- 20-25 मिनट

## चरण 1: VS Code डाउनलोड और इंस्टॉल करें

- [code.visualstudio.com](https://code.visualstudio.com) पर जाएँ
- **Download** बटन पर क्लिक करें (यह आपका OS पहचान लेता है)
- इंस्टॉलर चलाएँ:
   - **Windows:** `.exe` पर डबल-क्लिक करें, संकेतों के ज़रिए **Next** पर क्लिक करते जाएँ
   - **Mac:** `.dmg` खोलें, VS Code को **Applications** में खींचें
   - **Linux:** अपने पैकेज मैनेजर के लिए निर्देशों का पालन करें
- VS Code लॉन्च करें

आपको शुरुआत के विकल्पों के साथ एक Welcome टैब दिखेगा।

## चरण 2: इंटरफ़ेस का दौरा करें

VS Code में पाँच मुख्य क्षेत्र हैं:

- **एक्टिविटी बार (Activity Bar)** (बाईं किनारा) - Explorer, Search, Git, Extensions आदि के लिए आइकन
- **साइड बार (Side Bar)** - चुनी गई एक्टिविटी के लिए सामग्री दिखाता है (फ़ाइलें, सर्च नतीजे)
- **एडिटर (Editor)** (बीच में) - जहाँ आप कोड लिखते हैं
- **पैनल (Panel)** (नीचे) - Terminal, Problems, Output
- **स्टेटस बार (Status Bar)** (नीचे किनारा) - आपकी फ़ाइल और प्रोजेक्ट के बारे में जानकारी

फ़ाइल ब्राउज़र देखने के लिए **Explorer** आइकन (एक्टिविटी बार के ऊपर) पर क्लिक करें।

## चरण 3: एक फ़ोल्डर खोलें और एक्सप्लोर करें

- **File** → **Open Folder** पर क्लिक करें
- अपने कंप्यूटर पर किसी भी मौजूदा फ़ोल्डर पर जाएँ (जैसे, Documents)
- **Open** (या **Select Folder**) पर क्लिक करें
- अगर "Do you trust the authors?" पूछा जाए, तो **Yes, I trust the authors** पर क्लिक करें

Explorer साइडबार अब आपके फ़ोल्डर की फ़ाइलें दिखाता है:

- किसी फ़ोल्डर को विस्तृत करने के लिए उस पर क्लिक करें
- किसी भी फ़ाइल को एडिटर में खोलने के लिए उस पर क्लिक करें
- सभी फ़ाइलों में खोजने के लिए एक्टिविटी बार में **Search** आइकन (मैग्नीफाइंग ग्लास) पर क्लिक करें

## चरण 4: एक Markdown फ़ाइल बनाएँ

- Explorer में, **New File** आइकन (+ के साथ पेज) पर क्लिक करें
- इसका नाम `README.md` रखें
- यह सामग्री जोड़ें:

```
# मेरा प्रोजेक्ट

यह VS Code सीखने के लिए एक **डेमो प्रोजेक्ट** है।

## विशेषताएँ
- संपादित करना आसान
- Markdown फ़ॉर्मेटिंग
- लाइव प्रीव्यू

## अगले कदम
1. और सामग्री जोड़ें
2. अन्य फ़ाइल प्रकार आज़माएँ
3. एक्सटेंशन एक्सप्लोर करें
```
- सेव करने के लिए **File** → **Save** पर क्लिक करें

Markdown एक सरल टेक्स्ट फ़ॉर्मेट है जो हेडिंग के लिए `#`, बोल्ड के लिए `**`, और लिस्ट के लिए `-` जैसे सिंबल का उपयोग करता है। इसका व्यापक रूप से डॉक्यूमेंटेशन और ChatGPT व Claude जैसे LLM के साथ बातचीत करने के लिए उपयोग किया जाता है।

## चरण 5: Markdown Preview एक्सटेंशन इंस्टॉल करें

- एक्टिविटी बार में **Extensions** आइकन (चौकोर आइकन) पर क्लिक करें
- सर्च बॉक्स में `Markdown Preview Enhanced` टाइप करें
- नतीजों में **Markdown Preview Enhanced** ढूँढें
- **Install** पर क्लिक करें

## चरण 6: अपनी Markdown फ़ाइल की पूर्वावलोकन करें

- अगर `README.md` पहले से खुली नहीं है तो उसे खोलें
- एडिटर में राइट-क्लिक करें और **Markdown Preview Enhanced: Open Preview to the Side** चुनें

एक पूर्वावलोकन पैनल खुलता है जो आपके फ़ॉर्मेट किए गए Markdown को दिखाता है - बाईं ओर एडिट करें, दाईं ओर रीयल-टाइम में बदलाव देखें!

## चरण 7: इंटीग्रेटेड टर्मिनल का उपयोग करें

- **Terminal** → **New Terminal** पर क्लिक करें
- ये कमांड आज़माएँ:

**फ़ाइलों की सूची देखें:**
```
ls
```
(Windows Command Prompt पर, `dir` का उपयोग करें)

**वर्तमान डायरेक्टरी प्रिंट करें:**
```
pwd
```
(Windows Command Prompt पर, `cd` का उपयोग करें)

**एक नया फ़ोल्डर बनाएँ:**
```
mkdir notes
```

Explorer जाँचें - `notes` फ़ोल्डर दिखाई देता है! टर्मिनल आपके प्रोजेक्ट फ़ोल्डर में चलता है, इसलिए कमांड सीधे आपके प्रोजेक्ट को प्रभावित करते हैं।

## चरण 8: VS Code में AI एजेंट का उपयोग करें (वैकल्पिक)

VS Code में [GitHub Copilot Chat](https://code.visualstudio.com/docs/copilot/chat/getting-started-chat) शामिल है, एक AI असिस्टेंट जो कोड को समझा, लिख और डिबग कर सकता है।

- `README.md` फ़ाइल खोलें (या अपने प्रोजेक्ट की कोई अन्य फ़ाइल)
- टाइटल बार में **Chat** → **Open Chat** पर क्लिक करें (या Windows/Linux पर `Ctrl+Alt+I`, Mac पर `Ctrl+Cmd+I` दबाएँ)
- अगर पूछा जाए, तो अपने **GitHub अकाउंट** से साइन इन करें (एक मुफ़्त प्लान उपलब्ध है)
- खुलने वाले चैट पैनल में, टाइप करें: "इस फ़ाइल को समझाओ"
- **Enter** दबाएँ

GitHub Copilot आपकी फ़ाइल का विश्लेषण करेगा और बताएगा कि यह क्या करती है। आप इससे नया कोड लिखने, बग ठीक करने, या "मैं और सुविधाएँ कैसे जोड़ूँ?" जैसे सवालों के जवाब देने के लिए कह सकते हैं।

**टिप:** [इनलाइन एडिटिंग](https://code.visualstudio.com/docs/copilot/copilot-chat) के लिए, किसी भी फ़ाइल में कोड हाइलाइट करें और उस हिस्से को बदलने, ठीक करने, या समझाने के लिए Copilot से कहने के लिए `Ctrl+I` (Windows/Linux) या `Cmd+I` (Mac) दबाएँ।

## अपना प्रोजेक्ट फिर से कैसे खोलें

- Start मेनू (Windows), Spotlight (Mac), या Applications (Linux) से VS Code खोलें
- **File** → **Open Recent** पर क्लिक करें → अपना फ़ोल्डर चुनें
- या **File** → **Open Folder** पर क्लिक करें और उस तक जाएँ

## समस्या निवारण

- **पूर्वावलोकन नहीं दिख रहा:** सुनिश्चित करें कि Markdown Preview Enhanced एक्सटेंशन इंस्टॉल है और आपकी कोई `.md` फ़ाइल खुली है
- **टर्मिनल गलत डायरेक्टरी दिखा रहा है:** टर्मिनल पैनल में ट्रैश आइकन पर क्लिक करें, फिर **Terminal** → **New Terminal** पर क्लिक करें
- **Chat मेनू नहीं दिख रहा:** GitHub Copilot Chat इंस्टॉल करना पड़ सकता है - **Extensions** आइकन पर क्लिक करें, "GitHub Copilot Chat" खोजें, और इसे इंस्टॉल करें
- **एक्सटेंशन काम नहीं कर रहे:** **View** → **Command Palette** पर क्लिक करें, "reload window" टाइप करें, और **Developer: Reload Window** चुनें

## पूरा वर्कफ़्लो

1. VS Code में फ़ोल्डर खोलें
2. फ़ाइलें बनाएँ/एडिट करें
3. पूर्वावलोकन के लिए एक्सटेंशन का उपयोग करें
4. कमांड के लिए टर्मिनल का उपयोग करें
5. कोड को समझने और सुधारने के लिए AI का उपयोग करें
6. सेव करें और दोहराएँ

## अगले कदम

- **अन्य फ़ाइल प्रकार आज़माएँ:** `.html`, `.css`, `.js`, या `.py` फ़ाइलें बनाएँ और VS Code की सिंटैक्स हाइलाइटिंग देखें
- **AI सुविधाएँ एक्सप्लोर करें:** अपने प्रोजेक्ट के लिए कोड लिखने, बग ठीक करने, या सुधार सुझाने के लिए AI से कहें
- **और एक्सटेंशन इंस्टॉल करें:** ऑटो-फ़ॉर्मेटिंग के लिए "Prettier" या Git सुविधाओं के लिए "GitLens" आज़माएँ
- **शॉर्टकट सीखें:** अपने वर्कफ़्लो को तेज़ बनाने के लिए **Help** → **Keyboard Shortcuts Reference** पर क्लिक करें
