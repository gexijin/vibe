# WSL पर Claude Code के लिए VS Code सेट करें

आपने अपने Windows कंप्यूटर पर WSL और Claude Code इंस्टॉल कर लिया है - अब आपको अपने कोड के साथ काम करने के लिए एक विज़ुअल एडिटर चाहिए। VS Code, Windows और आपके Linux वातावरण के बीच की खाई को पाटता है, जिससे आप फ़ाइलों को विज़ुअली एडिट कर सकते हैं जबकि Claude Code इंटीग्रेटेड टर्मिनल में चलता रहता है। VS Code को अपनी Linux दुनिया में एक खिड़की समझें।

## मुख्य अवधारणाएँ

- **VS Code** - Microsoft का एक मुफ़्त कोड एडिटर जो Windows पर चलता है लेकिन WSL से जुड़ सकता है
- **WSL एक्सटेंशन (WSL Extension)** - VS Code को आपके Linux वातावरण से जोड़ता है ताकि आप Claude Code जैसे Linux टूल चला सकें
- **इंटीग्रेटेड टर्मिनल (Integrated Terminal)** - VS Code के अंदर एक टर्मिनल पैनल जो आपके WSL (Linux) वातावरण में चलता है
- **/mnt/c/** - WSL आपकी Windows फ़ाइलों तक कैसे पहुँचता है (जैसे, `/mnt/c/Users/...` = `C:\Users\...`)

## आपको क्या चाहिए

- [Windows पर Claude Code इंस्टॉल करना](./Install_CLAUDE_Code_Win) पूरा किया हो
- [VS Code की मूल बातें](./VS_Code_Getting_Started) पूरा किया हो
- 10-15 मिनट

## चरण 1: एक प्रोजेक्ट फ़ोल्डर बनाएँ

- **File Explorer** खोलें (अपनी टास्कबार में फ़ोल्डर आइकन पर क्लिक करें)
- **Documents** पर जाएँ
- खाली जगह पर राइट-क्लिक करें, **New > Folder** चुनें
- फ़ोल्डर का नाम `test_claude` रखें

## चरण 2: VS Code शुरू करें

- **Windows Start बटन** पर क्लिक करें (आपकी स्क्रीन के निचले-बाएँ कोने में)
- सर्च बॉक्स में `Visual Studio Code` या `VS Code` टाइप करें
- जब **Visual Studio Code** सर्च परिणामों में दिखे, उस पर क्लिक करें
- VS Code एक Welcome टैब के साथ खुलता है - आप इस टैब को बंद कर सकते हैं

## चरण 3: WSL एक्सटेंशन इंस्टॉल करें

- VS Code में, बाईं साइडबार में **Extensions** आइकन पर क्लिक करें (यह चार चौकोर आकृतियों जैसा दिखता है)
- सर्च बॉक्स में `WSL` टाइप करें
- Microsoft द्वारा बनाया गया **WSL** खोजें (यह पहला परिणाम होना चाहिए)
- नीले **Install** बटन पर क्लिक करें
- इंस्टॉलेशन पूरा होने की प्रतीक्षा करें (कुछ सेकंड)

## चरण 4: VS Code को WSL से जोड़ें

- VS Code के निचले-बाएँ कोने को देखें - आपको एक नीला या हरा आइकन दिखेगा
- रिमोट कनेक्शन मेनू खोलने के लिए इस आइकन पर क्लिक करें
- मेनू से **Connect to WSL** चुनें
- VS Code रीलोड होगा और आपके Ubuntu इंस्टॉलेशन से जुड़ जाएगा
- निचले-बाएँ कोने में अब **WSL: Ubuntu** दिखना चाहिए

पहली बार जब आप कनेक्ट करते हैं, VS Code WSL में एक छोटा सर्वर इंस्टॉल करता है। इसमें लगभग 30 सेकंड लगते हैं।

## चरण 5: VS Code में फ़ोल्डर खोलें

- VS Code में (अभी भी WSL से जुड़ा हुआ), मेनू बार में **File** पर क्लिक करें, फिर **Open Folder**
- ऊपर बीच में एक **Open Folder** ड्रॉपडाउन दिखाई देगा।
- यह टाइप करके अपना फ़ोल्डर खोजें:
  ```
  /mnt/c/Users/YOUR_USERNAME/Documents/test_claude
  ```
  `YOUR_USERNAME` की जगह अपना Windows यूज़रनेम डालें (जैसे, `John.Smith`)
- **OK** पर क्लिक करें। VS Code आपके `test_claude` फ़ोल्डर के साथ रीलोड होगा
- अगर "Do you trust the authors?" पूछा जाए, तो **Yes, I trust the authors** पर क्लिक करें

## चरण 6: Claude Code शुरू करें

- VS Code रीलोड होने के बाद, एक नया टर्मिनल खोलें: मेनू बार में **Terminal** पर क्लिक करें, फिर **New Terminal**
- टर्मिनल पैनल में टाइप करें:
  ```
  claude
  ```

अपने Claude सब्सक्रिप्शन से लॉगिन करें, जैसा [इंस्टॉलेशन ट्यूटोरियल](Install_CLAUDE_Code_Win.md) में बताया गया है। लॉगिन करने के बाद, आपको एक स्वागत संदेश और Claude Code प्रॉम्प्ट दिखेगा।

## चरण 7: वर्कफ़्लो का परीक्षण करें

- Claude Code में, टाइप करें:
```
एक छोटा लेख लिखें जिसमें बताया गया हो कि LLM को Markdown फ़ॉर्मेट का उपयोग करना क्यों पसंद है। इसे article.md के रूप में सेव करें।
```
- Claude Code फ़ाइल बनाएगा - आपको बाईं ओर Explorer पैनल में `article.md` दिखाई देगा
- इसे एडिटर में देखने के लिए Explorer में `article.md` पर क्लिक करें
- फ़ॉर्मेट किए गए लेख को प्रीव्यू करने के लिए: `article.md` टैब पर राइट-क्लिक करें और **Open Preview** चुनें
- आपको उचित हेडिंग, बुलेट पॉइंट और फ़ॉर्मेटिंग के साथ रेंडर किया गया Markdown दिखेगा

## बाद में VS Code में Claude को फिर से खोलना

VS Code बंद करने के बाद, अपने WSL प्रोजेक्ट्स पर वापस जाने का तरीका यहाँ है:

- **विकल्प A:** VS Code खोलें, निचले-बाएँ कोने पर क्लिक करें, **Connect to WSL** चुनें, फिर **File > Open Recent**। `/mnt/c/Users/YOUR_USERNAME/Documents/test_claude [WSL: Ubuntu]` चुनें
- **विकल्प B:** Windows से Ubuntu ऐप खोलें, टर्मिनल में अपने प्रोजेक्ट पर जाएँ, और `code .` टाइप करें

VS Code आपके हाल के फ़ोल्डर याद रखता है, इसलिए Open Recent के साथ विकल्प A आमतौर पर सबसे तेज़ है।

## अगले कदम

- Claude Code से किसी मौजूदा कोडबेस को समझाने के लिए कहें: "समझाएँ कि यह प्रोजेक्ट क्या करता है"
- Claude Code से नई सुविधाएँ लिखने में मदद लें: "एक फ़ंक्शन जोड़ें जो किसी सूची का औसत निकाले"
- बग ठीक करने के लिए Claude Code का उपयोग करें: "यह कोड एक एरर दे रहा है, क्या आप इसे ठीक कर सकते हैं?"
- इनलाइन डिफ़ के साथ विज़ुअल इंटरफ़ेस के लिए Claude Code VS Code एक्सटेंशन आज़माएँ (Extensions में "Claude Code" खोजें)
- बड़ी फ़ाइलों को अधिक कुशलता से संभालने के लिए, WSL फ़ाइल सिस्टम (`/home/user/`) में एक फ़ोल्डर बनाएँ। Windows से, File Explorer की साइडबार के नीचे Linux आइकन देखें। या एड्रेस बार में `\\wsl.localhost\` टाइप करें।

## समस्या निवारण

- **निचले-बाएँ कोने में "WSL: Ubuntu" नहीं दिख रहा** - सुनिश्चित करें कि WSL सही तरीके से इंस्टॉल है; यह जाँचने के लिए पहले Ubuntu टर्मिनल खोलने की कोशिश करें कि यह काम करता है
- **टर्मिनल में Linux की जगह PowerShell दिख रहा है** - टर्मिनल पैनल में **+** के बगल में ड्रॉपडाउन ऐरो पर क्लिक करें और **Ubuntu (WSL)** चुनें
- **`claude` कमांड नहीं मिला** - यह जाँचने के लिए `claude --version` चलाएँ कि Claude Code इंस्टॉल है या नहीं; अगर नहीं, तो पहले WSL इंस्टॉलेशन ट्यूटोरियल फॉलो करें

## वर्कफ़्लो का अवलोकन

- **VS Code** Windows पर चलता है और विज़ुअल एडिटर इंटरफ़ेस प्रदान करता है
- **WSL एक्सटेंशन** VS Code को Ubuntu से जोड़ता है ताकि आप Linux टूल चला सकें
- **इंटीग्रेटेड टर्मिनल** WSL के अंदर Claude Code चलाता है
- आपकी फ़ाइलें Windows (Documents फ़ोल्डर) में रहती हैं - WSL `/mnt/c/` के ज़रिए उन तक पहुँचता है
- एडिटर में फ़ाइलें एडिट करें, टर्मिनल में Claude Code से बात करें - दोनों दुनिया का सबसे अच्छा हिस्सा
