# Windows पर Claude Code के लिए VS Code सेट करें

आपने अपने Windows कंप्यूटर पर Claude Code इंस्टॉल कर लिया है - अब आपको अपने कोड के साथ काम करने के लिए एक विज़ुअल एडिटर चाहिए। VS Code में आप फ़ाइलों को विज़ुअली एडिट कर सकते हैं और साथ ही इंटीग्रेटेड टर्मिनल में Claude Code चला सकते हैं, दोनों एक ही विंडो में अगल-बगल।

## मुख्य अवधारणाएँ

- **VS Code** - Microsoft का एक मुफ़्त कोड एडिटर, जिसमें अपना टर्मिनल भी है
- **इंटीग्रेटेड टर्मिनल (Integrated Terminal)** - VS Code के अंदर एक PowerShell टर्मिनल पैनल, ताकि Claude Code चलाने के लिए आपको विंडो न बदलनी पड़े
- **वर्कस्पेस फ़ोल्डर (Workspace folder)** - वह फ़ोल्डर जिसे आप VS Code में खोलते हैं; Claude Code इसके अंदर की फ़ाइलें पढ़ता और एडिट करता है

## आपको क्या चाहिए

- [Windows पर Claude Code इंस्टॉल करना](./Install_CLAUDE_Code_Win) पूरा किया हो
- [VS Code की मूल बातें](./VS_Code_Getting_Started) पूरा किया हो
- 10-15 मिनट

## चरण 1: एक प्रोजेक्ट फ़ोल्डर बनाएँ

- **File Explorer** खोलें (अपनी टास्कबार में फ़ोल्डर आइकन पर क्लिक करें)
- **Documents** पर जाएँ
- खाली जगह पर राइट-क्लिक करें, **New > Folder** चुनें
- फ़ोल्डर का नाम `test_claude` रखें

## चरण 2: VS Code शुरू करें

- **Windows Start बटन** पर क्लिक करें (आपकी स्क्रीन के निचले-बाएँ कोने में)
- सर्च बॉक्स में `Visual Studio Code` या `VS Code` टाइप करें
- जब **Visual Studio Code** सर्च परिणामों में दिखे, उस पर क्लिक करें
- VS Code एक Welcome टैब के साथ खुलता है - आप इस टैब को बंद कर सकते हैं

## चरण 3: VS Code में फ़ोल्डर खोलें

- VS Code में, मेनू बार में **File** पर क्लिक करें, फिर **Open Folder**
- **Documents** पर जाएँ, और `test_claude` फ़ोल्डर चुनें
- **Select Folder** पर क्लिक करें। VS Code आपके `test_claude` फ़ोल्डर के साथ रीलोड होगा
- अगर "Do you trust the authors?" पूछा जाए, तो **Yes, I trust the authors** पर क्लिक करें

## चरण 4: Claude Code शुरू करें

- VS Code रीलोड होने के बाद, एक नया टर्मिनल खोलें: मेनू बार में **Terminal** पर क्लिक करें, फिर **New Terminal**
- टर्मिनल पैनल में टाइप करें:
  ```
  claude
  ```

अपने Claude सब्सक्रिप्शन से लॉगिन करें, जैसा [इंस्टॉलेशन ट्यूटोरियल](Install_CLAUDE_Code_Win.md) में बताया गया है। लॉगिन करने के बाद, आपको एक स्वागत संदेश और Claude Code प्रॉम्प्ट दिखेगा।

## चरण 5: वर्कफ़्लो का परीक्षण करें

- Claude Code में, टाइप करें:
```
एक छोटा लेख लिखें जिसमें बताया गया हो कि LLM को Markdown फ़ॉर्मेट का उपयोग करना क्यों पसंद है। इसे article.md के रूप में सेव करें।
```
- Claude Code फ़ाइल बनाएगा - आपको बाईं ओर Explorer पैनल में `article.md` दिखाई देगा
- इसे एडिटर में देखने के लिए Explorer में `article.md` पर क्लिक करें
- फ़ॉर्मेट किए गए लेख को प्रीव्यू करने के लिए: `article.md` टैब पर राइट-क्लिक करें और **Open Preview** चुनें
- आपको उचित हेडिंग, बुलेट पॉइंट और फ़ॉर्मेटिंग के साथ रेंडर किया गया Markdown दिखेगा

## बाद में VS Code में Claude को फिर से खोलना

VS Code बंद करने के बाद, अपने प्रोजेक्ट पर वापस जाने का तरीका यहाँ है:

- **विकल्प A:** VS Code खोलें, **File > Open Recent** पर क्लिक करें, और `test_claude` चुनें
- **विकल्प B:** **File Explorer** खोलें, `test_claude` फ़ोल्डर पर राइट-क्लिक करें, और **Open with Code** चुनें

## अगले कदम

- Claude Code से किसी मौजूदा कोडबेस को समझाने के लिए कहें: "समझाएँ कि यह प्रोजेक्ट क्या करता है"
- Claude Code से नई सुविधाएँ लिखने में मदद लें: "एक फ़ंक्शन जोड़ें जो किसी सूची का औसत निकाले"
- बग ठीक करने के लिए Claude Code का उपयोग करें: "यह कोड एक एरर दे रहा है, क्या आप इसे ठीक कर सकते हैं?"
- इनलाइन डिफ़ के साथ विज़ुअल इंटरफ़ेस के लिए Claude Code VS Code एक्सटेंशन आज़माएँ (Extensions में "Claude Code" खोजें)

## समस्या निवारण

- **`claude` कमांड नहीं मिला** - यह जाँचने के लिए VS Code टर्मिनल में `claude --version` चलाएँ कि Claude Code इंस्टॉल है या नहीं; अगर नहीं, तो पहले [इंस्टॉलेशन ट्यूटोरियल](Install_CLAUDE_Code_Win.md) फॉलो करें
- **WSL का उपयोग कर रहे हैं?** - अगर आपने वैकल्पिक WSL/Ubuntu वाला तरीका अपनाया है, तो Extensions साइडबार से **WSL** एक्सटेंशन इंस्टॉल करें, निचले-बाएँ कोने में नीले/हरे आइकन पर क्लिक करें, और अपना प्रोजेक्ट फ़ोल्डर खोलने से पहले **Connect to WSL** चुनें (फ़ोल्डर यहाँ मिलेगा: `/mnt/c/Users/YOUR_USERNAME/Documents/test_claude`)

## वर्कफ़्लो का अवलोकन

- **VS Code** Windows पर चलता है और विज़ुअल एडिटर इंटरफ़ेस प्रदान करता है
- **इंटीग्रेटेड टर्मिनल** सीधे VS Code के अंदर Claude Code चलाता है
- एडिटर में फ़ाइलें एडिट करें, टर्मिनल में Claude Code से बात करें - दोनों दुनिया का सबसे अच्छा हिस्सा
