# Claude Code में Subagent बनाएं

आप निवेश के अवसरों की तुलना करना चाहते हैं, लेकिन कई कंपनियों पर शोध करना और उन्हें स्कोर करना घंटों ले लेता है। एक Subagent को ऐसे समझें जैसे आपने एक फाइनेंशियल एनालिस्ट को नौकरी पर रखा हो जो ठीक-ठीक जानता है कि आपके शोध टूल्स का इस्तेमाल कैसे करना है—आप उसे कंपनियों के नाम देते हैं, और वह रिपोर्ट इकट्ठा करता है, हर कंपनी को मुख्य मापदंडों (metrics) पर स्कोर करता है, और सबसे अच्छे निवेश की सिफारिश करता है। एक बार जब आप Subagent बनाना सीख जाते हैं, तो आप अपने काम के किसी भी दोहराए जाने वाले मल्टी-स्टेप वर्कफ़्लो को स्वचालित (automate) कर सकते हैं। यह ट्यूटोरियल आपको दिखाता है कि यह एनालिस्ट कैसे बनाया जाए।

## मुख्य अवधारणाएँ

- **Subagent** - एक विशेष AI वर्कर जिसका अपना लक्ष्य, सिस्टम प्रॉम्प्ट, और टूल्स होते हैं और जो कार्यों को स्वतंत्र रूप से पूरा करता है
- **Isolated Context (अलग किया गया संदर्भ)** - एक Subagent अपने खुद के अलग वर्कस्पेस में काम करता है, इसलिए इसका शोध आपकी मुख्य बातचीत को अव्यवस्थित नहीं करता—केवल अंतिम परिणाम ही वापस आता है
- **Skill** - एक पुन: उपयोग करने योग्य क्षमता (जैसे स्टॉक रिपोर्ट बनाना) जिसे Subagent अपने लक्ष्य पूरे करने के लिए इस्तेमाल कर सकते हैं
- **System Prompt** - वे निर्देश जो तय करते हैं कि Subagent क्या करता है, यह कंपनियों को कैसे स्कोर करता है, और यह किस फॉर्मेट में परिणाम लौटाता है
- **Separation of Concerns (कार्यों का बंटवारा)** - Skills डेटा इकट्ठा करते हैं; Subagent उस डेटा का इस्तेमाल फैसले लेने के लिए करते हैं

## आपको क्या चाहिए

- पूरा किया हुआ [Create Your First Claude Skill](./Create_Your_First_Claude_Skill.md) ट्यूटोरियल
- उस ट्यूटोरियल से पहले से इंस्टॉल किया हुआ `stock-report` Skill (in `.claude/skills/stock-report/`)
- VS Code या कोई अन्य टेक्स्ट एडिटर
- 20-25 मिनट

## चरण 1: अपना प्रोजेक्ट फ़ोल्डर खोलें और Claude Code शुरू करें

आपका `stock-report` Skill उसी प्रोजेक्ट फ़ोल्डर में है जिसे आपने Skill ट्यूटोरियल के लिए इस्तेमाल किया था — नया फ़ोल्डर बनाने के बजाय उसी फ़ोल्डर को फिर से खोलें।

**Windows (PowerShell):**
- **Windows Start बटन** पर क्लिक करें, `PowerShell` टाइप करें, और उसे खोलें
- ये कमांड टाइप करें:
  ```powershell
  cd ~/Documents
  mkdir stock_picker_test
  cd stock_picker_test

  ```
- Claude Code शुरू करें:
  ```
  claude
  ```

**Mac:**
- **Terminal** खोलें (Applications > Utilities में मिलेगा)
- यह कमांड टाइप करें:
  ```bash
  cd ~/Documents/test_claude
  ```
- Claude Code शुरू करें:
  ```
  claude
  ```

इंस्टॉलेशन ट्यूटोरियल का पालन करते हुए अपने Claude सब्सक्रिप्शन से लॉग इन करें ([Windows](Install_CLAUDE_Code_Win.md) | [Mac](Install_Claude_Code_MacOS.md))। लॉग इन करने के बाद, आपको एक वेलकम मैसेज और Claude Code प्रॉम्प्ट दिखेगा।

## चरण 2: पुष्टि करें कि Stock Report Skill मौजूद है

अपना Subagent बनाने से पहले, पुष्टि करें कि Skill उपलब्ध है। टाइप करें:

```
सभी उपलब्ध Skills की सूची दिखाओ
```

आपको आउटपुट में `stock-report` दिखना चाहिए। यह Skill कंपनियों पर शोध करता है और प्रोडक्ट न्यूज़, मैनेजमेंट अपडेट, फाइनेंशियल परफॉरमेंस, और एनालिस्ट की राय को कवर करने वाली रिपोर्ट बनाता है।

अगर आपको यह नहीं दिखता, तो Skill की फ़ाइलें `.claude/skills/stock-report/` (प्रोजेक्ट लेवल पर) में होनी चाहिए। अगर पूरा फ़ोल्डर ही गायब है, तो पहले वापस जाकर इसी प्रोजेक्ट फ़ोल्डर में [Create Your First Claude Skill](./Create_Your_First_Claude_Skill.md) ट्यूटोरियल पूरा करें।

## चरण 3: Subagent बनाम Skill की संरचना (Architecture) को समझें

यहाँ बताया गया है कि Subagent और Skill एक साथ कैसे काम करते हैं:

| भाग (Component) | उद्देश्य | उदाहरण |
|-----------|---------|---------|
| **Skill** | एक कंपनी के बारे में कच्चा डेटा इकट्ठा करता है | "Apple के लिए रिपोर्ट बनाओ: प्रोडक्ट्स, फाइनेंस, मैनेजमेंट, एनालिस्ट" |
| **Subagent** | किसी लक्ष्य को पूरा करने के लिए Skill के डेटा का उपयोग करता है | "Apple और Microsoft के लिए रिपोर्ट लाओ, दोनों को स्कोर करो, सिफारिश करो कि किसमें निवेश करना चाहिए" |

**मुख्य अंतर:**
- **Skill = टूल** जो शोध करता है
- **Subagent = फैसला लेने वाला** जो टूल का इस्तेमाल करता है और लॉजिक लगाता है

आपका stock-picker Subagent यह करेगा:
1. हर कंपनी के लिए stock report Skill को इस्तेमाल करना (2+ बार)
2. कंपनियों को अलग-अलग श्रेणियों में स्कोर करना (फाइनेंस, ग्रोथ, मैनेजमेंट, सेंटिमेंट)
3. स्कोर की तुलना करना और सबसे अच्छे निवेश की सिफारिश करना

## चरण 4: Stock Picker Subagent बनाएं

यह कमांड टाइप करें:

```
/agents
```

आपको Claude Code का एजेंट्स इंटरफ़ेस दिखेगा जो मौजूदा Subagent (अगर कोई हों) और Subagent बनाने, संपादित करने, या हटाने के विकल्प दिखाता है (**Create**, **Edit**, या **Delete**)।

अब अपना Subagent बनाएं:
- **Create new subagent** चुनें
- **Project** चुनें
- **Generate with Claude (recommended)** चुनें
- निर्देशों के लिए यह पेस्ट करें:
  ```
  stock-picker नाम के एक नए Subagent के लिए एक markdown फ़ाइल बनाओ:
  - यह दो या उससे अधिक स्टॉक लेता है
  - शोध करने के लिए stock-report Skill का इस्तेमाल करता है
  - इकट्ठा किए गए डेटा की श्रेणियों के आधार पर स्कोर कार्ड बनाए जाते हैं
  - अंत में एक सिफारिश दी जाती है।
  ```
- **All tools** का इस्तेमाल करने के लिए **[Continue]** पर **Enter** दबाएं
- मॉडल के लिए **Sonnet** चुनें
- रैंडम रंग चुनने के लिए **Enter** दबाएं

**"All tools" का मतलब:** एक Subagent को सिर्फ ज़रूरी टूल्स तक सीमित किया जा सकता है—उदाहरण के लिए, सिर्फ वेब सर्च वाला एक रिसर्च-ओनली एजेंट। यह ट्यूटोरियल **All tools** का इस्तेमाल करता है क्योंकि stock-picker को ऑनलाइन शोध करना है और शायद फ़ाइलें भी लिखनी हैं। आप बाद में Subagent की फ़ाइल संपादित करके इसे सीमित कर सकते हैं।

## चरण 5: आपने जो बनाया उसकी समीक्षा करें (Reflection Checkpoint)

फ़ाइल को VS Code में खोलने के लिए, **File > Open File...** पर क्लिक करें और `.claude/agents/stock-picker.md` पर जाएं।

या आप Claude से यह कहकर पूछ सकते हैं:
```
मुझे stock-picker Subagent फ़ाइल दिखाओ।
```
Claude `.claude/agents/stock-picker.md` में स्थित Subagent फ़ाइल दिखाएगा। आपको दिखेगा:

ऊपर एक **YAML frontmatter** है:
```
---
name: stock-picker
description: Compares multiple companies for investment decisions...
skills: stock-report
---
```

यह frontmatter (`---` मार्कर्स के बीच का हिस्सा) Claude Code को बताता है कि इस Subagent को कब सक्रिय करना है और यह किन Skills का इस्तेमाल कर सकता है।

frontmatter के नीचे आपकी स्कोरिंग पद्धति (methodology) के साथ एक **System prompt** है।

**इन मुख्य तत्वों की पुष्टि करें:**
- Subagent की पहुंच `stock-report` Skill तक है
- System prompt स्कोरिंग के बंटवारे को समझाता है
- Subagent का लक्ष्य स्पष्ट है: कंपनियों की तुलना करना और एक की सिफारिश करना

आप फ़ाइल को सीधे संपादित कर सकते हैं या Claude से इसे अपडेट करने के लिए कह सकते हैं।

## चरण 6: Subagent को टेस्ट करें

अब अपने Subagent को एक असली तुलना के साथ टेस्ट करें। टाइप करें:

```
कौन सा बेहतर निवेश है: Apple या Google?
```

आपके विवरण के आधार पर Subagent अपने आप सक्रिय हो जाएगा।

## चरण 7: Subagent को काम करते हुए देखें

जब Subagent चलता है, तो आप देखेंगे कि यह:
1. **Skill को दो बार इस्तेमाल करता है** - पहले Apple के लिए, फिर Google के लिए stock-report Skill को कॉल करता है
2. **डेटा इकट्ठा करता है** - हर Skill कॉल वेब सर्च करती है और एक कंपनी रिपोर्ट बनाती है
3. **कंपनियों को स्कोर करता है** - श्रेणियों में 40/30/20/10 वेटिंग लागू करता है
4. **आउटपुट बनाता है** - तुलना तालिका और सिफारिश बनाता है

चूंकि इसमें वेब रिसर्च शामिल है, इसलिए इसमें 2-3 मिनट लग सकते हैं।

ध्यान दें कि आपकी मुख्य बातचीत सभी सर्च रिज़ल्ट और बीच के चरणों से नहीं भरती—यही isolated context का असर है। Subagent अपना शोध अपने ही अलग वर्कस्पेस में करता है और सिर्फ वही रिपोर्ट करता है जो आप यहाँ देखते हैं।

## चरण 8: आउटपुट की समीक्षा करें

Subagent एक विस्तृत विश्लेषण लौटाता है जिसमें शामिल है:
- **अलग-अलग कंपनी रिपोर्ट** - हर स्टॉक के लिए प्रोडक्ट अपडेट, फाइनेंशियल मापदंड, मैनेजमेंट बदलाव, एनालिस्ट सेंटिमेंट
- **तुलना स्कोरकार्ड** - श्रेणियों में संख्यात्मक स्कोर (फाइनेंशियल हेल्थ, ग्रोथ पोटेंशियल, मैनेजमेंट क्वालिटी, मार्केट सेंटिमेंट)
- **अंतिम सिफारिश** - किस स्टॉक में निवेश करना है और क्यों

Subagent इसे टर्मिनल में दिखा सकता है या पूरी रिपोर्ट के साथ एक markdown फ़ाइल बना सकता है। आप स्कोरिंग वेट या आउटपुट फॉर्मेट को कस्टमाइज़ करने के लिए Subagent फ़ाइल को संपादित कर सकते हैं।

## अगले कदम

अब जब आपके पास एक काम करने वाला stock-picker Subagent है, तो इन एक्सटेंशन को आज़माएं:

- **3+ स्टॉक की तुलना करें**: यह देखने के लिए कि Subagent और अधिक विकल्पों को कैसे संभालता है, "Compare AAPL, MSFT, and GOOGL" आज़माएं
- **स्कोरिंग वेट बदलें**: 40/30/20/10 के बंटवारे को बदलने के लिए Subagent फ़ाइल संपादित करें (उदाहरण के लिए, अगर आप ग्रोथ स्टॉक पसंद करते हैं तो ग्रोथ को 40% बनाएं)
- **अन्य Subagent बनाएं**: अलग-अलग कार्यों के लिए एक "code-reviewer" Subagent, "bug-hunter" Subagent, या "document-writer" Subagent बनाएं

## समस्या निवारण

- **Subagent सक्रिय नहीं हो रहा**: सुनिश्चित करें कि आपके अनुरोध में कंपनियों की तुलना या निवेश के फैसलों का ज़िक्र हो। यह आज़माएं: "Use the stock-picker subagent to compare..."
- **Skill नहीं मिल रहा**: पुष्टि करें कि `.claude/skills/stock-report/SKILL.md` मौजूद है। अगर आपने इसे अभी जोड़ा है, तो Claude Code को दोबारा शुरू करें।
- **अधूरे स्कोर**: Subagent से "जारी रखो" कहें या "हर श्रेणी के स्कोर को और विस्तार से समझाओ" कहें
- **Subagent बनाने में एरर**: पुष्टि करें कि `.claude/agents/` फ़ोल्डर मौजूद है। Claude Code को इसे अपने आप बनाना चाहिए।

## वर्कफ़्लो का अवलोकन

- **Subagent मल्टी-स्टेप वर्कफ़्लो को स्वचालित करते हैं** - वे Skills का संचालन करते हैं, लॉजिक लगाते हैं, और फैसले देते हैं
- **Skills पुन: उपयोग करने योग्य टूल हैं** - एक Skill को अलग-अलग लक्ष्यों के लिए कई Subagent इस्तेमाल कर सकते हैं
- **System prompt व्यवहार तय करते हैं** - स्पष्ट निर्देश और स्कोरिंग मापदंड Subagent को भरोसेमंद बनाते हैं
- **Subagent अपने काम पर केंद्रित रहते हैं** - हर Subagent का एक ही, स्पष्ट उद्देश्य होता है (स्टॉक चुनना, कोड रिव्यू, वगैरह)
- **कॉम्पोज़िशन बड़े स्तर पर काम करता है** - Skills और Subagent की एक लाइब्रेरी बनाएं जो साथ मिलकर काम करें
