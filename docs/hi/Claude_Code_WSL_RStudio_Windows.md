# Windows पर WSL से RStudio के साथ Claude Code का उपयोग करना

आपके पास R कोड चलाने के लिए Windows पर RStudio है और AI-संचालित कोडिंग सहायता के लिए WSL में Claude Code है। यह ट्यूटोरियल दिखाता है कि दोनों टूल को एक ही प्रोजेक्ट फ़ाइलों पर एक साथ कैसे उपयोग करें। आप Windows में एक R प्रोजेक्ट बनाएँगे, कुछ कोड मैन्युअल रूप से लिखेंगे, फिर Ubuntu टर्मिनल से Claude Code का उपयोग करके इसे विज़ुअलाइज़ेशन और विश्लेषण के साथ बेहतर बनाएँगे—यह सब तब जब RStudio आपके कोड को चलाने और परीक्षण करने के लिए खुला रहता है।

## मुख्य अवधारणाएँ

- **WSL (Windows Subsystem for Linux)** - Windows के अंदर Ubuntu Linux चलाता है, जहाँ Claude Code इंस्टॉल है
- **फ़ाइल पाथ ट्रांसलेशन** - `C:\Users\YourName\Documents` जैसे Windows पाथ, WSL में `/mnt/c/Users/YourName/Documents` बन जाते हैं
- **हाइब्रिड वर्कफ़्लो** - RStudio (Windows) कोड चलाता है; Claude Code (WSL) उसे लिखता और सुधारता है

## आपको क्या चाहिए

- [Windows पर Claude Code इंस्टॉल करना](./Install_CLAUDE_Code_Win) गाइड पूरी की हो
- Windows पर RStudio इंस्टॉल हो
- 20-30 मिनट

## चरण 1: Windows पर RStudio खोलें

- **Windows Start बटन** पर क्लिक करें
- सर्च बॉक्स में `RStudio` टाइप करें
- इसे खोलने के लिए **RStudio** पर क्लिक करें
- RStudio विंडो कई पैनल के साथ खुलती है

## चरण 2: एक नया R प्रोजेक्ट बनाएँ

- RStudio में, ऊपर के मेनू से **File** पर क्लिक करें
- **New Project...** पर क्लिक करें
- **New Directory** चुनें
- **New Project** चुनें
- **Directory name** में टाइप करें: `test_claude`
- "Create project as subdirectory of:" के बगल में **Browse** पर क्लिक करें
- अपने **Documents** फ़ोल्डर पर जाएँ
- **Select Folder** पर क्लिक करें
- **Create Project** पर क्लिक करें
- RStudio प्रोजेक्ट बनाता है और उस पर स्विच करता है

## चरण 3: एक नई R स्क्रिप्ट बनाएँ

- RStudio में, **File > New File > R Script** पर क्लिक करें
- ऊपर-बाएँ पैनल में एक नई खाली स्क्रिप्ट खुलती है
- **File > Save** पर क्लिक करें (या सेव आइकन पर)
- फ़ाइल का नाम रखें: `iris.R`
- **Save** पर क्लिक करें

## चरण 4: प्रारंभिक कोड मैन्युअल रूप से लिखें

अपनी `iris.R` फ़ाइल में यह कोड टाइप करें:

```r
data(iris)
str(iris)
summary(iris)
```

- अपने बदलाव सेव करने के लिए **File > Save** पर क्लिक करें
- कोड चलाने के लिए: सभी लाइनें हाइलाइट करें, फिर **Run** बटन पर क्लिक करें (स्क्रिप्ट पैनल के ऊपर-दाएँ)
- आपको Console पैनल में डेटासेट की संरचना और आँकड़े दिखाने वाला आउटपुट दिखना चाहिए

## चरण 5: Ubuntu Terminal खोलें

- **Windows Start बटन** पर क्लिक करें
- सर्च बॉक्स में `Ubuntu` टाइप करें
- **Ubuntu** (नारंगी गोल आइकन) पर क्लिक करें
- Ubuntu टर्मिनल खुलता है

## चरण 6: अपने प्रोजेक्ट फ़ोल्डर पर जाएँ

- Ubuntu टर्मिनल में, यह कमांड टाइप करें (`YourUsername` की जगह अपना असली Windows यूज़रनेम डालें):
  ```
  cd /mnt/c/Users/YourUsername/Documents/test_claude
  ```
- अपना यूज़रनेम पता करने के लिए, आप टाइप कर सकते हैं: `ls /mnt/c/Users/` और अपने फ़ोल्डर का नाम खोजें
- यह टाइप करके जाँचें कि आप सही जगह पर हैं:
  ```
  ls
  ```
- आपको `iris.R` और `test_claude.Rproj` सूचीबद्ध दिखने चाहिए

## चरण 7: Claude Code लॉन्च करें

- Ubuntu टर्मिनल में, टाइप करें:
  ```
  claude
  ```

अपने Claude सब्सक्रिप्शन से लॉगिन करें, जैसा [इंस्टॉलेशन ट्यूटोरियल](Install_CLAUDE_Code_Win.md) में बताया गया है। लॉगिन करने के बाद, आपको एक स्वागत संदेश और Claude Code प्रॉम्प्ट दिखेगा।

## चरण 8: Claude से स्कैटर प्लॉट के लिए कहें

अगर Claude Code धीमा या अनुत्तरदायी लगे, तो बस इसके शुरू होने की प्रतीक्षा करें। फिर, यह अनुरोध टाइप करें:

```
iris.R में sepal length बनाम width का एक स्कैटर प्लॉट बनाने के लिए कोड जोड़ें, जिसे species के अनुसार रंगा गया हो। ggplot2 का उपयोग करें।
```
- Claude Code आपकी `iris.R` फ़ाइल पढ़ेगा और विज़ुअलाइज़ेशन कोड जोड़ेगा
- पूछे जाने पर, उपयुक्त विकल्प चुनकर Claude को iris.R फ़ाइल एडिट करने की अनुमति दें
- Claude के पूरा होने की प्रतीक्षा करें (आपको एक पुष्टिकरण संदेश दिखेगा)

## चरण 9: RStudio में नया कोड चलाएँ

- वापस RStudio पर स्विच करें (RStudio विंडो पर क्लिक करें)
- हो सकता है आपको एक प्रॉम्प्ट दिखे जिसमें कहा गया हो कि फ़ाइल बदल गई है - रीलोड करने के लिए **Yes** पर क्लिक करें
- अगर कोई प्रॉम्प्ट न दिखे, तो **File > Reopen with Encoding > UTF-8** पर क्लिक करें
- सारा कोड हाइलाइट करें और **Run** पर क्लिक करें
- **Plots** पैनल (नीचे-दाएँ) में एक स्कैटर प्लॉट दिखाई देता है
- अगर आपको ggplot2 से जुड़ा एरर मिले, तो Console पैनल में `install.packages("ggplot2")` टाइप करके इसे इंस्टॉल करें

## चरण 10: स्कैटर प्लॉट को सुधारें

- Ubuntu टर्मिनल पर स्विच करें
- यह अनुरोध टाइप करें:
  ```
  टाइटल हटाएँ। species के अनुसार मार्कर टाइप बदलें। classic थीम में बदलें।
  ```

## चरण 11: सुधरा हुआ प्लॉट देखें

- RStudio पर स्विच करें
- अगर पूछा जाए तो फ़ाइल रीलोड करें
- अपडेट किया गया कोड हाइलाइट करें और **Run** पर क्लिक करें
- प्लॉट अब बिना टाइटल के, हर species के लिए अलग मार्कर आकार के साथ, और classic थीम का उपयोग करते हुए दिखना चाहिए

## चरण 12: Claude से PCA प्लॉट के लिए कहें

- Ubuntu टर्मिनल पर स्विच करें
- यह अनुरोध टाइप करें:
  ```
  संख्यात्मक वेरिएबल्स पर PCA करने और पहले दो प्रिंसिपल कंपोनेंट्स का उपयोग करके सैंपल्स को प्लॉट करने के लिए कोड जोड़ें।
  ```

## चरण 13: PCA विश्लेषण चलाएँ

- RStudio पर स्विच करें
- अगर पूछा जाए तो फ़ाइल रीलोड करें
- सारा कोड हाइलाइट करें और **Run** पर क्लिक करें
- एक PCA प्लॉट दिखाई देता है जो PC1 और PC2 पर प्रोजेक्ट किए गए सैंपल्स को species के अनुसार रंगकर दिखाता है

## चरण 14: Claude से समीक्षा और टिप्पणी के लिए कहें

- Ubuntu टर्मिनल पर स्विच करें
- यह अनुरोध टाइप करें:
  ```
  सटीकता के लिए पूरी स्क्रिप्ट की समीक्षा करें। जहाँ ज़रूरी हो वहाँ टिप्पणियाँ (comments) जोड़ें।
  ```
- Claude कोड की समीक्षा करेगा और व्यापक टिप्पणियाँ जोड़ेगा

## चरण 15: Claude से R Markdown बनाने के लिए कहें

- Ubuntu टर्मिनल पर स्विच करें
- यह अनुरोध टाइप करें:
  ```
  इस विश्लेषण के लिए एक नई R Markdown फ़ाइल बनाएँ। इसे iris_report.Rmd के रूप में सेव करें।
  ```
- Claude आपसे यह फ़ाइल बनाने की अनुमति माँगेगा।
- Claude आपके प्रोजेक्ट फ़ोल्डर में एक नई `.Rmd` फ़ाइल बनाएगा

## चरण 16: R Markdown फ़ाइल को Knit करें

- RStudio पर स्विच करें
- **File > Open File...** पर क्लिक करें
- `iris_report.Rmd` चुनें और **Open** पर क्लिक करें
- स्क्रिप्ट पैनल के ऊपर **Knit** बटन (धागे की गेंद के आइकन के साथ) पर क्लिक करें
- RStudio एक HTML रिपोर्ट जनरेट करेगा
- रिपोर्ट एक नई विंडो में खुलती है जो कथात्मक टेक्स्ट के साथ आपका पूरा विश्लेषण दिखाती है
- HTML फ़ाइल आपके प्रोजेक्ट फ़ोल्डर में सेव हो जाती है

## समस्या निवारण

- **WSL से Windows फ़ाइलों तक पहुँचने पर "Permission denied"** - सुनिश्चित करें कि आप `C:/` की जगह `/mnt/c/` का उपयोग कर रहे हैं। जाँचें कि पाथ में आपका यूज़रनेम सही है।
- **RStudio फ़ाइल में बदलाव नहीं दिखा रहा** - फ़ाइल को मैन्युअल रूप से रीलोड करने के लिए **File > Reopen with Encoding > UTF-8** पर क्लिक करें।
- **"claude: command not found"** - सुनिश्चित करें कि आपने इंस्टॉलेशन गाइड पूरी की है। एक नई Ubuntu टर्मिनल विंडो खोलने की कोशिश करें।
- **प्लॉट नहीं दिख रहे** - सुनिश्चित करें कि ggplot2 इंस्टॉल है। ज़रूरत पड़ने पर RStudio Console में `install.packages("ggplot2")` चलाएँ।
- **एरर: "cannot change working directory"** - आपके Windows पाथ में स्पेस हैं। चरण 6 में, पाथ को कोटेशन में रखें: `cd "/mnt/c/Users/Your Name/Documents/test_claude"`
- **Claude Code पहली रिक्वेस्ट पर धीमा है** - Claude के शुरू होने के लिए 30-60 सेकंड प्रतीक्षा करें। बाद की रिक्वेस्ट तेज़ होंगी।

## अगले कदम

- अपने विश्लेषण में सांख्यिकीय परीक्षण (t-tests, ANOVA) जोड़ने के लिए Claude से पूछने की कोशिश करें
- Claude से इस कोड का **Python संस्करण** प्राप्त करने और एक Quarto डॉक्यूमेंट तैयार करने के लिए कहें
- अपने R स्क्रिप्ट में दोहराए जाने वाले कामों के लिए फ़ंक्शन बनाने के लिए Claude से कहें
- जब आपका R कोड न चले तो एरर संदेशों को डीबग करने के लिए Claude का उपयोग करें
- धीमे R कोड को बेहतर परफ़ॉर्मेंस के लिए ऑप्टिमाइज़ करने के लिए Claude से पूछने की कोशिश करें

## वर्कफ़्लो सारांश

यह हाइब्रिड सेटअप दोनों दुनिया का सबसे अच्छा हिस्सा जोड़ता है:

- **RStudio (Windows)** - इंटरैक्टिव R कंसोल, तुरंत प्लॉट देखना, कोड चलाने के लिए परिचित GUI
- **Claude Code (WSL)** - AI-संचालित कोड जनरेशन, समीक्षा और सुधार
- **साझा फ़ाइलें** - दोनों टूल WSL के `/mnt/c/` माउंट पॉइंट के ज़रिए एक ही फ़ाइलों पर काम करते हैं
- **पुनरावृत्त सुधार** - मैन्युअल कोड से शुरू करें, Claude से सुधारें, RStudio में परीक्षण करें, फिर और सुधारें
- **डॉक्यूमेंटेशन** - Claude आपके विश्लेषण के लिए व्यापक रिपोर्ट और टिप्पणियाँ जनरेट कर सकता है

वर्कफ़्लो सरल है: Ubuntu टर्मिनल में Claude के साथ कोड लिखें या एडिट करें, फिर तुरंत RStudio में उसका परीक्षण करें और उसे चलाएँ। किसी फ़ाइल कॉपी करने या मैन्युअल सिंकिंग की ज़रूरत नहीं—WSL और Windows बिना किसी रुकावट के एक ही फ़ाइलें साझा करते हैं।
