# Mac पर VS Code में Python के लिए Claude Code का उपयोग करें

आपने VS Code में Python सेट कर लिया है और मैन्युअल रूप से कोड लिख सकते हैं। अब आप चाहते हैं कि AI आपके Python कोड को लिखने, सुधारने और डीबग करने में मदद करे, जबकि आप विश्लेषण पर ध्यान केंद्रित करें। Claude Code को एक कोडिंग पार्टनर समझें जो VS Code के अंदर रहता है - आप बताते हैं कि आपको क्या चाहिए, और यह उसी विंडो में रहते हुए कोड लिखता या सुधारता है।

## मुख्य अवधारणाएँ

- **[Claude Code Extension](https://marketplace.visualstudio.com/items?itemName=anthropic.claude-code)** - VS Code एक्सटेंशन जो Claude AI असिस्टेंट को इनलाइन कोड एडिट के साथ सीधे आपके एडिटर में लाता है
- **चैट पैनल (Chat Panel)** - VS Code में साइड पैनल जहाँ आप अपने कोड के बारे में Claude से बातचीत करते हैं
- **इनलाइन एडिट (Inline Edits)** - Claude के सुझाए गए कोड बदलाव सीधे आपकी फ़ाइलों में डिफ़ के साथ दिखते हैं, जिन्हें आप स्वीकार या अस्वीकार कर सकते हैं

## आपको क्या चाहिए

- [VS Code में Python कोडिंग](./Python_Coding_VS_Code_Guide) ट्यूटोरियल पूरा किया हो - Python को VS Code में काम करना चाहिए
- [Mac पर Claude Code इंस्टॉल करें](./Install_Claude_Code_MacOS) ट्यूटोरियल पूरा किया हो - Claude Code CLI इंस्टॉल होना चाहिए
- Claude Pro/Max सब्सक्रिप्शन या Anthropic API key
- 20-30 मिनट

## चरण 1: VS Code खोलें और Python प्रोजेक्ट बनाएँ

- **Visual Studio Code** खोलें
- मेनू बार में **File** पर क्लिक करें, फिर **Open Folder**
- अपने **Documents** फ़ोल्डर पर जाएँ
- डायलॉग के नीचे **New Folder** पर क्लिक करें
- फ़ोल्डर का नाम `claude_python_test` रखें
- नया फ़ोल्डर खोलने के लिए **Open** पर क्लिक करें
- अगर "Do you trust the authors?" पूछा जाए, तो **Yes, I trust the authors** पर क्लिक करें

## चरण 2: Claude Code एक्सटेंशन इंस्टॉल करें और साइन इन करें

- बाईं साइडबार में **Extensions** आइकन पर क्लिक करें (चार चौकोर आकृतियों वाला आइकन)
- सर्च बॉक्स में `Claude Code` टाइप करें
- Anthropic द्वारा बनाया गया **Claude Code** खोजें और **Install** पर क्लिक करें
- इंस्टॉलेशन के बाद, Claude पैनल खोलने के लिए VS Code विंडो के नीचे-दाएँ कोने (स्टेटस बार) में **✻ Claude Code** पर क्लिक करें
- पहली बार एक साइन-इन स्क्रीन दिखेगी: **Sign in** पर क्लिक करें, अपने ब्राउज़र में एक्सेस की अनुमति दें, फिर VS Code पर वापस आएँ
- विस्तृत ऑथेंटिकेशन चरणों के लिए, [Mac पर Claude Code इंस्टॉल करें](./Install_Claude_Code_MacOS) गाइड (चरण 3) देखें
- साइन इन करने के बाद, आपको पैनल में एक **Learn Claude Code** चेकलिस्ट और नीचे एक प्रॉम्प्ट बॉक्स दिखेगा

## चरण 3: प्रारंभिक Python स्क्रिप्ट मैन्युअल रूप से बनाएँ

- मेनू बार में **File > New File** पर क्लिक करें
- **Select a language** पर क्लिक करें और `Python` टाइप करें, फिर **Python** चुनें
- **File > Save** पर क्लिक करके फ़ाइल सेव करें, इसका नाम `iris_analysis.py` रखें
- यह कोड टाइप करें:

```python
from sklearn import datasets
import pandas as pd

# Load iris dataset
iris = datasets.load_iris()
iris_df = pd.DataFrame(iris.data, columns=iris.feature_names)
iris_df['species'] = iris.target_names[iris.target]

# Display structure
iris_df.info()
print("\nSummary statistics:")
print(iris_df.describe())
```

- **File > Save** पर क्लिक करके फ़ाइल सेव करें
- एक virtual environment बनाएँ, जैसा [VS Code में Python कोडिंग](./Python_Coding_VS_Code_Guide) के चरण 5 में किया था: **View > Command Palette** पर क्लिक करें, `Python: Create Environment` टाइप करें, **Venv** चुनें, फिर अपना Python वर्शन चुनें
- Explorer में `.venv` फ़ोल्डर दिखने तक प्रतीक्षा करें
- एक टर्मिनल खोलें: मेनू बार में **View** पर क्लिक करें, फिर **Terminal**। प्रॉम्प्ट की शुरुआत में आपको `(.venv)` दिखना चाहिए
- इस स्क्रिप्ट के लिए ज़रूरी पैकेज इंस्टॉल करें:
  ```
  pip install scikit-learn pandas
  ```
- टर्मिनल में यह चलाएँ: `python iris_analysis.py`
- आपको टर्मिनल में डेटासेट की संरचना और सारांश आँकड़े दिखेंगे

## चरण 4: Claude से स्कैटर प्लॉट जोड़ने के लिए कहें

- Claude पैनल खोलें (खुली फ़ाइल के ऊपर-दाएँ कोने में Spark आइकन, या नीचे-दाएँ कोने में **✻ Claude Code**)
- नीचे चैट बॉक्स में टाइप करें:

```
iris_analysis.py में sepal length बनाम width का एक स्कैटर प्लॉट बनाने के लिए कोड जोड़ें, जिसे species के अनुसार रंगा गया हो। seaborn का उपयोग करें।
```

- भेजने के लिए Enter दबाएँ
- Claude आपकी फ़ाइल पढ़ता है और उसे एडिट करता है - नया कोड `iris_analysis.py` में दिखाई देता है
- अगर Claude एक डिफ़ दिखाकर अनुमति माँगे, तो बदलाव स्वीकार करें
- seaborn/matplotlib कोड आपकी फ़ाइल में दिखाई देगा
- Claude के कोड में इस्तेमाल होने वाले प्लॉटिंग पैकेज इंस्टॉल करें (ये चरण 3 में इंस्टॉल नहीं हुए थे)। टर्मिनल में (जब `(.venv)` दिख रहा हो) चलाएँ:
  ```
  pip install seaborn matplotlib
  ```

## चरण 7: Claude से PCA विश्लेषण के लिए कहें

- Claude चैट पैनल में टाइप करें:

```
संख्यात्मक वेरिएबल्स पर PCA करने और पहले दो प्रिंसिपल कंपोनेंट्स का उपयोग करके सैंपल्स को प्लॉट करने के लिए कोड जोड़ें।
```

- Enter दबाएँ
- Claude आपकी स्क्रिप्ट में PCA कोड जोड़ता है
- अगर पूछा जाए, तो बदलाव स्वीकार करें
- कोड चलाएँ: टर्मिनल में `python iris_analysis.py`
- एक PCA प्लॉट दिखाई देता है जो PC1 और PC2 पर प्रोजेक्ट किए गए सैंपल्स को species के अनुसार रंगकर दिखाता है
- पूरा होने पर प्लॉट विंडो बंद करें

## समस्या निवारण

- **Claude एक्सटेंशन नहीं दिख रहा** - इंस्टॉलेशन के बाद VS Code को रीस्टार्ट करें। यह सत्यापित करने के लिए **View > Extensions** पर क्लिक करें कि यह इंस्टॉल है।
- **"Cannot read Python file" एरर** - सुनिश्चित करें कि आपने फ़ाइल को `.py` एक्सटेंशन के साथ सेव किया है। Claude को फ़ाइलें पढ़ने के लिए उनका सेव होना ज़रूरी है।
- **ऑथेंटिकेशन विफल** - जाँचें कि आपका Claude Pro/Max सब्सक्रिप्शन सक्रिय है या आपकी API key मान्य है। ऑथेंटिकेशन समस्या निवारण के लिए [Mac पर Claude Code इंस्टॉल करें](./Install_Claude_Code_MacOS) देखें।
- **पैकेज नहीं मिला एरर** या **`command not found: python`** - सुनिश्चित करें कि टर्मिनल में `(.venv)` दिख रहा है (अगर नहीं, तो उसे बंद करें और **View > Terminal** से नया टर्मिनल खोलें), फिर आवश्यक पैकेज इंस्टॉल करें: `pip install seaborn matplotlib scikit-learn pandas`। कोड चलाने से पहले इंस्टॉलेशन पूरा होने की प्रतीक्षा करें।
- **कोड बदलाव लागू नहीं हो रहे** - अगर Claude ने अनुमति माँगी थी, तो सुनिश्चित करें कि आपने बदलाव स्वीकार किया है। अगर यह काम नहीं कर रहा, तो Claude के सुझाए गए कोड को मैन्युअल रूप से कॉपी करने की कोशिश करें।
- **प्लॉट नहीं दिख रहा** - सुनिश्चित करें कि आपके पास डिस्प्ले है। कुछ सिस्टम पर आपको अंत में `plt.show()` जोड़ने या Jupyter में `%matplotlib inline` का उपयोग करने की आवश्यकता हो सकती है।

## वर्कफ़्लो सारांश

- **Claude Code Extension** चैट पैनल और इनलाइन डिफ़ के साथ सीधे VS Code में एक AI असिस्टेंट प्रदान करता है
- **बार-बार सुधार (Iterative refinement)** - बुनियादी कोड से शुरू करें, Claude से सुधार के लिए कहें, तुरंत परीक्षण करें, फिर और सुधारें
- **संदर्भ जागरूकता (Context awareness)** - Claude आपकी Python फ़ाइलें पढ़ता है और आपके प्रोजेक्ट की संरचना को समझता है
- **इनलाइन एडिटिंग** - सुझाए गए बदलाव आपकी असली फ़ाइलों में डिफ़ के रूप में दिखते हैं, अलग चैट जवाबों में नहीं
- **फ़्लो में बने रहें** - ब्राउज़र और एडिटर के बीच स्विच करने की ज़रूरत नहीं - सब कुछ VS Code में होता है
