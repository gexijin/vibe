# Claude Desktop ऐप इंस्टॉल करें

Claude Desktop, Windows और Mac के लिए एक अलग चैट ऐप है। आप इसे खोलते हैं, एक मैसेज टाइप करते हैं, और Claude जवाब देता है — न कोई टर्मिनल, न कमांड टाइप करने की ज़रूरत। रोज़मर्रा के सवालों, रिसर्च या लिखने के काम के लिए Claude से चैट करने का यह एक बढ़िया तरीका है।

यह **Claude Code** से अलग है, जिसका उपयोग बाकी ट्यूटोरियल में किया गया है। Claude Code टर्मिनल में रहता है और किसी प्रोजेक्ट फ़ोल्डर में कोड लिखने और बदलने में आपकी मदद करता है। Claude Desktop एक आम चैट विंडो है। आप दोनों इंस्टॉल कर सकते हैं, और पेड प्लान पर आप Claude Desktop के अंदर से Claude Code भी खोल सकते हैं।

## मुख्य अवधारणाएँ

- **Claude Desktop**: Windows और Mac के लिए एक ऐप जिसमें आप सीधे Claude से चैट करते हैं, किसी मैसेजिंग ऐप की तरह।
- **Claude.ai अकाउंट**: वह अकाउंट जिससे आप साइन इन करते हैं — वही जिसका उपयोग आप [claude.ai](https://claude.ai) पर करते हैं। मुफ़्त और पेड दोनों प्लान काम करते हैं।
- **Claude Code**: टर्मिनल में चलने वाला कोडिंग सहायक, जिसके बारे में इस साइट के बाकी ट्यूटोरियल हैं। इसे अलग से इंस्टॉल करना होता है — देखें [Windows पर Claude Code इंस्टॉल करें](./Install_CLAUDE_Code_Win.md) या [Mac पर Claude Code इंस्टॉल करें](./Install_Claude_Code_MacOS.md)।

## आपको क्या चाहिए

- एक Windows 10 (या नया) या Mac (macOS 11 Big Sur या नया) कंप्यूटर
- इंटरनेट कनेक्शन
- एक मुफ़्त या पेड Claude.ai अकाउंट (अगर आपके पास नहीं है तो सेटअप के दौरान बना सकते हैं)
- 5 मिनट

## चरण 1: इंस्टॉलर डाउनलोड करें

- [claude.ai/download](https://claude.ai/download) पर जाएँ
- **Windows:** **Download for Windows** पर क्लिक करें। (अगर आपके पास ARM वाला Windows PC है — जो कम ही होता है — तो इसके बजाय पेज पर दिया गया अलग arm64 डाउनलोड लिंक इस्तेमाल करें।)
- **Mac:** **Download for macOS** पर क्लिक करें। यह एक ही डाउनलोड Intel और Apple Silicon दोनों तरह के Mac पर चलता है, इसलिए आपको यह जानने की ज़रूरत नहीं कि आपके Mac में कौन सी चिप है।

## चरण 2: ऐप इंस्टॉल करें

### Windows

- डाउनलोड की गई फ़ाइल खोलें (अगर यह अपने आप नहीं खुलती, तो अपना **Downloads** फ़ोल्डर देखें)
- इंस्टॉलर में स्क्रीन पर दिए गए निर्देशों का पालन करें
- इंस्टॉल पूरा होने पर, अपने Start मेन्यू में **Claude** ढूँढें

### Mac

- डाउनलोड की गई फ़ाइल खोलें
- पूछे जाने पर **Claude** आइकन को खींचकर **Applications** फ़ोल्डर में छोड़ें
- अपने **Applications** फ़ोल्डर या Launchpad से **Claude** खोलें

## चरण 3: साइन इन करें

- Claude ऐप खोलें
- स्क्रीन पर दिए गए निर्देशों का पालन करते हुए अपने Claude.ai अकाउंट से लॉग इन करें
- अकाउंट नहीं है? पहले [claude.ai](https://claude.ai) पर जाकर एक मुफ़्त अकाउंट बनाएँ, फिर वापस आकर साइन इन करें

## चरण 4: अपना पहला मैसेज भेजें

- मैसेज बॉक्स के अंदर क्लिक करें
- कुछ ऐसा टाइप करें: `आप किन कामों में मेरी मदद कर सकते हैं?`
- भेजने के लिए **Enter** दबाएँ
- Claude ऐप की विंडो में ही जवाब देगा

## चरण 5: (वैकल्पिक) देखें कि Claude Desktop और क्या कर सकता है

Claude Desktop सिर्फ़ चैट के लिए नहीं है। आपके प्लान के हिसाब से:

- **Chat** — हर प्लान पर उपलब्ध, Free प्लान पर भी
- **Claude Code** — Pro, Max, Team और Enterprise प्लान पर आप अलग टर्मिनल खोले बिना, Claude Desktop के अंदर से ही Claude Code शुरू कर सकते हैं
- **Claude Cowork** — पेड प्लान पर, यह Claude को आपकी कंप्यूटर की फ़ाइलों तक पहुँच के साथ कई चरणों वाले काम करने देता है
- **Desktop Extensions** — एक उन्नत सुविधा जो इंस्टॉल किए जा सकने वाले एक्सटेंशन की सूची के ज़रिए Claude को आपके कंप्यूटर के ऐप और फ़ाइलों से जोड़ती है; शुरुआत करने के लिए इसकी ज़रूरत नहीं है

रोज़ की चैट के लिए Claude Desktop इस्तेमाल करने में इनमें से किसी की भी ज़रूरत नहीं है — जब आप बुनियादी बातों में सहज हो जाएँ, तब इन्हें आज़माना अच्छा रहेगा।

## समस्या निवारण

- **Windows इंस्टॉलर को "Windows protected your PC" मैसेज के साथ रोक देता है** — यह नए डाउनलोड के लिए Windows की सामान्य SmartScreen चेतावनी है, यह सिर्फ़ Claude के लिए नहीं है। अगर आपको स्रोत (आधिकारिक claude.ai/download पेज) पर भरोसा है, तो **More info** पर क्लिक करें, फिर **Run anyway** पर।
- **Mac कहता है कि ऐप "cannot be opened because it is from an unidentified developer"** — यह macOS Gatekeeper है, एक सामान्य सुरक्षा जाँच। Claude ऐप पर राइट-क्लिक (या Control-क्लिक) करें और **Open** चुनें, फिर पुष्टि करें।
- **साइन इन नहीं हो रहा** — अपना इंटरनेट कनेक्शन जाँचें, और पहले पक्का करें कि आप ब्राउज़र में [claude.ai](https://claude.ai) पर लॉग इन कर पा रहे हैं।
- **इंस्टॉल करने के बाद ऐप नहीं खुलता** — अपना कंप्यूटर रीस्टार्ट करें, फिर Claude को दोबारा खोलकर देखें। अगर इससे भी काम न बने, तो [claude.ai/download](https://claude.ai/download) से इंस्टॉलर फिर से डाउनलोड करें।
