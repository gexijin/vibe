# मेडिकल रिसर्च के लिए एक Claude Skill बनाएँ

मेडिकल रिसर्च के साथ कदमताल रखने का मतलब है शब्दजाल से भरे घने वैज्ञानिक शोधपत्रों से जूझना। एक Claude Skill एक ऐसे रिसर्च असिस्टेंट की तरह है जो सैकड़ों शोधपत्र पढ़ता है और उन्हें सरल भाषा में समझाता है - PubMed खोजने और तकनीकी भाषा को समझने में घंटों बिताने के बजाय, आप एक सीधा सवाल पूछते हैं और नवीनतम विज्ञान पर आधारित एक स्पष्ट सारांश पाते हैं।

इस ट्यूटोरियल में, आप एक Claude Skill बनाएँगे जो पीयर-रिव्यूड मेडिकल साहित्य खोजती है। हम पहले एक Python स्क्रिप्ट बनाते हैं जो PubMed से क्वेरी करती है। सबसे अच्छी बात? आप सारा काम करने के लिए Claude से कह सकते हैं! इसके पास एक ऐसी Skill है जो Skills बनाती है!

## मुख्य अवधारणाएँ

- **Claude Skill** - एक विशेष टूल जो `.claude/skills/` में सेव किए गए कस्टम निर्देशों, कोड, और दस्तावेज़ीकरण के साथ Claude Code की क्षमताओं का विस्तार करता है
- **PubMed** - US National Library of Medicine द्वारा रखरखाव किया गया 3.5 करोड़+ बायोमेडिकल रिसर्च पेपरों का मुफ़्त डेटाबेस
- **Biopython** - एक Python लाइब्रेरी जो PubMed के डेटाबेस को प्रोग्रामेटिक तरीके से क्वेरी करने के टूल देती है
- **ऑटो-एडिट मोड (Auto-edit mode)** - Shift+Tab से सक्रिय होने वाला फ़ीचर जो Claude को हर बार अनुमति माँगे बिना कई फ़ाइल बदलाव करने देता है

## आपको क्या चाहिए

- पूरा किया हुआ [Claude Code in VS Code on Windows](./Claude_Code_in_VS_Code_Win.md) या [Claude Code in VS Code on Mac](./Claude_Code_in_VS_Code_Mac.md)
- PubMed खोजों के लिए इंटरनेट कनेक्शन
- 15-20 मिनट

## चरण 1: प्रोजेक्ट फ़ोल्डर पर जाएँ

यदि आपने [स्लैश कमांड ट्यूटोरियल](./Reuse_Prompts_via_Slash_Commands.md) पूरा कर लिया है, तो `test_claude` फ़ोल्डर पहले से मौजूद है। ये कमांड दोनों ही स्थितियों में काम करते हैं।

**Windows (WSL):**
- Start मेनू से **Ubuntu** खोलें
- ये कमांड टाइप करें:
  ```bash
  cd /mnt/c/Users/YOUR_USERNAME/Documents
  mkdir -p test_claude
  cd test_claude
  ```
  `YOUR_USERNAME` को अपने Windows यूज़रनेम से बदलें

**Mac:**
- **Terminal** खोलें (इसे Applications > Utilities में खोजें)
- ये कमांड टाइप करें:
  ```bash
  cd ~/Documents
  mkdir -p test_claude
  cd test_claude
  ```

`-p` फ़्लैग फ़ोल्डर बनाता है अगर वह मौजूद नहीं है, या यदि पहले से मौजूद है तो कुछ नहीं करता।

## चरण 2: Claude Code शुरू करें

यह कमांड टाइप करें:
```bash
claude
```

इंस्टॉलेशन ट्यूटोरियल ([Windows](Install_CLAUDE_Code_Win.md) | [Mac](Install_Claude_Code_MacOS.md)) के अनुसार अपने Claude सब्सक्रिप्शन से लॉगिन करें। लॉगिन करने के बाद, आपको एक स्वागत संदेश और Claude Code प्रॉम्प्ट दिखेगा।

## चरण 3: ऑटो-एडिट मोड सक्षम करें

ऑटो-एडिट मोड सक्षम करने के लिए **Shift+Tab** दबाएँ। आपको एक पुष्टिकरण संदेश दिखेगा।

ऑटो-एडिट मोड Claude को हर बार अनुमति माँगे बिना कई फ़ाइलें बनाने और बदलने देता है। कई फ़ाइलें बनाने वाली skills बनाने के लिए यह ज़रूरी है।

## चरण 4: PubMed सर्च स्क्रिप्ट बनाएँ

यह प्रॉम्प्ट कॉपी-पेस्ट करें:

```
pubmed_search.py नाम की एक Python स्क्रिप्ट लिखें जो:
- कमांड लाइन आर्गुमेंट के रूप में एक खोज क्वेरी ले
- 10 तक हाल के शोधपत्र प्राप्त करे
- PMID, शीर्षक, लेखक, जर्नल, वर्ष, एब्सट्रैक्ट प्रीव्यू, और URL लौटाए
```
Claude स्क्रिप्ट बनाता है। यह ज़रूरी Biopython पैकेज इंस्टॉल करता है, जिसमें PubMed के साथ बातचीत करने के लिए एक entrez मॉड्यूल शामिल है। स्क्रिप्ट की संरचना देखने के लिए आउटपुट की समीक्षा करें।

## चरण 5: स्क्रिप्ट का परीक्षण करें

Claude से इसका परीक्षण करने के लिए कहें:

```
"immunotherapy breast cancer" क्वेरी के साथ स्क्रिप्ट का परीक्षण करें
```

Claude स्क्रिप्ट चलाता है और ब्रेस्ट कैंसर के लिए इम्यूनोथेरेपी के बारे में 10 हाल के शोधपत्र दिखाता है। आपको शीर्षक, लेखक, एब्सट्रैक्ट, और PubMed लिंक दिखेंगे।

**नोट:** खोज हज़ारों शोधपत्र ढूँढती है लेकिन जल्दी समीक्षा के लिए केवल 10 सबसे हाल के शोधपत्र प्राप्त करती है।

## चरण 6: मेडिकल रिसर्च Skill बनाएँ

अब हम सब कुछ एक फिर से उपयोग होने वाली skill में पैक करेंगे। यह कॉपी-पेस्ट करें:

```
"medical-research" नाम की एक Claude Skill बनाएँ जो:
- एक मेडिकल सवाल को संभाले
- PubMed एब्सट्रैक्ट प्राप्त करने के लिए क्वेरी डिज़ाइन करे
- गैर-वैज्ञानिकों के लिए सुलभ सरल-भाषा सारांश बनाए
- skill फ़ोल्डर के भीतर pubmed_search.py स्क्रिप्ट शामिल करे
```

Claude पूरी skill संरचना बनाता है:
- `.claude/skills/medical-research/pubmed_search.py` - सर्च स्क्रिप्ट
- `.claude/skills/medical-research/SKILL.md` - Claude के लिए skill उपयोग करने के निर्देश
- `.claude/skills/medical-research/README.md` - उपयोगकर्ता दस्तावेज़ीकरण
- `.claude/skills/medical-research/EXAMPLES.md` - उदाहरण आउटपुट

Claude द्वारा विस्तृत दस्तावेज़ीकरण लिखे जाने के कारण इसमें 2-3 मिनट लगते हैं।

## चरण 7: Skill का परीक्षण करें

सरल भाषा में एक रिसर्च सवाल पूछें:

```
क्या मैं keto डाइट से वज़न कम कर सकता हूँ?
```

Claude स्वतः:
- इसे एक मेडिकल रिसर्च सवाल के रूप में पहचानता है
- medical-research skill सक्रिय करता है
- संबंधित शोधपत्रों के लिए PubMed खोजता है
- निष्कर्षों का विश्लेषण करता है
- प्रभावशीलता, तंत्र, और विचारणीय बिंदुओं को शामिल करते हुए सरल भाषा में रिसर्च समझाता है

जवाब में "How It Works," "Research Findings," "Important Considerations," और "The Bottom Line" जैसे सेक्शन शामिल होते हैं।

## चरण 8: एक और सवाल आज़माएँ

एक और रिसर्च विषय आज़माएँ:

```
क्या वैक्सीन से ऑटिज़्म होता है?
```

जवाब वैज्ञानिक सहमति, इस मिथक की उत्पत्ति, और वास्तविक दुनिया के परिणाम समझाता है।

## चरण 9: Skill फ़ाइलें एक्सप्लोर करें (वैकल्पिक)

skill संरचना देखने के लिए VS Code खोलें:

**Windows:**
- **File Explorer** खोलें, `C:\Users\YOUR_USERNAME\Documents\test_claude` पर जाएँ
- फ़ोल्डर पर राइट-क्लिक करें और **Open with Code** चुनें

**Mac:**
- **Finder** खोलें, `Documents/test_claude` पर जाएँ
- फ़ोल्डर पर राइट-क्लिक करें और **Open with Visual Studio Code** चुनें
- या बस Terminal से ``` code . ``` टाइप करें

VS Code में:
- फ़ाइल एक्सप्लोरर में `.claude/skills/medical-research/` विस्तारित करें
- Claude के लिए विस्तृत निर्देश देखने के लिए `SKILL.md` खोलें
- उपयोगकर्ता दस्तावेज़ीकरण देखने के लिए `README.md` खोलें
- Python कोड देखने के लिए `pubmed_search.py` खोलें

**नोट:** skill पूरी तरह स्व-निहित (self-contained) है - सारा कोड और दस्तावेज़ीकरण एक ही फ़ोल्डर में रहता है।

## चरण 10: Anthropic के रिपॉज़िटरी से Skills इंस्टॉल करना

Anthropic पहले से बनी skills का एक रिपॉज़िटरी बनाए रखता है जिन्हें आप तुरंत इंस्टॉल करके उपयोग कर सकते हैं।

- रिपॉज़िटरी से कोई skill इंस्टॉल करने के लिए, बस Claude से कहें:

  ```
  Anthropic के रिपॉज़िटरी से document skill इंस्टॉल करें
  ```
- यह skill आज़माएँ:
  ```
  Claude Skills पर एक PowerPoint प्रेजेंटेशन बनाएँ।
  ```


**document skill** आपको PDF, Word, PowerPoint, और Excel फ़ाइलें पढ़ने और लिखने में मदद करती है। Claude skill को आपके `.claude/skills/` फ़ोल्डर में क्लोन कर देगा।

**Anthropic के रिपॉज़िटरी से उपलब्ध अन्य skills:**
- पूरी सूची [github.com/anthropics/claude-skills](https://github.com/anthropics/skills) पर ब्राउज़ करें
- वर्तमान सूची देखने के लिए Claude से पूछें "What skills are available in the Anthropic repository?"

## अगले कदम

- **PDF:** इस प्रोजेक्ट फ़ोल्डर में एक सबफ़ोल्डर में कुछ PDF फ़ाइलें कॉपी करें और सारांश माँगें।
- **अन्य पब्लिक skills:** Anthropic से उपलब्ध skills आज़माएँ।
- **Skills साझा करें:** Skills बस ज़िप की हुई फ़ोल्डर होती हैं!
- **अन्य skills बनाएँ:** जिसमें भी आपकी रुचि हो। उदाहरण के लिए, आप अपनी खुद की डेटा फ़ाइलें किसी skill फ़ोल्डर में रख सकते हैं।

## समस्या निवारण

- **Biopython इंस्टॉल नहीं है:** स्क्रिप्ट बनाते समय Claude अपने आप Biopython इंस्टॉल कर देगा। यदि परीक्षण के दौरान आपको import त्रुटियाँ दिखें, तो Claude से `pip install biopython` के साथ Biopython मैन्युअल रूप से इंस्टॉल करने के लिए कहें
- **स्क्रिप्ट नहीं मिलती:** जाँचें कि ऑटो-एडिट मोड सक्षम था (Shift+Tab) - Claude को फ़ाइलें बनाने की अनुमति चाहिए
- **Skill सक्रिय नहीं होती:** skill बनने के तुरंत बाद काम करनी चाहिए - सवाल फिर से पूछने की कोशिश करें या जाँचें कि SKILL.md के हेडर में सही `name: medical-research` है

## वर्कफ़्लो अवलोकन

- **Claude Skills** स्लैश कमांड से ज़्यादा शक्तिशाली हैं - वे कोड, दस्तावेज़ीकरण, और कस्टम निर्देशों को जोड़ती हैं
- **ऑटो-एडिट मोड** (Shift+Tab) बार-बार अनुमति संबंधी प्रॉम्प्ट से बचाकर निर्माण को सुव्यवस्थित करता है
- **स्व-निहित पैकेजिंग** - स्क्रिप्ट skill फ़ोल्डर के भीतर रहती हैं, जिससे वे पोर्टेबल और साझा करने योग्य बनती हैं
- **स्वचालित सक्रियण** - सवाल के पैटर्न के आधार पर skills ट्रिगर होती हैं (रिसर्च सवाल medical-research को सक्रिय करते हैं)
- **सरल-भाषा इंटरफ़ेस** - तकनीकी विवरण जाने बिना स्वाभाविक सवाल पूछें

## Skills बनाम स्लैश कमांड

| फ़ीचर | Skills | स्लैश कमांड |
|---------|--------|----------------|
| **इसमें क्या शामिल है** | प्रॉम्प्ट, कोड, डेटा, और दस्तावेज़ीकरण | केवल प्रॉम्प्ट |
| **सक्रियण** | प्रासंगिक होने पर अपने आप लोड हो जाती है | `/command` से मैन्युअल रूप से ट्रिगर होता है |
| **उपयोग का मामला** | कोड निष्पादन की ज़रूरत वाले जटिल वर्कफ़्लो | त्वरित प्रॉम्प्ट टेम्पलेट और वर्कफ़्लो |
| **फ़ाइल स्थान** | `.claude/skills/skill-name/` | `.claude/commands/` |
| **संरचना** | कई फ़ाइलें (SKILL.md, README.md, कोड फ़ाइलें) | प्रति कमांड एक `.md` फ़ाइल |

**मुख्य बात:** स्लैश कमांड बस UI से प्रॉम्प्ट इंजेक्ट करते हैं। यह उपयोगी है, लेकिन सीमित है।
