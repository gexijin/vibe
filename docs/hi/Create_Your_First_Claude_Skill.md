# अपना पहला Claude Skill बनाएं

आप रिपोर्ट बनाने के लिए मैन्युअल रूप से `/stock-report AAPL` टाइप करते आए हैं। क्या हो अगर Claude आपकी बातचीत के आधार पर खुद तय कर सके कि कब स्टॉक रिपोर्ट बनानी है? यही Skills की ताकत है—जैसे मैन्युअल गियर बदलने से ऑटोमैटिक ट्रांसमिशन में अपग्रेड होना, जो ज़रूरत पड़ने पर खुद गियर बदल लेता है।

## मुख्य अवधारणाएँ

- **Skill** - `.claude/skills/` में संग्रहीत एक ऐसी क्षमता जिसे मॉडल खुद बुलाता है (model-invoked), जिसे Claude संदर्भ (context) के आधार पर अपने आप सक्रिय करता है
- **Model-invoked (मॉडल द्वारा बुलाया गया)** - Claude इसकी डिस्क्रिप्शन पढ़कर तय करता है कि Skill कब इस्तेमाल करनी है, बिना आपके कोई कमांड टाइप किए
- **SKILL.md** - मुख्य फ़ाइल जिसमें YAML frontmatter (मेटाडेटा) और Claude के लिए निर्देश होते हैं

## आपको क्या चाहिए

- पूरा किया हुआ [Create Custom Slash Commands](./Reuse_Prompts_via_Slash_Commands.md) ट्यूटोरियल
- उस ट्यूटोरियल का `stock-report` slash कमांड
- VS Code इंस्टॉल किया हुआ
- 10-15 मिनट

## चरण 1: प्रोजेक्ट फ़ोल्डर पर जाएं

**Windows (WSL):**
- Start मेनू से **Ubuntu** खोलें
- टाइप करें:
  ```bash
  cd /mnt/c/Users/YOUR_USERNAME/Documents/test_claude
  ```
  `YOUR_USERNAME` की जगह अपना Windows यूज़रनेम डालें

  अगर फ़ोल्डर मौजूद नहीं है, तो पहले इसे बनाएं:
  ```bash
  mkdir -p /mnt/c/Users/YOUR_USERNAME/Documents/test_claude
  cd /mnt/c/Users/YOUR_USERNAME/Documents/test_claude
  ```

**Mac:**
- **Terminal** खोलें (Applications > Utilities)
- टाइप करें:
  ```bash
  cd ~/Documents/test_claude
  ```

  अगर फ़ोल्डर मौजूद नहीं है, तो पहले इसे बनाएं:
  ```bash
  mkdir -p ~/Documents/test_claude
  cd ~/Documents/test_claude
  ```

## चरण 2: Claude Code शुरू करें

टाइप करें:
```
claude
```

इंस्टॉलेशन ट्यूटोरियल का पालन करते हुए अपने Claude सब्सक्रिप्शन से लॉग इन करें ([Windows](Install_CLAUDE_Code_Win.md) | [Mac](Install_Claude_Code_MacOS.md))। लॉग इन करने के बाद, आपको एक वेलकम मैसेज और Claude Code प्रॉम्प्ट दिखेगा।

## चरण 3: एडिट के लिए ऑटो-अप्रूव सक्षम करें

एडिट के लिए ऑटो-अप्रूव मोड सक्षम करने के लिए `Ctrl+E` (Windows/Linux) या `Cmd+E` (Mac) दबाएं।

इससे Claude हर बार अनुमति मांगे बिना फ़ाइलें बना और बदल सकता है।

## चरण 4: Claude से slash कमांड को बदलने के लिए कहें

यह प्रॉम्प्ट टाइप करें:
```
मेरे stock-report slash कमांड को एक Skill में बदल दो।
यह Skill तब अपने आप सक्रिय होनी चाहिए जब मैं कंपनियों या स्टॉक्स के बारे में पूछूं।
```

Claude आपके मौजूदा slash कमांड का विश्लेषण करता है और इसे `.claude/skills/stock-report/` में एक Skill में बदल देता है।

**क्या होता है:** Claude एक नया फ़ोल्डर स्ट्रक्चर बनाता है जिसमें `SKILL.md` होती है जिसमें YAML frontmatter होता है जो Claude को बताता है कि इस Skill को कब अपने आप इस्तेमाल करना है।

## चरण 5: Skill की संरचना की समीक्षा करें

VS Code खोलें और प्रोजेक्ट देखें:
- **File > Open Folder** पर क्लिक करें
- `Documents/test_claude` चुनें
- फ़ाइल एक्सप्लोरर में, `.claude/skills/stock-report/` पर जाएं
- इसे खोलने के लिए `SKILL.md` पर क्लिक करें

संरचना पर ध्यान दें:
```yaml
---
name: stock-report
description: Generates reports on companies... Use when users ask about stocks, companies, or ticker symbols.
---

[बाकी निर्देश]
```

`description` फ़ील्ड ही सबसे ज़रूरी है—यह Claude को बिल्कुल बताता है कि इस Skill को कब अपने आप सक्रिय करना है।

## चरण 6: Skill को टेस्ट करें (बिना कमांड टाइप किए)

`/stock-report AAPL` टाइप करने के बजाय, बस एक सामान्य सवाल पूछें:
```
Apple के साथ हाल ही में क्या हो रहा है?
```

**मुख्य अंतर:** आपने कोई कमांड टाइप नहीं किया। Claude आपका सवाल पढ़ता है, पहचानता है कि आप किसी कंपनी के बारे में पूछ रहे हैं, Skill की डिस्क्रिप्शन जांचता है, और अपने आप stock-report Skill इस्तेमाल करने का फैसला करता है।

Claude को काम करते हुए देखें—इसे वही व्यापक रिपोर्ट बनानी चाहिए जो आपने पहले देखी थी।

## चरण 7: दोनों तरीकों की तुलना करें

**Slash कमांड (मैन्युअल):**
```
/stock-report AAPL
```
- आप स्पष्ट रूप से Claude को बताते हैं कि क्या करना है
- हर बार एक जैसा
- दोहराए जाने वाले, अनुमानित कार्यों के लिए अच्छा

**Skill (स्वचालित):**
```
Tesla के हाल के घटनाक्रमों के बारे में बताओ
```
या
```
मैं Microsoft में निवेश करने के बारे में सोच रहा हूं
```
या
```
NVIDIA क्या कर रहा है?
```
- Claude तय करता है कि Skill इस्तेमाल करनी है या नहीं
- ज़्यादा स्वाभाविक बातचीत
- जटिल वर्कफ़्लो के लिए अच्छा जिन्हें Claude आपके लिए संभालता है

## चरण 8: एज केस टेस्ट करें

ऐसे सवाल आज़माएं जिन्हें stock report Skill को ट्रिगर नहीं करना चाहिए:
```
मैं Python कैसे इंस्टॉल करूं?
```

Claude Skill को इस्तेमाल किए बिना सामान्य रूप से जवाब देता है।

अब एक ऐसा सवाल आज़माएं जिसे इसे ट्रिगर करना चाहिए:
```
Google और Meta की तुलना करो
```

Claude को Skill दो बार इस्तेमाल करनी चाहिए—एक बार Google के लिए, एक बार Meta के लिए।

## चरण 9: Skill की डिस्क्रिप्शन बदलें (वैकल्पिक)

आइए Skill को और चयनात्मक (selective) बनाएं। Claude से कहें:
```
stock-report Skill को अपडेट करो ताकि यह तभी सक्रिय हो जब मैं किसी कंपनी के
नाम के साथ स्पष्ट रूप से "analyze" या "report" शब्द का इस्तेमाल करूं।
```

Claude `SKILL.md` में `description` फ़ील्ड को अपडेट करता है। अंतर टेस्ट करें:
```
Apple क्या कर रहा है?
```
(अब शायद Skill को ट्रिगर न करे)

```
Apple का विश्लेषण करो
```
(इसे Skill को ट्रिगर करना चाहिए)

## अगले कदम

अब जब आप Skills को समझ गए हैं, तो अपने वर्कफ़्लो के लिए और बनाएं:

- **Research Skill** - जब आप ऐसे सवाल पूछें जिनके लिए वेब रिसर्च चाहिए, तब अपने आप सक्रिय हो
- **Code Review Skill** - जब आप बग, समस्याओं, या कोड की दिक्कतों का ज़िक्र करें, तब सक्रिय हो
- **Meeting Notes Skill** - जब आप मीटिंग ट्रांसक्रिप्ट पेस्ट करें या सारांश का ज़िक्र करें, तब सक्रिय हो

पैटर्न यह है: तय करें कि Claude को कब अपने आप मदद करनी चाहिए, न कि सिर्फ वे शॉर्टकट जिन्हें आप मैन्युअल रूप से चलाते हैं।

## समस्या निवारण

- **Skill सक्रिय नहीं हो रही:** `SKILL.md` में `description` फ़ील्ड जांचें—इसमें आपके सवाल से जुड़े ट्रिगर शब्द होने चाहिए
- **Skill बहुत बार सक्रिय हो रही है:** डिस्क्रिप्शन को इस बारे में और स्पष्ट बनाएं कि इसे कब इस्तेमाल करना है
- **Skill फ़ोल्डर नहीं मिल रहा:** Skills `.claude/skills/` में होती हैं (छिपा हुआ फ़ोल्डर—अपने फ़ाइल एक्सप्लोरर में "Show hidden files" सक्षम करें)
- **SKILL.md में बदलाव काम नहीं कर रहे:** बदले जाने पर Skills अपने आप लोड हो जाती हैं—किसी रीस्टार्ट की ज़रूरत नहीं। फिर भी काम न करे तो YAML फॉर्मेटिंग जांचें

## वर्कफ़्लो का अवलोकन

- **Slash कमांड** ऐसे शॉर्टकट हैं जिन्हें आप मैन्युअल रूप से टाइप करते हैं (बुकमार्क की तरह)
- **Skills** ऐसी क्षमताएं हैं जिन्हें Claude खुद खोजता और इस्तेमाल करता है (ऐसे असिस्टेंट की तरह जो आपकी पसंद जानता हो)
- **Skill की डिस्क्रिप्शन** निर्देश की तरह काम करती है जो Claude को बताती है: "जब यूज़र X कहे तब मुझे इस्तेमाल करो"
- **दोनों साथ रह सकते हैं** - तेज़, दोहराए जाने वाले कामों के लिए slash कमांड इस्तेमाल करें; जटिल वर्कफ़्लो के लिए Skills इस्तेमाल करें
- **Skills बेहतर स्केल करती हैं** - आपको कमांड के नाम याद रखने की ज़रूरत नहीं; Claude संदर्भ के आधार पर फैसला करता है
