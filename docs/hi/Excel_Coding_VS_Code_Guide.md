# VS Code में Excel के साथ Claude Code का उपयोग करें

आपको एक स्प्रेडशीट चाहिए - फ़ॉर्मूला, फ़ॉर्मेटिंग, शायद एक चार्ट भी - लेकिन आप Excel के मेनू में उलझना नहीं चाहते। Claude Code को एक ऐसे सहायक की तरह सोचें जो Excel को अच्छी तरह जानता है: आप सादी भाषा में बताते हैं कि आपको क्या चाहिए, और यह काम करने वाले फ़ॉर्मूला के साथ एक असली `.xlsx` फ़ाइल बना देता है। यह ट्यूटोरियल आपको दिखाता है कि VS Code में एक प्रोजेक्ट फ़ोल्डर कैसे सेट करें और Claude Code से अपने लिए Excel स्प्रेडशीट कैसे बनवाएँ और बदलवाएँ।

## मुख्य अवधारणाएँ

- **xlsx skill** - Claude Code की एक क्षमता, जिससे वह असली फ़ॉर्मूला, फ़ॉर्मेटिंग और चार्ट के साथ `.xlsx` स्प्रेडशीट बना और बदल सकता है। जब आप अपने Claude अकाउंट से लॉग इन करते हैं, तो यह अपने आप मिल जाती है। पर्दे के पीछे, Claude इसका उपयोग छोटे-छोटे Python प्रोग्राम लिखने और चलाने के लिए करता है, जो फ़ाइल बनाते हैं
- **[Spreadsheet Viewer extension](https://marketplace.visualstudio.com/items?itemName=GrapeCity.gc-excelviewer)** (पहले का नाम Excel Viewer) - VS Code एक्सटेंशन, जिससे आप एडिटर छोड़े बिना स्प्रेडशीट के नंबर जल्दी से देख सकते हैं। यह चार्ट नहीं दिखाता
- **फ़ॉर्मूला बनाम सीधे टाइप किए गए नंबर** - Claude Code असली Excel फ़ॉर्मूला लिखता है (जैसे `=SUM(B2:B9)`), इसलिए डेटा बदलने पर आपकी शीट अपने आप दोबारा हिसाब लगाती है

## आपको क्या चाहिए

- पूरा किया हुआ [VS Code के साथ शुरुआत करें](./VS_Code_Getting_Started)
- Claude Code इंस्टॉल और काम करता हुआ (देखें [Windows पर Claude Code इंस्टॉल करें](./Install_CLAUDE_Code_Win) या [Mac पर Claude Code इंस्टॉल करें](./Install_Claude_Code_MacOS))
- चार्ट देखने के लिए Microsoft Excel, [LibreOffice Calc](https://www.libreoffice.org/download/download-libreoffice/) (मुफ़्त), या Google Sheets (आपके वेब ब्राउज़र में मुफ़्त)
- 20-25 मिनट

## चरण 1: Python इंस्टॉल करें

Claude छोटे Python प्रोग्राम लिखकर स्प्रेडशीट बनाता है, इसलिए आपके कंप्यूटर पर Python होना ज़रूरी है। आपको खुद कोई Python नहीं लिखना होगा।

- **Windows**:
  - [python.org/downloads/windows](https://www.python.org/downloads/windows/) पर जाएँ
  - सबसे नए Python 3 रिलीज़ के नीचे, **Windows installer (64-bit)** पर क्लिक करें
  - डाउनलोड हुई फ़ाइल चलाएँ
  - पहली स्क्रीन के नीचे **"Add python.exe to PATH" बॉक्स को चेक करें**, फिर **Install Now** पर क्लिक करें
- **Mac**:
  - [python.org/downloads](https://www.python.org/downloads/) पर जाएँ और पीले **Download Python** बटन पर क्लिक करें
  - डाउनलोड हुई फ़ाइल खोलें और इंस्टॉलर के निर्देशों का पालन करें, **Continue** और **Install** पर क्लिक करते हुए

अगर VS Code पहले से खुला है, तो उसे बंद करके फिर से खोलें ताकि वह Python ढूँढ सके।

## चरण 2: VS Code में Spreadsheet Viewer एक्सटेंशन इंस्टॉल करें

- VS Code खोलें
- बाएँ साइडबार में **Extensions** आइकन पर क्लिक करें (या **View > Extensions** पर क्लिक करें)
- `GrapeCity.gc-excelviewer` खोजें
- **MESCIUS** के **Spreadsheet Viewer** पर **Install** क्लिक करें

**ध्यान दें:** इस एक्सटेंशन का नाम पहले **GrapeCity** का **Excel Viewer** था, और पुरानी गाइड और वीडियो में अब भी यही नाम दिख सकता है। अब "Excel Viewer" खोजने पर कई दूसरे एक्सटेंशन भी दिखते हैं, इसलिए सही एक्सटेंशन पाने के लिए ऊपर दिए गए ID से खोजें। ID अब भी `GrapeCity` से शुरू होता है - यह सामान्य है।

इससे आप किसी भी `.xlsx` फ़ाइल पर क्लिक करके उसकी शीट, नंबर और फ़ॉर्मूला सीधे VS Code के अंदर देख सकते हैं। जल्दी जाँचने के लिए यह बढ़िया है, लेकिन यह चार्ट, रंगीन हाइलाइटिंग या ड्रॉपडाउन सूचियाँ नहीं दिखा सकता - उनके लिए फ़ाइल को Excel, LibreOffice Calc या Google Sheets में खोलें।

## चरण 3: अपना प्रोजेक्ट फ़ोल्डर बनाएँ

- अपने कंप्यूटर पर एक नया फ़ोल्डर बनाएँ (जैसे, `my-excel-project`)
- VS Code में, **File > Open Folder** पर क्लिक करें और अपना नया फ़ोल्डर चुनें
- **Select Folder** (Windows) या **Open** (Mac) पर क्लिक करें

## चरण 4: Claude Code शुरू करें

- VS Code में **Terminal > New Terminal** पर क्लिक करें
- यह कमांड टाइप करें और Enter दबाएँ:

```bash
claude
```

- अगर आप पहली बार ऐसा कर रहे हैं, तो ऑथेंटिकेशन के लिए एक ब्राउज़र विंडो खुलेगी - अपने Claude अकाउंट से लॉग इन करें
- जब टर्मिनल में Claude का स्वागत संदेश दिखे, तो VS Code पर वापस आएँ

## चरण 5: अपनी पहली स्प्रेडशीट बनाएँ

- Claude Code टर्मिनल में, टाइप करें:

```
budget.xlsx नाम की एक स्प्रेडशीट बनाएँ, जिसमें Category, Monthly Amount और Notes नाम के कॉलम हों। Rent, Groceries और Utilities जैसी 6 उदाहरण खर्च की कैटेगरी असली लगने वाली रकम के साथ जोड़ें। सबसे नीचे एक Total पंक्ति जोड़ें, जो फ़ॉर्मूला से Monthly Amount कॉलम का जोड़ निकाले। सभी रकम US डॉलर ($) में रखें।
```

- Enter दबाएँ
- देखें कि Claude एक Python स्क्रिप्ट लिखता है, उसे चलाता है, और आपके प्रोजेक्ट फ़ोल्डर में `budget.xlsx` बना देता है
- कमांड चलाने या मददगार टूल (जैसे `openpyxl`, स्प्रेडशीट के लिए एक Python ऐड-ऑन) इंस्टॉल करने से पहले Claude आपसे अनुमति माँगेगा - उसे आगे बढ़ने देने के लिए **Yes** चुनें
- अगर Claude कहे कि Python इंस्टॉल नहीं है या मिल नहीं रहा, तो चरण 1 पर वापस जाएँ, फिर VS Code बंद करके फिर से खोलें

## चरण 6: नतीजा देखें

- VS Code के Explorer पैनल (बाईं ओर) में, `budget.xlsx` पर क्लिक करें
- Spreadsheet Viewer एक्सटेंशन फ़ाइल को स्प्रेडशीट के रूप में खोलता है
- अगर इसकी जगह आपको अजीब अक्षर और चिह्न दिखें, तो VS Code ने फ़ाइल को सादे टेक्स्ट के रूप में खोला है - नीचे समस्या निवारण देखें
- सबसे नीचे **Total** सेल पर क्लिक करें - ध्यान दें कि यह एक फ़ॉर्मूला है, हाथ से टाइप किया गया नंबर नहीं
- अगर आपके पास Excel या LibreOffice Calc इंस्टॉल है, तो आप फ़ाइल को File Explorer (Windows) या Finder (Mac) में डबल-क्लिक करके वहाँ भी खोल सकते हैं

## चरण 7: Claude से एक चार्ट जोड़ने को कहें

- Claude Code टर्मिनल में वापस जाकर, टाइप करें:

```
budget.xlsx में एक पाई चार्ट जोड़ें, जो दिखाए कि कुल मासिक खर्च में हर कैटेगरी का कितना हिस्सा है।
```

- Enter दबाएँ
- चार्ट देखने के लिए, `budget.xlsx` को Excel या LibreOffice Calc में खोलें (File Explorer या Finder में उस पर डबल-क्लिक करें), या उसे Google Sheets में अपलोड करें
- VS Code का Spreadsheet Viewer चार्ट नहीं दिखाएगा - यह सामान्य है, चार्ट फ़ाइल में मौजूद है

## चरण 8: डेटा बदलें और Claude से उसे अपडेट करने को कहें

- Excel या LibreOffice Calc में, किसी एक रकम को बदलें (उदाहरण के लिए, Rent की रकम दोगुनी कर दें)
- फ़ाइल सेव करें और बंद करें
- यह बदलाव Spreadsheet Viewer में न करें - वहाँ से सेव करने पर फ़ाइल से चार्ट हट सकता है
- Claude Code टर्मिनल में, टाइप करें:

```
मैंने budget.xlsx में कुछ नंबर बदले हैं। Total फिर से निकालें और पक्का करें कि चार्ट अब भी डेटा से मेल खाता है।
```

- Enter दबाएँ
- Claude आपके बदलाव पढ़ता है, फ़ॉर्मूला जाँचता है, और पुष्टि करता है कि सब कुछ ठीक बैठता है

**Excel या LibreOffice नहीं है?** हाथ से बदलाव करना छोड़ दें और Claude से ही कहें: "budget.xlsx में Rent की रकम दोगुनी कर दें।"

यही मुख्य तरीका है: बताएँ कि आपको क्या चाहिए, Claude को बनाने दें, नतीजा जाँचें, और सादी भाषा में बदलाव माँगें।

## चरण 9: Claude से गड़बड़ डेटा साफ़ करवाएँ

Claude Code उन स्प्रेडशीट को ठीक करने में भी काम आता है जिनमें पहले से गड़बड़ है।

- टाइप करें:

```
बिक्री के डेटा की 15 पंक्तियों वाली एक messy_sales.csv फ़ाइल बनाएँ, जिसमें कुछ गड़बड़ियाँ हों: कुछ खाली सेल, तारीख के अलग-अलग फ़ॉर्मेट, और एक दोहराई गई पंक्ति। फिर sales_clean.xlsx नाम का एक साफ़ वर्शन बनाएँ जिसमें ये गड़बड़ियाँ ठीक हों, और बताएँ कि आपने क्या-क्या ठीक किया।
```

- Enter दबाएँ
- Claude ने क्या पाया और क्या ठीक किया, उसका जो सारांश वह देता है, उसे पढ़ें
- `sales_clean.xlsx` खोलकर पक्का करें कि डेटा सही दिखता है

## अगले कदम

- Claude से अपनी किसी मौजूदा CSV फ़ाइल से स्प्रेडशीट बनाने को कहें (पहले उसे अपने प्रोजेक्ट फ़ोल्डर में खींचकर डालें)
- थोड़े बड़े अनुरोध आज़माएँ: "conditional formatting जोड़ें ताकि $500 से ज़्यादा वाली हर कैटेगरी लाल हो जाए"
- Claude से एक दूसरी शीट जोड़ने को कहें जो पहली शीट के डेटा का सारांश दिखाए
- अपनी स्प्रेडशीट के वर्शन काम करते-करते सेव करने के लिए इसे [Claude Code के साथ GitHub Desktop का उपयोग करें](./GitHub_Desktop_Claude_Code_Workflow) के साथ मिलाएँ
- कई शीट वाला पूरा प्रोजेक्ट बनाने के लिए [Excel में बजट ट्रैकर की Vibe Coding](./Vibe_Coding_Excel_Guide) पर आगे बढ़ें

## समस्या निवारण

- **`budget.xlsx` अजीब अक्षरों और चिह्नों के रूप में खुलता है (`PK` से शुरू होकर)**: VS Code कच्ची फ़ाइल दिखा रहा है, क्योंकि किसी स्प्रेडशीट व्यूअर ने उसे नहीं खोला। फ़ाइल में कोई खराबी नहीं है - `.xlsx` फ़ाइल एक कंप्रेस किया हुआ बंडल होती है, सादा टेक्स्ट नहीं। जाँचें कि MESCIUS का **Spreadsheet Viewer** (`GrapeCity.gc-excelviewer`) इंस्टॉल और चालू है, फिर टैब बंद करें, Explorer पैनल में `budget.xlsx` पर राइट-क्लिक करें, **Open With...** चुनें, और **Excel Editor** (`.xlsx` फ़ाइलों के लिए Spreadsheet Viewer का एडिटर) चुनें। अगर कोई दूसरा स्प्रेडशीट एक्सटेंशन भी इंस्टॉल है, तो उसी सूची में **Configure default editor for '*.xlsx'...** चुनें और **Excel Editor** चुनें, ताकि आगे से फ़ाइल पर एक बार क्लिक करने पर यही खुले।
- **Spreadsheet Viewer खाली या टूटा हुआ प्रीव्यू दिखाता है**: टैब बंद करें और फ़ाइल फिर से खोलें। अगर फिर भी काम न करे, तो फ़ाइल को Excel, LibreOffice Calc या Google Sheets में खोलें - फ़ाइल ठीक है, यह सिर्फ़ प्रीव्यू की गड़बड़ी है।
- **फ़ॉर्मूला वाले सेल में नंबर की जगह खाली दिखता है**: आमतौर पर इसका मतलब है कि फ़ाइल लिखे जाने के बाद उसका दोबारा हिसाब नहीं लगाया गया। Claude से कहें: "budget.xlsx का दोबारा हिसाब लगाएँ और पक्का करें कि किसी फ़ॉर्मूला में त्रुटि नहीं है।"
- **Claude के बदलाव नहीं दिख रहे**: पक्का करें कि आप वही फ़ाइल देख रहे हैं जिसे Claude ने बदला है (Claude जो फ़ाइल नाम बताता है, उसे जाँचें)। रिफ़्रेश करने के लिए VS Code में टैब बंद करके फिर से खोलें।
- **टर्मिनल में "claude is not recognized"**: Claude Code सही से इंस्टॉल नहीं हुआ है। [Windows](./Install_CLAUDE_Code_Win) या [Mac](./Install_Claude_Code_MacOS) के लिए इंस्टॉलेशन गाइड फिर से देखें।
- **चार्ट गायब है**: Spreadsheet Viewer चार्ट नहीं दिखा सकता। फ़ाइल को Excel, LibreOffice Calc या Google Sheets में खोलें। अगर वहाँ भी चार्ट न दिखे, तो Claude से कहें: "budget.xlsx से पाई चार्ट गायब है - कृपया उसे फिर से जोड़ें।"

## वर्कफ़्लो सारांश

- **VS Code** - आपका प्रोजेक्ट फ़ोल्डर, और Spreadsheet Viewer एक्सटेंशन से स्प्रेडशीट देखने की जगह
- **Claude Code** - आपके सादी भाषा के अनुरोधों के आधार पर काम करने वाले फ़ॉर्मूला के साथ असली `.xlsx` फ़ाइलें लिखता और बदलता है
- **Excel / LibreOffice / Google Sheets** - चार्ट देखने और Claude की बनाई फ़ाइलों में हाथ से छोटे-मोटे बदलाव करने के लिए
- **दोहराते रहें** - बताएँ कि आपको क्या चाहिए, नतीजा जाँचें, अगला बदलाव बताएँ
