# Mac पर VS Code से Claude Code का उपयोग करें

आपने अपने Mac पर Claude Code इंस्टॉल कर लिया है - अब आप अपने कोड के साथ काम करने के लिए एक विज़ुअल एडिटर चाहते हैं। VS Code आपको फ़ाइलों को विज़ुअली संपादित करने देता है, जबकि आप इंटीग्रेटेड टर्मिनल में Claude Code चलाते हैं। इसे ऐसे समझें जैसे आपका कोड एडिटर और AI सहायक एक ही विंडो में साथ-साथ हों।

## मुख्य अवधारणाएँ

- **VS Code** - Microsoft का एक मुफ़्त कोड एडिटर जो Mac पर चलता है
- **इंटीग्रेटेड टर्मिनल (Integrated Terminal)** - VS Code के अंदर एक टर्मिनल पैनल जहाँ आप Claude Code चलाते हैं
- **एक्सप्लोरर पैनल (Explorer Panel)** - VS Code के बाईं तरफ़ का फ़ाइल ब्राउज़र

## आपको क्या चाहिए

- पूरा किया हुआ [Mac पर Claude Code इंस्टॉल करना](./Install_Claude_Code_MacOS)
- पूरा किया हुआ [VS Code की बुनियादी बातें](./VS_Code_Getting_Started)
- 10-15 मिनट

## चरण 1: VS Code शुरू करें

- **Finder** खोलें और **Applications** पर जाएँ
- **Visual Studio Code** ढूँढें और उस पर डबल-क्लिक करें
- अगर आपको चेतावनी दिखे "Visual Studio Code is an app downloaded from the internet", तो **Open** पर क्लिक करें
- VS Code एक Welcome टैब के साथ खुलता है - आप इस टैब को बंद कर सकते हैं

**सुझाव:** बाद में आसान पहुँच के लिए Dock में VS Code पर राइट-क्लिक करें और **Options > Keep in Dock** चुनें।

## चरण 2: एक प्रोजेक्ट फ़ोल्डर बनाएँ

- **Finder** खोलें
- बाईं साइडबार में **Documents** पर क्लिक करें
- मेनू बार में **File** पर क्लिक करें, फिर **New Folder**
- फ़ोल्डर का नाम `test_claude` रखें

## चरण 3: लॉग इन करें

Claude Code सबसे पहले आपसे लॉग इन करने के लिए कहेगा। निर्देशों का पालन करें।

1. ब्राउज़र विंडो खोलने के लिए Enter दबाएँ
2. Anthropic के साथ लॉग इन करें या एक अकाउंट बनाएँ
3. कोड कॉपी करें और उसे वापस टर्मिनल में पेस्ट करें
4. Enter दबाएँ

अब आप लॉग इन हो गए हैं। यह आपको सिर्फ़ एक बार करना है।

## चरण 4: फ़ोल्डर को VS Code में खोलें

- VS Code में, मेनू बार में **File** पर क्लिक करें, फिर **Open Folder**
- **Documents** पर जाएँ और अपने बनाए हुए `test_claude` फ़ोल्डर को चुनें
- **Open** पर क्लिक करें
- अगर पूछा जाए "Do you trust the authors of the files in this folder?", तो **Yes, I trust the authors** पर क्लिक करें

अब आपको बाईं तरफ़ के एक्सप्लोरर पैनल में `TEST_CLAUDE` दिखना चाहिए।

## चरण 5: Claude Code शुरू करें

- एक नया टर्मिनल खोलें: मेनू बार में **Terminal** पर क्लिक करें, फिर **New Terminal**
- VS Code के नीचे एक टर्मिनल पैनल दिखाई देता है
- टर्मिनल में टाइप करें:
  ```
  claude
  ```
- आपको एक स्वागत संदेश और Claude Code प्रॉम्प्ट दिखेगा
- अब आप VS Code में फ़ाइलें संपादित करते हुए Claude Code का उपयोग कर सकते हैं

## चरण 6: वर्कफ़्लो टेस्ट करें

- Claude Code में टाइप करें:
```
एक छोटा-सा लेख लिखें जिसमें बताया गया हो कि LLM Markdown फ़ॉर्मैट का उपयोग करना क्यों पसंद करते हैं। इसे article.md के रूप में सेव करें
```
- Claude Code फ़ाइल बनाता है - आपको बाईं तरफ़ के एक्सप्लोरर पैनल में `article.md` दिखाई देगी
- इसे एडिटर में देखने के लिए एक्सप्लोरर में `article.md` पर क्लिक करें
- फ़ॉर्मैट किए गए लेख को प्रीव्यू करने के लिए: `article.md` टैब पर राइट-क्लिक करें और **Open Preview** चुनें
- आपको Markdown सही हेडिंग्स, बुलेट पॉइंट्स, और फ़ॉर्मैटिंग के साथ रेंडर होता हुआ दिखेगा

## बाद में VS Code में Claude को फिर से खोलना

VS Code बंद करने के बाद, अपने प्रोजेक्ट पर वापस लौटने का तरीका यह है:

- **विकल्प A:** VS Code खोलें, **File > Open Recent** पर क्लिक करें, और `test_claude` चुनें
- **विकल्प B:** Terminal खोलें, `cd ~/Documents/test_claude` से अपने प्रोजेक्ट पर जाएँ, और `code .` टाइप करें

VS Code आपके हाल के फ़ोल्डरों को याद रखता है, इसलिए Open Recent वाला विकल्प A आमतौर पर सबसे तेज़ होता है।

## अगले कदम

- Claude Code से किसी मौजूदा कोडबेस को समझाने के लिए कहें: "बताओ यह प्रोजेक्ट क्या करता है"
- Claude Code से नई सुविधाएँ लिखवाएँ: "एक फ़ंक्शन जोड़ो जो किसी लिस्ट का औसत निकाले"
- बग ठीक करने के लिए Claude Code का उपयोग करें: "यह कोड एक त्रुटि दे रहा है, क्या तुम इसे ठीक कर सकते हो?"
- इनलाइन diffs के साथ एक विज़ुअल इंटरफ़ेस के लिए Claude Code VS Code एक्सटेंशन आज़माएँ (Extensions में "Claude Code" खोजें)

## समस्या निवारण

- **टर्मिनल में "zsh" दिखता है पर Claude Code शुरू नहीं होता** - सुनिश्चित करें कि Claude Code सही तरीके से इंस्टॉल है; इसे जाँचने के लिए `claude --version` चलाएँ
- **Terminal में "code" कमांड नहीं मिलता** - VS Code में, मेनू बार में **View** पर क्लिक करें, फिर **Command Palette**, "shell command" टाइप करें, और **Shell Command: Install 'code' command in PATH** चुनें
- **VS Code नहीं खुलता क्योंकि यह किसी अज्ञात डेवलपर से है** - **System Settings > Privacy & Security** पर जाएँ और **Open Anyway** पर क्लिक करें

## वर्कफ़्लो का अवलोकन

- **VS Code** विज़ुअल एडिटर इंटरफ़ेस देता है
- **इंटीग्रेटेड टर्मिनल** VS Code के अंदर Claude Code चलाता है
- आपकी फ़ाइलें आपके Documents फ़ोल्डर में (या जहाँ भी आप चुनें) रहती हैं
- एडिटर में फ़ाइलें संपादित करें, टर्मिनल में Claude Code से बात करें - दोनों दुनिया का सबसे अच्छा हिस्सा
